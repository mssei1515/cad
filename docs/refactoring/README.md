## 進め方

1. 対象の正式仕様、呼出し経路、既存テストを確認する。
2. 再現図面・操作と、成功／失敗時のDocument・参照・履歴を比較できる検証を揃える。
3. 入力、編集の確定と復元、計算、表示の責務を段階的に分離する。
4. 同じfixture・環境で拘束精度、固定対象、追従量、所要時間を比較する。

数値境界・互換性・操作別の復元範囲を一律に統合しない。新しい仕様判断が必要な場合はユーザーへ確認する。テストを下位層へ移す場合は同じ不具合を検出できることを確認してから旧テストを削除する。
