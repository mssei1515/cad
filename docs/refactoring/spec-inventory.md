# 新構成と移行台帳

章単位の一次棚卸し。正式仕様を変更するものではない。移動先は[新しい目次案](./README.md)の領域名を示す。各章に複数の領域が混在するため、段落単位の移動先・保証対応は次段階で確定する。

全項目を保持することを初期状態とし、移動済みへ変更するときは実在する新仕様へのリンクを付ける。削除する場合は、重複の集約先または承認された廃止理由を記録する。小見出しも列挙し、見出しのない段落は直前の章の追跡対象に含める。
