# Cad2 仕様書

このフォルダは、Cad2 の現行実装を確認するための仕様書と、今後の設計判断を分けて管理する。

調査基準日は 2026-08-12、実装基準は Git commit `5beaefc` である。仕様の一次情報として `app.js`、`constraint_solver.js`、`index.html`、Playwright E2E テストを確認した。

## 読み方

文書内では、次の状態を区別する。

| 表記 | 意味 |
| --- | --- |
| **実装済み** | UI、保存形式、またはテストで現在の動作を確認できる |
| **部分実装** | データや処理の一部はあるが、利用経路または整合性が不足している |
| **未実装** | 既存文書などで構想されていたが、現在のコードにはない |
| **要議論** | 今後の仕様として選択が必要である |

「実装済み」は望ましい仕様を意味せず、現時点の挙動を記録したものとする。不具合らしい挙動も、現行仕様と改善候補の両方に明記する。

## 仕様の優先順位

矛盾がある場合は、次の順で「現在の挙動」を判断する。

1. 実行コードと保存・読込処理
2. 自動テストで固定されている挙動
3. このフォルダの「実装済み」記述
4. 「要議論」または「未実装」の設計案

将来仕様を決定したら、先に該当文書の「要議論」を決定事項へ変え、その後にコードとテストを追従させる。

## 用語

| 用語 | 定義 |
| --- | --- |
| Document | 保存対象となる Cad2 データ全体 |
| Geometry | 点・線・円・円弧、ブロック投影、および形状を成立させる拘束 |
| Sketch | Geometry と拘束の作図・solve 単位 |
| Presentation | Geometry を変形せず、見え方と注記を定義する領域 |
| Presentation Sheet | Presentation の独立した見え方を保持する単位 |
| Block Definition | ローカル座標と内部スケッチを持つ再利用可能な Geometry 定義 |
| Block Instance | Block Definition の配置、回転、有効内部スケッチを持つ実体 |
| Projection | Block Instance からワールド座標へ導出される読み取り専用形状 |
