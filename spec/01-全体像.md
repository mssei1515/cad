# 全体像

## 1. プロダクト境界

Cad2 は、ブラウザ上で動作するパラメトリック 2D CAD である。現在はバックエンド、ユーザーアカウント、クラウド同期を持たず、1つの HTML ページと Canvas で動作する。

- `index.html`: ツール、モード切替、スケッチ・ブロック・サイドバーの DOM
- `style.css`: 画面レイアウトとモード別表示
- `geometry_kernel.js`: UIとSolverで共有する副作用のない角度、Arc端点、Line方向・距離計算
- `constraint_solver.js`: Geometry の型、拘束式、数値 solve、自由度解析
- `app.js`: Document 状態、作図コマンド、描画、入力、保存、履歴、ブロック、Presentation
- `tests/e2e`: ブラウザ操作、solve、性能、保存互換性の回帰テスト

Document はブラウザメモリ上にあり、JSON ファイルとして保存・読込する。自動保存はない。

JavaScriptは`geometry_kernel.js`、`constraint_solver.js`、`app.js`の順に読み込む。後続2ファイルは共通数学契約を`window.GeometryKernel`から参照する。

## 2. ドメインの分離

Cad2 は次の2領域を持つ。

```text
Document
├─ Geometry
│  ├─ Sketch tree
│  ├─ Point / Line / Circle / Arc
│  ├─ Constraint / driving dimension
│  └─ Block definition / instance / projection
└─ Presentation
   └─ Presentation Sheet
      ├─ Geometry element style overrides
      └─ Annotation dimension / leader
```

Geometry は形状と成立条件を定義する。Presentation は Geometry を参照するが、形状や拘束を変更しない。この一方向性は現在の実装でも保たれている。

## 3. モード

### Geometry Mode

`appMode = "geometry"`。作図、編集、拘束、拘束寸法、スケッチ、ブロックを扱う。

主な機能は次のとおり。

- 点、連続線、矩形、円、円弧
- 補助線・補助円・補助円弧
- トリム、R面取り、オフセット
- 選択、矩形選択、ドラッグ、コピー、切り取り、貼り付け、削除
- 寸法、一致、水平、垂直、平行、直交、対称、同心、等寸、接線、固定
- スケッチ階層と読み取り専用の先祖参照
- ブロック作成、配置、編集、入れ子、構成切替

### Presentation Mode

`appMode = "presentation"`。Geometry は参照・選択できるが、作図・変形・拘束追加はできない。

現在実装されている主な機能は次のとおり。

- Presentation Sheet の追加、選択、名前変更
- 点・線・円・円弧の要素単位スタイル
- 注記寸法
- Geometry を参照する引出線とテキスト
- 注記寸法と引出線のドラッグ

詳細および未実装範囲は [Presentation](./06-Presentation.md) を参照する。

## 4. Geometry の基本単位

Geometry の実体は `Point`、`Line`、`Circle`、`Arc` である。

- Line は2つの Point を共有参照する。
- Circle と Arc は中心 Point を共有参照するが、半径は数値パラメータとして持つ。
- Arc は開始角と終了角も独立パラメータとして持つ。
- 各要素は1つの `sketchId` を持つ。
- ブロック投影は座標を保存せず、定義とインスタンスから導出する。

拘束は Geometry オブジェクトへの参照を持ち、数値 solve の誤差式を提供する。拘束寸法は拘束値と表示配置を併せ持つ。

## 5. 編集と solve の境界

通常の作図・編集はアクティブスケッチだけを変更する。別スケッチの表示中 Geometry へスナップはできるが、同じ要素を共有しない。

先祖スケッチへの参照拘束では、先祖 Geometry を固定入力として扱う。参照元から依存先へ、トポロジカル順で再 solve する。

ブロックの外部 solve は Block Instance の `x`、`y`、必要に応じて `rotation` だけを変数にする。Block Definition の内部 Geometry は通常画面から変形しない。

## 6. 現在の非目標

コード上、次は存在しない。

- 3D、押し出し、ソリッド、面トポロジー
- 単位系の切替や Document 単位メタデータ
- DXF、SVG、PDF などの図面形式への出力
- 印刷ページ、用紙、縮尺、ビューポート
- クラウド保存、共同編集、外部参照ファイル
- ブロックの倍率、鏡像、通常 Geometry への分解
- 自由曲線、楕円、ポリライン専用型

Presentation の塗り、ハッチング、自由テキスト等は構想にはあるが、現在は未実装である。

## 7. 主要な不変条件

1. Root Sketch には Geometry を作成しない。
2. 通常 Geometry と拘束は、作図可能な1つの Sketch に所属する。
3. 通常拘束は同一 Sketch 内で閉じる。
4. 別 Sketch 参照は、アクティブ Sketch から先祖 Sketch への一方向参照に限る。
5. 参照拘束は参照先を動かさない。
6. Presentation は Geometry の solve 変数や拘束を変更しない。
7. Block Projection は導出値であり、直接保存・変形しない。
8. Block Definition の参照グラフに循環を許さない。
9. 保存時は ID 参照へ変換し、読込時にオブジェクト参照を再構築する。
