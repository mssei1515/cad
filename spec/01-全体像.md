# 全体像

## 1. 製品モデル

Jot2Dはブラウザ上で動作する2DパラメトリックCADである。1つのDocumentに、Geometry、Constraint、Sketch階層、Block Definition／Instance、Parameter、Appearance、Sketch所属Annotation、閉領域へ追従するHatch、手動トレース用の参照画像を保存する。

表示専用の別モードおよびSheetは持たない。すべてのオブジェクトを同じCanvas上で表示・選択・編集する。

```text
Document
├─ Units（長さはmm固定）
├─ Document Appearance defaults
├─ Document Parameters
├─ Sketch hierarchy
│  ├─ Root／子Sketch（子SketchのAppearanceはDocument既定を直接継承）
│  ├─ Geometry
│  ├─ Constraint / Constraint Dimension
│  ├─ Block Instance
│  ├─ Hatch
│  ├─ Reference Image
│  └─ Annotation（Leader／Free Text）
├─ Block Definitions
│  ├─ Definition-local Parameters
│  ├─ internal Sketch / Geometry / Constraint / Block Instance
│  └─ internal Sketch所属Hatch／Annotation／Reference Image
```

## 2. 主要責務

- Geometryは形状を保持する。
- ConstraintはGeometryの成立条件を保持し、solverが座標・半径・角度・Block配置を解く。
- Constraint DimensionはConstraintの値と表示属性を扱う。注記寸法という別オブジェクトは存在しない。
- Parameter、拘束寸法、参照寸法はDocumentまたはBlock Definition固有の名前空間に属し、数式で相互参照できる。
- AppearanceはGeometryの通常表示を決める。
- Hatchは通常Geometryが作る閉領域を参照し、境界変形へ追従する平行線、クロスまたは色塗りつぶしを表示する。
- Annotationは作図可能Sketchに所属し、Geometryを変形せず、引出線または自由テキストを重ねる。
- 参照画像は作図可能Sketchに所属し、Geometry背面の手動トレース用下地として表示する。Constraint、solver、snapには参加しない。
- スケッチ投影、ミラー、直線パターンは参照元から読み取り専用Geometryを動的生成する派生Instanceとして扱う。
- Interaction StateとView StateはDocumentデータから分離する。

## 3. 表示の原則

通常時はAppearanceと各寸法のVisible設定に従って描画する。Toolbarの固定切替buttonを有効にしている間、またはSpaceを押している間はConstraint Status Viewへ切り替え、拘束状態色を優先し、visible=falseのGeometryと寸法も表示する。この操作はDocumentを変更せず履歴にも追加しない。

矛盾は通常表示でもStatus Barの矛盾件数とエラーHintで通知する。

## 4. UI領域

画面はMenu Bar、Toolbar、Canvas、右Properties、下Status Barで構成する。左Explorerは持たない。Canvas左上のSketch Treeに、Sketch階層と所属Objectの分類一覧を統合し、Canvas選択およびPropertiesと同期する。

## 5. 保存互換

Jot2Dの正式な保存ファイル拡張子は`.jot2d`とし、ファイル内容には現行のDocument JSONをそのまま使用する。開く、現在の保存先への上書き保存、名前を付けて保存にはFile System Access APIを使用する。

現行JSONのversionと構造、および旧版からの移行・拒否・無効状態での保持は[データモデルと永続化](./02-データモデルと永続化.md)に定義する。旧版の移行規則も現在の保存互換仕様として維持する。

## 6. 実装構成

- `index.html`: 固定ワークスペースとコマンドUI
- `style.css`: レイアウトと状態表現
- `app.js`: Document状態、描画、入力、保存、履歴、Block、Appearance、Annotation、Reference Image
- `parameter_engine.js`: Parameter式の字句解析、構文解析、依存評価、識別子検証と名称書換え
- `constraint_solver.js`: GeometryとConstraintのsolver
- `geometry_ref.js`: 直接GeometryとBlock Projectionの参照codec
- `spline_geometry.js`: Splineの補間、評価、微分、最近点、flatten、交点計算
- `hatch_region.js`: 閉領域の交点計算、平面グラフ、面探索、境界復元
- `offset_chain.js`: Line／Arcチェーンの支持曲線オフセット、マイター接続、退化・自己交差検出
- `constraint_codec_registry.js`: Constraint永続化dispatch
