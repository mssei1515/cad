# 全体像

## 1. 製品モデル

Cad2はブラウザ上で動作する2DパラメトリックCADである。1つのDocumentに、Geometry、Constraint、Sketch階層、Block Definition／Instance、Parameter、Appearance、Document Annotationを保存する。

表示専用の別モードおよびSheetは持たない。すべてのオブジェクトを同じCanvas上で表示・選択・編集する。

```text
Document
├─ Appearance fallback data
├─ Document Parameters
├─ Sketch hierarchy
│  ├─ Root Sketch（通常／補助Geometry／寸法の既定Appearanceを操作）
│  ├─ Geometry
│  ├─ Constraint / Constraint Dimension
│  └─ Block Instance
├─ Block Definitions
│  └─ Definition-local Parameters
└─ Document Annotations
   ├─ Leader
   └─ Free Text
```

## 2. 主要責務

- Geometryは形状を保持する。
- ConstraintはGeometryの成立条件を保持し、solverが座標・半径・角度・Block配置を解く。
- Constraint DimensionはConstraintの値と表示属性を扱う。注記寸法という別オブジェクトは存在しない。
- Parameter、拘束寸法、参照寸法はDocumentまたはBlock Definition固有の名前空間に属し、数式で相互参照できる。
- AppearanceはGeometryの通常表示を決める。
- Document AnnotationはGeometryを変形せず、引出線または自由テキストを重ねる。
- Interaction StateとView StateはDocumentデータから分離する。

## 3. 表示の原則

通常時はAppearanceと各寸法のVisible設定に従って描画する。Toolbarの固定切替buttonを有効にしている間、またはSpaceを押している間はConstraint Status Viewへ切り替え、拘束状態色を優先し、visible=falseのGeometryと寸法も表示する。この操作はDocumentを変更せず履歴にも追加しない。

矛盾は通常表示でもStatus Barの矛盾件数とエラーHintで通知する。

## 4. UI領域

画面はMenu Bar、Toolbar、左Explorer、中央Canvas、右Properties、下Status Barで構成する。ExplorerとPropertiesはCanvas選択と同期する。

## 5. 保存互換

現行JSONはversion 10である。version 9以前の寸法には名前と数値式を補完する。旧JSONの表示専用モード／Sheetデータは読み込まず破棄し、Geometry、Constraint、Sketch、Blockなど対応可能な旧データは現行モデルへ正規化する。version 10のParameter式または依存関係が不正な場合はDocument全体の読込を拒否し、読込前のDocumentを維持する。

## 6. 実装構成

- `index.html`: 固定ワークスペースとコマンドUI
- `style.css`: レイアウトと状態表現
- `app.js`: Document状態、描画、入力、保存、履歴、Block、Appearance、Annotation
- `parameter_engine.js`: Parameter式の字句解析、構文解析、依存評価、識別子検証と名称書換え
- `constraint_solver.js`: GeometryとConstraintのsolver
- `geometry_ref.js`: 直接GeometryとBlock Projectionの参照codec
- `constraint_codec_registry.js`: Constraint永続化dispatch
