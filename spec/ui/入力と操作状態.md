# 入力と操作状態

[画面構成](./画面構成.md)・[入力と操作状態](./入力と操作状態.md)・[表示とビュー操作](./表示とビュー操作.md)を目的に応じて参照する。機能固有の操作は[仕様の入口](../README.md)から読む。

共通の外観規則は[外観](../contracts/外観.md)、Objectの編集可否は[所属と編集可否](../contracts/所属と編集可否.md)を参照する。

## 共通選択ダイアログ

複数の選択肢を確認するmodalは`choice_dialog.js`の`ChoiceDialog.create(dialog).show(options)`で共通化する。呼び出し側がタイトル、説明、値と表示名を持つ選択肢、初期選択値、キャンセル／閉じるの表示名を渡し、Promiseで選択値を受け取る。キャンセル・×・Escは`null`を返す。表示文字列はHTMLとして解釈しない。

初期選択のbuttonにフォーカスし、Tabでダイアログ内を移動、Enter／Spaceでフォーカス中のbuttonを実行できる。背景は操作不可とし、キー操作をCanvasへ伝播させない。閉じた際はブラウザ標準のdialog動作で呼出元へフォーカスを戻す。同じダイアログへの同時表示要求は拒否し、再表示時に前回の内容と選択結果を引き継がない。呼び出し側は選択確定後に業務処理を実行し、キャンセル時の状態保持を担当する。表示色は既存settings dialogと同じテーマ変数を利用する。

## 1. Selectionと操作状態

SelectionはInteraction Stateから独立する。選択したままPropertiesを編集でき、作図・拘束・Annotation配置はそれぞれInteraction Stateとして管理する。

Escは進行中コマンドを段階的にcancelし、コマンドがなければSelectionを解除する。Canvas空白clickはSelectionを解除する。

操作固有の入力は[派生Instanceの入力と選択](../operations/派生Instance.md#6-派生instanceの入力と選択)を参照する。

ドラッグのtarget選択と計算は[拘束と依存更新](../calculation/拘束と依存更新.md#3-lineドラッグのtarget選択)に従う。

操作固有の入力は[寸法コマンドの入力](../operations/拘束と寸法.md#5-寸法コマンドの入力)を参照する。

操作固有の入力は[Offsetのチェーン選択](../operations/作図と形状編集.md#3-offsetのチェーン選択)を参照する。

Sketch TreeのConstraint分類には拘束寸法と参照寸法を表示し、各rowの先頭へ`d1:`のようにParameter名を表示する。参照寸法には読み取り専用であることを表示する。

### Canvas右クリックメニュー

Canvas上で右clickした場合はbrowser標準menuを抑止し、pointer位置を基準とするJot2Dのcontext menuをCanvas領域内に収めて表示する。右click自体ではdragや作図を開始しない。pointer位置の選択候補が1件の場合はそのObjectを選択してCanvasとPropertiesへ同期するが、現在の複数Selectionに含まれるObjectを右clickした場合は複数Selectionを維持する。非アクティブSketchおよび非表示Objectはcontext menuの選択対象にしない。

pointer位置に2件以上のObjectが重なる場合は、Object固有操作の代わりにcontext menu先頭から「選択候補」を一覧表示し、右clickした時点ではSelectionを変更しない。候補はPoint、Arc endpoint、Line、Circle、Arc、Spline、Constraint Dimension、Annotation（Free Text／Leader）、Block、派生Geometry Instance、Hatchを対象とする。

Block Definition内から投影されたGeometry、Annotation、Hatchは個別候補にせず、配置先の最上位Blockへ1件に集約する。派生Geometryも生成Geometryごとではなく派生Geometry Instanceへ集約する。

Spline編集modeのfit point handleは親Splineと別候補にせず、fit point追加・削除のObject固有menuを直接表示する。候補順はpointerからの距離、既存の種類優先順位、同種Objectの描画順の順で決める。

各候補rowはToolbar／Sketch Treeと共通のSVG、種類、IDまたは寸法Parameter名、端点ID・Block Definition名・本文冒頭などの補助情報を表示する。rowのpointer hoverまたはkeyboard focus中はその候補だけをCanvasで一時強調し、rowから離れた場合はmenuを開く前のhover／Selection表示へ戻す。

rowをclickすると既存SelectionをそのObjectだけへ置き換え、PropertiesとSketch Treeへ同期してmenuを閉じる。上下矢印、Home、Endで候補間のfocusを移動し、EnterまたはSpaceでも候補を確定できる。

- 進行中コマンドがある場合: コマンドcancel、Undo、Redo
- Canvas空白: Paste、Undo、Redo、表示中Geometryへのfit
- Object共通: Cut、Copy、Delete、Properties表示。Line、Circle、Arc、Spline、Hatch、Block Instance、派生Geometry Instanceでは、さらに「最前面へ移動」「前面へ移動」「背面へ移動」「最背面へ移動」を表示する。対象Selectionで実行できない項目はdisabledにする
- Point: 固定／固定解除、Leader追加
- Line: 固定／固定解除、通常／補助Geometry切替、Offset、2本選択時のFillet、Leader追加、選択からBlock作成
- Circle／Arc: 通常／補助Geometry切替、Offset、Leader追加、選択からBlock作成
- Spline: 通常／補助Geometry切替、Leader追加、選択からBlock作成。専用fit point編集modeではSpline本体から通過点を追加し、fit point handleから通過点を削除する。Trim、Offset、Filletは表示しない
- Arc endpoint: 固定／固定解除
- Block: 固定／固定解除、直交回転lock／自由回転、Block Definition編集、選択からBlock作成
- Constraint Dimension: `値 / 数式`編集。参照寸法はdisabledにする
- `値 / 数式`では数値を直接入力し、数式は先頭`=`を必須とする。数式入力中のCanvas寸法clickは通常selectionの代わりに同一名前空間のParameter名をcaret位置へ挿入する
- Hatch: 境界を再指定、選択からBlock作成。Copy／Cut／Block化は全境界Geometryが同時選択されている場合だけ有効にする
- Annotation: 選択からBlock作成

各項目はToolbar、Properties、shortcutと同じ既存command経路を使用し、model変更は同じ検証、Undo/Redo、rollback規則へ従う。menuは項目実行、外側pointer操作、Esc、wheel、window resize、window focus喪失で閉じる。上下矢印、Home、Endで有効項目間のkeyboard focusを移動できる。表示文言はapplication言語へ即時対応する。

描画順の変更はアクティブSketch内だけで行い、異なるSketchのObjectを相互に前後移動しない。「前面へ移動」「背面へ移動」は同じSketchの隣接する描画Objectを1つ越える。

「最前面へ移動」「最背面へ移動」は同じSketchの端へ移す。複数選択では対象同士の相対順を維持してまとめて移動し、1回の操作を1つのUndo単位とする。

Block Instanceと派生Geometry InstanceはInstance全体を移動する。Reference Image、Point、Constraint Dimension、Annotation、操作markerはこの共通描画順の対象外とする。

## 2. Shortcut

| 操作 | shortcut |
| --- | --- |
| 上書き保存 | Ctrl+S |
| 名前を付けて保存 | Ctrl+Shift+S |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y または Ctrl+Shift+Z |
| Copy / Cut / Paste | Ctrl+C / Ctrl+X / Ctrl+V |
| Delete | Delete / Backspace |
| Constraint Status View | Spaceを押している間 |
| コマンドcancel／選択解除 | Esc |

入力欄編集中はBackspace／Deleteを含む文字入力をCanvas shortcutとして扱わない。

## 3. Geometryの選択と編集

- 単一クリック後のドラッグで Point、Line、Circle、Arc、Arc 端点、Spline全体を編集する。Splineのfit pointは専用編集mode中だけ表示・dragする。
- Arc本体のhover／選択では端点ハンドルを表示しない。Arc端点を直接hover、選択、ドラッグしている場合だけ対象端点の操作ハンドルを表示する。
- Shift/Ctrl クリックで加算・解除選択する。
- 左から右の矩形選択は完全包含、右から左は交差選択とする。
- 選択 Geometry はコピー、切り取り、貼り付けできる。
- 貼り付け先は現在のアクティブ Sketch で、繰り返すごとに画面上24px相当ずつずらす。
- コピー範囲内で閉じる拘束を複製する。範囲外への拘束は複製しない。
- Block Instance は、内部で閉じる外部拘束とともにコピーできる。
- 同じParameter名前空間へ寸法をコピーすると新しい`dN`を付与し、同時にコピーした寸法間の参照だけを新しい名前へトークン単位で書き換える。
- 別のParameter名前空間へコピーすると、拘束寸法式をコピー時点の評価値による数値式へ固定して新しい`dN`を付与する。
- HatchのCopy／Cut／PasteとBlock化は参照する全境界Geometryの同時選択を必須とし、不足時は操作全体を拒否する。Pasteでは境界GeometryRefを新IDへ書き換える。
- 派生Instanceの生成Geometryはsnap、拘束、寸法、Hatch、Leaderに使用できる。通常選択は全体から内部Geometryへの段階選択、拘束・寸法コマンドでは生成Geometry単位とする。スケッチ投影の生成Geometryは所属する子Sketch内の通常Geometryと通常拘束でき、先祖Sketchの参照元は読取専用の入力として扱う。同一Sketch内で完結するミラー／直線パターン／自由配置の生成Geometryは、形状dragを派生変換で逆変換して最終的な参照元Geometryの通常dragとして処理し、参照元の拘束を維持する。スケッチ投影およびスケッチ投影を経由する派生chainは、子Sketchから先祖Sketchを変更しないため形状dragを拒否する。自由配置・ミラー・直線パターンでは未選択Instanceの最初の押下・ドラッグで全体を選択・移動し、同じInstanceの次の押下・ドラッグで内部Geometryを選択・形状編集する。内部選択中は同じInstance内を続けて編集でき、別Instanceは全体選択から始める。Tree行は全体選択に戻す。全体移動は共有形状と関係を保ち、未固定の軸・方向Lineも拘束に従って間接的に動かせる。回転と鏡像はPropertiesで変更する。trim、fillet、通過Point追加・削除などのSpline構造編集、固定、通常／補助作図切替は派生側で拒否する。AppearanceはInstanceの上書きとして編集できる。
