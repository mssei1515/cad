# コマンドパネル

## 表示と終了

Canvas右上に小さなフローティングパネルを表示する。通常時は非表示とし、対応コマンドの開始時に開き、完了・取消・他コマンドへの切替時に閉じる。連続作成する塗りつぶしは完了後に空の領域リストへ戻り、パネルを開いたまま次の作成を受け付ける。パネルはCanvasへの入力を遮らず、パネル自身のボタンや入力欄を操作してもCanvasの選択・配置を行わない。外観はアプリの言語とテーマに従う。

コマンド名、現在の選択対象一覧と件数、次に必要な操作、コマンド固有の設定、完了・キャンセル操作を表示する。Geometryの対象一覧には所属Sketch名とGeometry IDを表示する。塗りつぶしでは選択した領域の番号と面積（mm²）を表示し、合計面積も示す。未選択や設定不正の場合は完了を無効にし、必要な操作・設定条件を案内する。

## 対応コマンド

| コマンド | 選択・状態 | 設定と完了 |
| --- | --- | --- |
| 注記・引出線追加 | 本文と配置状態。引出線追加では参照Geometryを仮指定 | 新規は引出線有無と複数行本文。本文と必要な配置が揃ったら完了／CanvasのEnterで1件確定し終了。本文欄のEnterは改行、Escは取消 |
| 塗りつぶし・境界再指定 | 選択した閉領域のリスト、各面積・件数・合計面積 | clickで追加・解除、リスト選択で強調、Delete／Backspaceで解除。1領域以上を選び、完了／Enterで全領域を1つの塗りつぶしとして確定 |
| スケッチ投影 | 仮選択した投影対象と件数、投影先Sketch | 対象を1件以上選択し、完了／Enter／既存の右クリック「実行」で確定 |
| ミラー投影 | 仮選択した複写元一覧と件数、対称軸の選択状態 | 軸線クリックは仮選択。別の線へ変更可能。完了／Enterで生成 |
| 直線パターン | 仮選択した複写元一覧と件数、方向線の選択状態 | 間隔(mm)、元を除くコピー数、方向反転。方向線を選択後、完了／Enterで生成 |
| 同期インスタンス | 複写元一覧と件数、配置基準点・配置先の独立した入力 | 開始直後から角度・左右反転・上下反転を編集。必要な入力が揃ったら完了／Enterで生成 |
| 派生インスタンスの対象図形編集 | 編集対象Instance ID、仮選択した参照元一覧と件数 | 1件以上を選択し、完了／Enterで確定 |

ミラー／直線パターン／同期インスタンスは未選択でも開始でき、事前選択があれば複写元に引き継ぐ。複写元・基準線・配置基準点・配置先・設定は固定順序を設けず、いつでも指定・変更できる。各入力は枠付きのリストボックスとし、空の場合も「クリックして指定」を表示する。リストボックス内・対象行を直接クリックしてCanvasの入力先を切り替える。直上の項目名と件数は単純なラベルとし、選択操作や選択状態の強調は持たない。入力先の強調はリストボックスの枠で表す。専用の「変更」ボタンは設けない。事前選択なしでは複写元、有りでは基準線（同期インスタンスは配置基準点）を初期入力先とする。スケッチ投影は適格な先祖Sketchの事前選択を引き継ぐ。

対象行はクリックまたはEnter／Spaceで選択し、上下矢印とHome／Endでも移動・選択できる。その対象をCanvasで強調する。Delete／Backspaceでその仮選択だけを解除し、元図形は削除しない。複写元はCanvasの再クリックでも追加・解除できる。基準線や配置点の解除後は必要な入力が揃うまで完了を無効にする。他の入力・設定は保持する。塗りつぶし・境界再指定では対象行やリストにフォーカスしたEnterも完了とする。その他のコマンドでは対象行にフォーカスしたEnterは行選択、Canvasまたは設定欄のEnterは完了とする。設定欄のDelete／Backspaceは通常の文字編集に用いる。

直線パターンの初期値は間隔10mm、コピー数2、方向反転OFF。間隔は有限の正数、コピー数は1〜1000の整数とする。入力ダイアログは使用せず、設定不正では生成しない。

同期インスタンスの設定はPropertiesと同じ作成途中のInstanceへ反映し、Canvasプレビューにも反映する。配置点の指定・スナップ・Propertiesからの編集を維持する。キャンセルは作成途中のInstanceを破棄する。

パネルのキャンセルとEscは確定前の選択・設定を破棄し、保存データや履歴を追加しない。対象図形編集の取消では既存Instanceを再選択する。入力欄にフォーカスがある場合もEscで取消できる。入力欄のEnterは現在値を反映してから、実行可能な完了操作を行う。複数行textareaのEnterは改行として扱う。

## 共通基盤

`CommandPanel`はコマンド固有のモデルを持たず、表示用state（id、title、step、selections、settings、message、actions、任意のcompleteOnEnter）とaction／setting／select／removeのcallbackを受け取る。各選択groupはkey・label・activeと表示用items（各itemはkey・label・selected）、各設定はkey・label・type・value・任意のmin／max／stepを持ち、type: textareaは複数行の即時入力に対応する。focus・caretを更新時に維持する。各actionはid・label・disabledを持つ。stateがnullの場合は閉じる。コマンド状態・選択条件・検証・確定・履歴の責任は各コマンドに残す。

`AnnotationCommandPanel`は注記作成・引出線追加の仮状態を表示し、状態と確定はAnnotationCommandが所有する。

`DerivedCommandPanel`は派生コマンドの状態を共通形式へ変換するadapterである。`HatchCommandPanel`は塗りつぶしの未確定領域リストと面積を表示し、completeOnEnterでリストのEnterによる完了を指定するadapterである。将来の作図・拘束・寸法・Blockは同じ共通stateとcallbackを提供して接続できる。仮状態やパネル自体の状態はDocumentへ保存しない。
