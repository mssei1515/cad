# コマンドパネル

## 表示と終了

Canvas右上に小さなフローティングパネルを表示する。通常時は非表示とし、対応コマンドの開始時に開き、完了・取消・他コマンドへの切替時に閉じる。パネルはCanvasへの入力を遮らず、パネル自身のボタンや入力欄を操作してもCanvasの選択・配置を行わない。外観はアプリの言語とテーマに従う。

コマンド名、現在の選択対象一覧と件数、次に必要な操作、コマンド固有の設定、完了・キャンセル操作を表示する。対象一覧には所属Sketch名とGeometry IDを表示する。未選択や設定不正の場合は完了を無効にし、必要な操作・設定条件を案内する。

## 対応コマンド

| コマンド | 選択・状態 | 設定と完了 |
| --- | --- | --- |
| スケッチ投影 | 仮選択した投影対象と件数、投影先Sketch | 対象を1件以上選択し、完了／Enter／既存の右クリック「実行」で確定 |
| ミラー投影 | 先に選択した複写元一覧と件数、対称軸の選択状態 | 軸線クリックは仮選択。別の線へ変更可能。完了／Enterで生成 |
| 直線パターン | 先に選択した複写元一覧と件数、方向線の選択状態 | 間隔(mm)、元を除くコピー数、方向反転。方向線を選択後、完了／Enterで生成 |
| 同期インスタンス | 複写元一覧と件数、配置基準点指定／配置先指定の段階 | 配置先指定中に角度・左右反転・上下反転を編集。Canvasの配置先クリックで完了。パネルの完了欄にもこの操作を表示 |
| 派生インスタンスの対象図形編集 | 編集対象Instance ID、仮選択した参照元一覧と件数 | 1件以上を選択し、完了／Enterで確定 |

ミラー／直線パターン／同期インスタンスの複写元は既存どおりコマンド開始前に選択する。作成途中に複写元を変更する操作は設けない。複写元と選択済み基準線をCanvasで強調する。スケッチ投影と対象図形編集では既存の仮選択の強調を維持する。

直線パターンの初期値は間隔10mm、コピー数2、方向反転OFF。間隔は有限の正数、コピー数は1〜1000の整数とする。入力ダイアログは使用せず、設定不正では生成しない。

同期インスタンスの設定はPropertiesと同じ作成途中のInstanceへ反映し、Canvasプレビューにも反映する。配置点の指定・スナップ・Propertiesからの編集を維持する。キャンセルは作成途中のInstanceを破棄する。

パネルのキャンセルとEscは確定前の選択・設定を破棄し、保存データや履歴を追加しない。対象図形編集の取消では既存Instanceを再選択する。入力欄にフォーカスがある場合もEscで取消できる。入力欄のEnterは現在値を反映してから、実行可能な完了操作を行う。

## 共通基盤

`CommandPanel`はコマンド固有のモデルを持たず、表示用state（id、title、step、selections、settings、message、actions）とaction／settingのcallbackを受け取る。各選択groupはlabelと表示用items、各設定はkey・label・type・value・任意のmin／max／step、各actionはid・label・disabledを持つ。stateがnullの場合は閉じる。コマンド状態・選択条件・検証・確定・履歴の責任は各コマンドに残す。

`DerivedCommandPanel`は派生コマンドの状態を共通形式へ変換するadapterである。将来の作図・拘束・寸法・Blockは同じ共通stateとcallbackを提供して接続できる。仮状態やパネル自体の状態はDocumentへ保存しない。
