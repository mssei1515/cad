# 表示とビュー操作

[画面構成](./画面構成.md)・[入力と操作状態](./入力と操作状態.md)・[表示とビュー操作](./表示とビュー操作.md)を目的に応じて参照する。機能固有の操作は[仕様の入口](../README.md)から読む。

共通の外観規則は[外観](../contracts/外観.md)、Objectの編集可否は[所属と編集可否](../contracts/所属と編集可否.md)を参照する。

## 1. ビュー操作とpointer処理

wheelでzoom、middle dragでpan、middle double clickで表示中Geometryへfitする。表示倍率100%はDocumentの1mmを`96 / 25.4` CSS pxで描くCSS基準の概算実寸であり、wheel操作後はこの基準に対する百分率をStatus BarのHintへ表示する。

wheelではpointer下の位置を動かさない。背景Gridは描画せず、Geometry IDはViewメニューから切り替える。

Canvas内では選択、作図、drag、panを含むすべての状態でbrowser native custom cursorを使用し、Canvas再描画と独立したOS cursor経路で高速なpointer移動へ追従させる。pointer矢印は約18px高のcompactな共通形状とし、輪郭線は0.8pxの細線とする。

状態遷移時にも矢印のhotspotと大きさを変えない。選択以外の継続中commandでは、この矢印へ対応するToolbar buttonのSVG icon badgeを一体化する。

対象はGeometry作図・編集、拘束・寸法入力、Annotation配置、Block配置、Spline fit point編集とし、補助線切替や固定など即時完了するtoggleは対象外とする。iconはToolbarの通常iconと同じ色・線幅による18px表示とし、Toolbar surfaceと同じ明色背景、境界線、角丸を持つ22px badge内へ配置する。

影は付けない。custom cursorはCanvas領域だけで使用し、pan中やdrag中も別のcursorへ切り替えない。

Canvasの高頻度なpointer moveは、未処理の最新位置だけを保持し、animation frameごとに最大1回だけhit test、drag用local solve、依存Sketch solve、Canvas再描画および座標表示更新を行う。同一frame内に複数のmoveが到着した場合は途中位置を省略するが、pointer down、pointer up、pointer cancel、double click、wheelの処理前には保留位置を同期的に反映し、選択開始位置、drag終了位置およびzoom基準位置を失わない。

1回の入力処理と再描画では、Block Projectionを含む全Geometry一覧と解決済みAppearanceを一時cacheしてhit testと描画の間で再利用する。Canvas bitmap寸法はresize時に更新し、通常の再描画ではlayout測定を繰り返さない。

Sketch Tree／PropertiesのSelection class更新はCanvas再描画から分離し、SelectionまたはUI再構築時だけ行う。

## 2. 単一Canvas

Geometry、Constraint Dimension、Sketch所属Annotation、Sketch所属Hatch、Sketch所属Reference Imageは同じCanvasに描画する。表示専用モードおよびSheetは存在しない。

Reference Imageを背面へ描画し、その上で同じSketchに属するLine、Circle、Arc、Spline、Hatch、Block Instance、派生Geometry Instanceを共通の重なり順で描画する。寸法、Annotation、選択輪郭、操作markerなどの注記・操作表示は共通の重なり順より手前へ描画する。

### 1.1 モデル単位と表示倍率

Documentのモデル長さはmmであり、`viewport.scale`は1mmを何CSS pxで描くかを表す。表示倍率100%は`96 / 25.4 CSS px/mm`とし、25.4mmを96 CSS pxで描くCSS基準の概算実寸とする。画面座標は`screen = world(mm) × viewport.scale + viewport offset(CSS px)`で変換する。`devicePixelRatio`はCanvas bitmapの解像度補正にだけ使用し、表示倍率へ含めない。

表示倍率の百分率は`viewport.scale / (96 / 25.4) × 100`で求める。wheelではpointer下のworld位置を維持したまま連続的に拡大・縮小し、範囲は0.1%～1,000,000,000%とする。起動時および空のBlock Editorは100%から開始する。モニターの画素密度やOS倍率を物理計測して校正しないため、100%は物理的な実寸を保証しない。

GeometryとReference Imageのモデル寸法は表示倍率に比例して画面上で拡大・縮小する。線幅、dash、操作marker、hit test／snap距離、Geometry IDなど画面px基準の要素と、Dimension Appearance、Annotation、Hatch間隔の画面上の概算mmは`viewport.scale`を相殺して画面上の大きさを維持する。`viewport`はView Stateであり、Document保存およびUndo／Redoには含めない。

## 3. Constraint Status View

ToolbarのView buttonを有効にしている間、またはSpaceを押している間は次を行う。

- Geometryを完全拘束、支持位置拘束、未拘束、矛盾の状態色で描く。
- 非表示Geometryを含めて表示する。
- Dimension AppearanceのVisibleがfalseの寸法も含め、表示中Sketchに属するすべての寸法を表示する。
- 非アクティブSketchの寸法は、非アクティブGeometryと同じ灰色`#cbd5e1`で描く。アクティブSketchの寸法は設定済みのDimension Appearance色を維持する。
- explicit Pointや中心Pointなど、状態確認に必要なPointを表示する。
- Line endpointの操作用の丸markerは通常は表示せず、アクティブSketchの端点をCanvas上で直接hoverしている間だけ通常表示と同じhover markerを表示する。補助Lineの外観設定による端部点は[初期値と補助Lineの端部](../contracts/外観.md#初期値と補助lineの端部)の`endpointMarkers`に従い、Constraint Status Viewでも表示する。

Toolbar buttonまたはView menuのcheckboxは、clickごとに固定表示を切り替え、両者のON/OFF表示を同期する。Spaceは押下中だけの一時表示であり、固定状態とは独立する。Space押下中もToolbar buttonとView menu checkboxは実際の表示状態をONとして示す。固定表示中にSpaceを押して離しても表示を維持する。windowがfocusを失った場合はSpace由来の一時表示だけを解除する。View Stateだけを変更し、Document、履歴、Selectionは変更しない。

## 4. View State

View StateはDocumentと分離し、少なくとも次を持つ。

- Geometry ID表示
- Constraint Status View

背景Gridは表示しない。Geometry IDはViewメニューで切り替える。Geometryを直接選択・hoverしたときは対象IDを補助表示できるが、Sketch treeのSketch hoverではGeometry IDを表示しない。Block Instance全体の選択・hoverだけでも内部ProjectionのGeometry IDを一括表示しない。Geometry IDとConstraint Status Viewは保存・Undo/Redo対象外である。

## 5. 数値表示

- 拘束寸法は `1e-6` 以内の浮動小数誤差を簡潔な10進値へ正規化する。
- 読み取り専用寸法は実測値のため `1e-5` を使う。
- ゼロではない値をゼロへ丸めない。
- 小数部がゼロなら整数表示し、末尾の不要なゼロを除く。
- 角度ラベルには `°` を付ける。
- 寸法テキストは象限に応じ、上下反転しない JIS 読み方向へ調整する。

Documentは`units: { length: "mm" }`を持ち、Geometry座標、半径、長さ拘束、距離拘束および参照寸法の長さ値をmmとして保存・計算する。Canvas上の寸法ラベルは従来どおり数値だけを表示し、単位文字列を自動付加しない。角度寸法の値は度とする。
