# 画面構成

[画面構成](./画面構成.md)・[入力と操作状態](./入力と操作状態.md)・[表示とビュー操作](./表示とビュー操作.md)を目的に応じて参照する。機能固有の操作は[仕様の入口](../README.md)から読む。

共通の外観規則は[外観](../contracts/外観.md)、Objectの編集可否は[所属と編集可否](../contracts/所属と編集可否.md)を参照する。

## 1. 固定レイアウト

画面は次の領域で構成する。

1. Menu Bar
2. Toolbar
3. Canvas
4. 右Properties
5. 下Status Bar

左Explorer、3tab、Explorer最小化buttonは持たず、Canvasをworkspace左端まで拡張する。Propertiesは独立してscrollし、title barの矢印buttonで36pxのrailまで最小化でき、同じbuttonで復元する。

Canvasは残り領域を使用し、Properties幅が変わっても表示中心を維持する。ライトテーマの通常Canvasは真っ白なUI部品とわずかに区別できる薄い青みの白`#fcfdff`、Block Editor中は淡い青`#f3f7ff`とする。

ダークテーマでは通常Canvasを`#0f172a`、Block Editor中を`#111c30`とする。

Sketch TreeはCanvas左上へ背景透過で常時表示する。Block Editorでも同じ位置と操作を再利用し、編集中Definitionの内部Sketch Treeへ切り替える。

起動時はRoot Sketchと、その直下の作図可能な`Sketch-1`だけを持つ空の新規Documentを開く。`Sketch-1`をactiveにし、Geometry、Constraint、Block、Annotation、Hatch、Reference Image、Parameterは作成しない。起動用のsample Geometryは表示しない。

### 1.1 配色

application UIはライト／ダークのcolor schemeを持ち、Jot2Dのbrand colorである濃い青と、青みを持つneutral colorを基調とする。青はbrand、選択、focus、編集対象に使用し、灰色は通常surface、読み取り中心の情報、境界の分離に使用する。errorまたは破壊的操作を除き、役割のない別系統の色相を追加しない。Menu Barはテーマにかかわらず現行brand colorの`#1e3a5f`を維持する。

隣り合う通常surfaceは同系統の明度差で分離し、必要な箇所だけ`border`または`strong border`を併用する。ライトテーマのPropertiesでは外側`#f4f7fb`、基本情報`#f8fafc`、編集区分`#f2f8ff`の順で役割を区別する。

Block Editorは紫系など別色相へ切り替えず、各テーマの通常Canvasより青みの強い背景で編集状態を示す。ライトテーマのBlock Editor overlayには`rgba(239, 246, 255, 0.95)`、境界には`#93c5fd`、影には`rgba(30, 64, 175, 0.14)`を使用する。

Canvas上のGeometry、Constraint、Dimension、Hatch、Annotation等が保持するDocument Appearance colorは、テーマ切替で書き換えず、保存JSONにも影響させない。ダークテーマのCanvasでHEX色と背景`#0f172a`のcontrastが4.5:1未満になる場合だけ、描画時に同じ色を白方向へ混合し、4.5:1以上となる最初の色へ表示上だけ補正する。ライトテーマでは保存色をそのまま描画する。

通常サイズの文字は背景に対して原則4.5:1以上のcontrastを確保する。muted文字`#5f6f86`は最も近いeditable surface`#f2f8ff`上でもこの基準を満たす。hover、選択、focus、error等の状態は色だけに依存せず、背景、境界、outline、accent、iconまたはbadgeを組み合わせて識別可能にする。

## 2. Menu Bar

Menu Bar左端には背景を透過したJot2D SVGロゴを108×24pxの表示枠へ縦横比を維持して全体が収まるように表示し、ファイル名は画面上へ表示しない。38pxのMenu Bar内では上下7pxの余白を確保する。

背景色はテーマにかかわらず青系の`#1e3a5f`とし、ライトテーマではStatus Barも同色とする。Menu Barはファイル、編集、表示、Geometry、Block、Constraint、Annotation、ヘルプを持つ。

View menuにはGeometry IDとConstraint Status Viewのcheckboxを表示し、Constraint Status ViewはToolbar buttonおよびSpaceによる実際の表示状態と同期する。Geometry menuのcommandは1列で表示し、2段組にしない。

File menuは`.jot2d`の開く、上書き保存、名前を付けて保存、およびParameter画面を開くcommandを持つ。Block menuはToolbarと共通のBlock作成command、およびBlock Definitions管理画面を開くcommandを持つ。

Help menuは、実行中branch名と12桁の短縮commit IDを`branch@commit`形式で表示し、working treeに未commit変更がある場合は「変更あり」／`dirty`を付記する。commit ID全体はtooltipで確認できる。

`file:` URLではGit状態から生成したGit管理外の`runtime-version.js`を読み込み、HTTP配信ではserverが同じ形式のscriptを動的に返す。`file:` URLを含む各起動では、読み込むJavaScriptへ起動ごとに異なるqueryを付け、ブラウザに残った旧scriptや旧commit情報を再利用しない。

commit情報を取得できない場合は取得不能であることを表示する。Document設定、Application設定、Parameterは別画面として開く。

開く・保存のpicker、現在の保存先、取消時の扱いは[ファイル操作](../operations/ファイル操作.md)に従う。

menuは同時に1つだけ開く。すべて閉じている状態ではhoverだけで開かず、clickで開く。

1つのmenuが開いている間は、別のmenu summaryへのmouse／pen hoverから1 frame相当（16ms）で先のmenuを閉じてhover先へ切り替え、focusもそのsummaryへ移す。touchではhover切替を行わない。

別のmenuのclick、Menu Bar外のpointer操作、menu commandの実行、Esc、windowのfocus喪失でも先に開いていたmenuを閉じる。Escでmenuを閉じた場合はそのsummaryへfocusを戻し、同じkey操作でCanvas commandのcancelやSelection解除までは行わない。

- Root以外のSketch Propertiesは、Document設定と同じ3つの外観区分を`一般外観`／`General Appearance`、`補助線外観`／`Construction Appearance`、`寸法外観`／`Dimension Appearance`と表示する。各区分は個別に折り畳み可能で、初期状態ではすべて閉じる。ユーザーが開閉した後はPropertiesの再描画やSketch切替後もsession中の状態を維持する。各区分の未設定fieldは対応するDocument設定を直接継承し、補助線外観は一般外観を経由しない。補助線外観ではvisible、color、lineType、lineWidth、端部のはみ出し、端部の点を設定できる。寸法外観ではvisible、color、lineWidth、precision、prefix、suffixに加え、寸法補助線の突出量・起点すき間、端末記号の種類・サイズ・矢印系の開き角、寸法文字の高さ・寸法線との間隔を設定でき、そのSketch自身の個別上書きのない対象へ即時反映する。長さ系入力には`mm`、開き角には`°`を表示し、線幅は画面px単位とする。Root SketchおよびBlock Definition内のRoot Sketchには外観区分を表示しない。
継承経路は[外観](../contracts/外観.md)のAPP-01／02／05に従い、未設定欄は日本語で`既定 (継承値)`、英語で`Default (inherited value)`を表示する。

- Document設定は一般外観、補助線外観、寸法外観を編集するmodal画面とし、すべての通常SketchおよびBlock Definition内Sketchに対する既定値を設定する。Document設定の変更は即時反映し、Undo/Redo対象とする。寸法外観内の3groupはPropertiesと共通のフラットな小見出しと水平区切り線で階層を示し、groupごとの枠、角丸、背景塗りは使用しない。
- Application設定はDocument設定から独立したapplication viewであり、言語を日本語／English、表示テーマをライト／ダークから選択する。初回既定値は日本語およびライトとし、選択値はbrowserのapplication-local storageへ保存して次回起動時にも適用する。言語と表示テーマはDocument JSON、Undo/Redo履歴へ含めない。
- 表示テーマ切替はToolbar、Canvas、Sketch Tree、Properties、各menu popover、Settings、Status Barを含むapplication UIへ即時反映する。ただしMenu Barの背景、文字、hover、focus色はテーマ切替の対象外とし、常に同じbrand配色を使用する。
- 言語切替はMenu、Toolbar、Sketch Tree、Properties、Settings、Status Bar、標準操作Hintを含むapplication UI全体へ即時反映する。Sketch PropertiesおよびDocument設定に動的生成する3区分のAppearance項目名と選択肢にも、現在のapplication言語を適用する。Document名、Sketch名、Block名、Annotation本文などのユーザーデータは翻訳しない。

## 3. Toolbar

ミラーと直線パターンはGeometry menuとToolbarの同じcommandとして配置し、対称形状および等間隔コピーを表す専用iconを使用する。

Toolbarは上書き保存／開く、Undo/Redo/Delete、選択、Geometry作図・編集（円弧とは別の3点円弧、長穴、スケッチ投影、中心線、円中心十字線、ハッチングを含む）、Block作成、Constraint、Annotation、画像を読み込み、Viewの各コマンドを横方向に配置する。「3点円弧」は円弧上の3点を示す専用iconを使用し、Geometry menuとGeometry groupの同じcommandを使用する。

「長穴」はGeometry menuとGeometry groupに独立commandとして置き、丸端の外形と2つの半円中心を示すiconを使用する。「画像を読み込み」はAnnotation menuとAnnotation groupの同じcommandを使用する。

「スケッチ投影」はGeometry menuとGeometry groupの同じcommandを使用し、上側の破線形状、3本の下向き投影線、下側の実線形状からなる製図投影iconを使用する。中心線buttonは、短い2本の縦実線の間を縦の一点鎖線が上下へ越えるiconとし、Sketch Treeの中心線行とcommand cursorでも同じSVGを使用する。

円中心十字線buttonはCircleの上下左右へ一点鎖線が越えるiconを使用する。ViewにはConstraint Status Viewの固定切替buttonを置き、目の輪郭と完全拘束／支持位置拘束／未拘束／矛盾の4状態色を並べたiconで表示する。

上書き保存／開くはFile menuからも同じcommandを実行できる。各command buttonは従来のSVG iconを使用するicon-only表示とし、tooltipとaccessible nameで名称を提示する。

File、View、Geometry、Block、Constraint、Annotation等のToolbar group見出しは表示しない。

Block作成buttonは1つだけ配置する。アクティブSketch内のGeometryまたはBlock Instanceが選択されていれば選択内容からDefinitionを作成し、選択がなければ空Definitionを作成する。どちらも同じBlock Editorを開く。

## 4. Sketch Tree

派生Geometryは個別Geometry分類へ表示せず、BlockとConstraintの間に「派生インスタンス」分類を設けて1 Instanceを1 rowで表示する。

Canvas左上のSketch TreeへSketch階層とObject一覧を統合する。表示領域は初期約320px幅、最大約70vhとし、右端をmouse dragして220–560pxの範囲で横幅を変更できる。

狭いCanvasではCanvas内に収まる上限へclampし、幅はsession内だけ保持してJSONとUndo/Redoへ含めない。handleは左右矢印keyでも16px単位で変更でき、Home／Endで最小／最大幅へ移動する。

surface、border、角丸、shadow、背景blurを持たない完全透過表示とする。header、通常のSketch・分類・Object・拘束状態集計rowも背景を透過し、hover、選択、active、error等の操作・状態を示す一時背景だけを表示する。

Block Editorでは同じ位置と操作を再利用し、編集中Definitionの内部Sketch Treeへ切り替える。

Objectを持つactive Sketch rowはchevronまたはrow本体のclickで開閉でき、閉じた場合はそのSketch直下の図形・拘束等の分類とObject rowだけを隠す。非active Sketchのrow本体をclickした場合は、そのSketchを表示してactive化するだけで開閉状態を維持し、active化後の次のrow clickから開閉する。

表示、名前変更、削除buttonは固有の操作だけを行い、rowの開閉を発生させない。子Sketchおよびその子孫のSketch rowは親Sketchの開閉状態にかかわらず常に表示し、Sketch階層全体を確認できる状態を保つ。

Root SketchなどObject分類を持たないSketchは開閉buttonを表示しないが、行頭が空白に見えないように同じ位置へ薄い無効状態の`▼`を表示する。Objectを持たないrow本体のclickはactive化だけを行う。

Root以外のSketchは分類を初期折り畳みとし、起動直後は全階層のSketch名を確認できる一方で図形や拘束の分類を表示しない。入れ子Sketchの作成、Object rowやCanvas操作によるactive化では、各Sketchの開閉状態を変更しない。

各Root以外のSketch直下へ、存在する分類だけをPoint、Line、Circle、Arc、Spline、Hatch、Image、Block、派生インスタンス、Constraint、Annotationの順に置き、その後に子Sketchを置く。空分類はDOMにも生成しない。

Pointにはexplicit PointとLine端点を含めるが、Circle／Arc中心はexplicit PointまたはLine端点でもある場合だけ重複表示する。SplineにはそのSketchに所属するSplineを表示する。

HatchにはそのSketchに所属するハッチだけを表示する。ImageにはそのSketchに所属するReference Imageを表示する。

Blockには配置先のInstanceだけを表示し、Projection内部Objectはホスト側で個別表示しない。派生インスタンスには投影、ミラー、直線パターンの派生Instanceを表示し、仮想出力は個別表示しない。

Block EditorではDefinition内部Objectを表示する。Constraintには通常拘束、拘束寸法、参照寸法、固定Pointを含める。

展開時の先頭にはSketch別の拘束状態集計をObject rowと同じ22pxの枝付き補助rowとして置き、完全、支持、未拘束、矛盾を状態色のdotと件数でcompactに表示する。完全な名称と件数はtooltipで表示する。

分類もすべて初期折り畳みとする。Sketch rowの開閉状態はDocumentまたはBlock DefinitionとSketch ID、分類の開閉状態はそれらに分類を加えた組み合わせでsession中だけ記憶し、JSONとUndo/Redoへ含めない。

Sketch rowを閉じて再び開いた場合は、配下の分類ごとの開閉状態を維持する。ファイル読込時は全Sketch rowを表示し、Root以外のSketch rowと全分類を閉じる。

閉じたSketchではそのSketch自身の分類とObject rowを生成しないが、子Sketch rowの生成は継続する。閉じた分類ではObject rowを生成しない。

閉じた分類が選択またはhover対象を含む場合は分類見出しを薄い青と左accentで通知する。Canvas選択によるSketchまたは分類の自動展開は行わない。

既存の18px tree cell、縦線、tee／elbow枝線を分類・Object rowまで連続させ、枝線領域の実幅とcontent開始位置を階層ごとの18px indentへ揃える。末端elbowの縦線は横線との交点で終端し、下方向へはみ出させない。

Sketch rowは約19px、分類rowは約20px、Object rowは約22pxとする。Rootを含むすべてのSketch rowは、枝線領域の直後かつSketch名の直前に、重なった作図面を表す13pxの線画iconを表示してObject rowと明確に区別する。

Sketchの開閉表示には10px幅、分類の開閉表示には12px幅の専用列を設け、muted色・7pxの小さい塗りつぶし`▶`／`▼`を配置する。Sketch行のchevronは専用列の中央へ配置して左右の余白をほぼ均等にし、Sketch名buttonには追加の左余白を設けない。

分類rowはchevron、分類名、件数pillを持つ。Object rowはToolbar buttonからcloneした14px SVG、主表示、補助表示、意味のある状態badge、操作領域の1行構成とし、長い文字列は省略してtooltipへ全文を表示する。

- Line: ID、始点–終点ID、リンク中の投影badge
- Circle／Arc: ID、中心ID、半径、リンク中の投影badge
- Spline: ID、fit point数、開／閉、リンク中の投影badge
- Hatch: ID、pattern種類（平行線／クロス／塗りつぶし）、無効時の境界error badge
- Image: ID、名前、pixel寸法、非表示・位置ロックbadge
- Block: Instance ID、Definition名
- Constraint: Parameter名、localize済み拘束名
- Instance: 投影／ミラー／直線パターンの種類、ID、参照状態。生成Geometryは個別行にしない
- Annotation: ID、種類、本文冒頭

Point、Line、Circle、Arc、Spline、Hatch、Image、Block、Leader、Textは対応するToolbar作成buttonと同じSVGを使う。Free Textは枠内の`A`と文字列を表すテキストボックス型SVGとし、単独の`T`は使用しない。

Constraintは寸法、一致、水平、垂直、平行、直角、対称、同心、等寸、接線、固定を種類別のToolbar SVGへ対応させ、派生拘束は同じ操作系iconを使う。補助、固定、読み取り専用、重複、参照エラーなど意味のある状態だけを小さいbadgeで表示する。

Geometry／Constraint rowの削除と固定解除buttonは右端に維持し、Hatch／Image／Block／Annotationは選択後にToolbar Deleteを使う。

通常clickは選択を置換し、Ctrl／Shift clickは同じSketch内のGeometry、Block、Annotation、Reference Imageを加算／解除する。Constraintは単一選択とする。

非アクティブSketchのObject rowをclickすると、対象Sketchを表示してactive化してから対象を選択し、PropertiesとCanvasへ同期する。hoverだけでは非アクティブObjectをCanvas強調しない。

ObjectはSketch別に1回だけ索引化し、event handlingは`#sketchList`のdelegationで行う。

Block DefinitionsはBlock menuからmodal windowを開き、配置、編集、名前変更、削除を行う。Definition作成はToolbarまたはBlock menuの共通commandから行う。Block配置中の回転モードと表示内部SketchはPropertiesへ表示し、開始時にPropertiesを一時展開し、完了またはキャンセル時に元の開閉状態へ戻す。

tree全体のHide／Show buttonは設けない。

Root Sketchのrowをhoverした場合は、Root配下の表示中Sketchに属するGeometryとBlock Projectionをすべて、通常のSketch Tree hoverと同じ規則で強調する。Line endpointおよびBlock ProjectionのPoint markerは追加表示しない。

## 5. Properties

Propertiesは現在のSelectionを表示・編集する。Sketch TreeのObject rowとCanvasのどちらで選択しても直ちに同じ対象へ同期し、未選択時はactive Sketchを表示する。

全体のpanel余白、section間隔、行高、入力欄、選択肢およびColor buttonは、情報量を保ちながら縦方向をcompactに配置する。ライトテーマではProperties全体を淡い青みのグレー`#f4f7fb`、`基本情報`を淡い灰色`#f8fafc`、`外観`、`内容`等の編集区分を淡い青色`#f2f8ff`とし、ダークテーマではそれぞれ`#0b1220`、`#111827`、`#15243a`とする。

補助説明、読み取り専用値、単位等のmuted文字にはライトテーマで`#5f6f86`、ダークテーマで`#9aacbf`を使用し、編集区分上でも通常文字として十分なcontrastを確保する。単一ObjectまたはSketchの枠外見出しは種類だけを表示し、IDまたは名前を併記しない。

全対象の第一区分見出しは`基本情報`／`Basic Information`に統一する。各行は項目名を必ず持ち、Constraintを除く単一Objectには`種類`と`ID`を表示する。

Geometryにはその形状を定義するPoint ID、中心Point ID、半径、角度等を表示する。Constraintには、その拘束が直接参照しているPoint、Line、Circle、Arc等のGeometry IDを役割ごとに表示する。

選択によってPropertiesを再描画した場合も、section見出しと項目名には現在のapplication言語を適用し、選択操作によって英語表記へ戻さない。Appearanceの部分プロパティが未設定の場合は、入力欄または選択肢にapplication言語が日本語なら`既定 (継承値)`、英語なら`Default (inherited value)`を表示する。

空文字を継承する場合は`既定 (空)`／`Default (Empty)`とする。ColorはHEX文字列入力と、色buttonから開くJot2DのColor Palette modalの両方から設定できる。

Propertiesの文字列・数値入力は、入力途中の値が有効になった時点でmodelとCanvasへ即時反映する。空欄によるAppearance継承も即時反映し、無効な数値や未完成のHEX色はCanvasへ適用しない。

入力中は履歴を増やさず、change確定時に一連の入力を1回のUndo単位として記録する。Parameter名と`値 / 数式`は検証および拘束再計算を伴うため、従来どおり確定時に反映する。

Appearance区分の見出しは対象を明示し、Pointは`点の外観`／`Point Appearance`、Lineは`線の外観`／`Line Appearance`、Circleは`円の外観`／`Circle Appearance`、Arcは`円弧の外観`／`Arc Appearance`、Splineは`スプラインの外観`／`Spline Appearance`、Constraint Dimensionは`寸法外観`／`Dimension Appearance`、Hatchは`ハッチング外観`／`Hatching Appearance`、Blockは`ブロック外観の上書き`／`Block Appearance Override`、Leaderは`引出線の外観`／`Leader Appearance`、Free Textは`自由テキストの外観`／`Free Text Appearance`、複数選択は`共通外観`／`Common Appearance`と表示する。SketchはDocument設定と同じ`一般外観`、`補助線外観`、`寸法外観`を使用する。

Color Palette modalには、Jot2Dが用意する無彩色と複数色相の明色・標準色・暗色、そのDocumentで明示設定されている有効なHEX色を重複なしで集めた「このファイルで使用中の色」、任意色を選ぶOS color inputを表示する。使用色の収集対象は互換用Document Default、各Sketchの通常／補助Geometry／寸法Appearance、Geometry、Constraint Dimensionの個別Appearance、Block Definition内部の各Sketch・Geometry・Constraint Dimension、通常／入れ子Block InstanceのAppearance Override、Document／Definition Annotationのstyle colorであり、継承による実効色は追加しない。

標準色または使用色のswatch clickは対象Colorへ即時設定する。swatchのhover／keyboard focusでは枠とoutlineだけを強調し、swatchの背景色は実際の色から変更しない。

任意色は選択後に適用buttonで設定する。Color専用の「既定へ戻す」buttonは表示せず、HEX文字列入力を空にすると従来どおり上位設定を継承する。

入力欄でBackspace／Deleteを操作してもCanvas Selectionを削除しない。

- Point: 種類、ID、X／Y座標、固定状態、Appearance
- Line: 種類、ID、始点／終点Point ID、長さ、拘束状態、construction、Appearance。補助LineのAppearanceには端部のはみ出しと端部の点を表示し、各項目を所属Sketchから継承または個別上書きできる。
- Circle: 種類、ID、中心Point ID、半径、construction、Appearance
- Arc: 種類、ID、中心Point ID、半径、始点／終点角度、construction、Appearance
- Spline: 種類、ID、定義方式、次数、fit point ID列、開／閉、construction、Appearance、fit point編集mode開始button。通常modeではfit pointを表示せず、編集modeでだけhandleと補助polygonを表示する。投影中のGeometryでは参照元Sketch ID、参照元Geometry ID、投影先Geometry IDも読み取り専用で表示する。
- Sketch: 種類、ID、名前、親Sketch、active状態、Appearance
- Block: 種類、ID、Block Definition名とID、X／Y、角度、回転モード、表示する内部Sketch、Appearance Override。X／Yおよび自由回転時の角度は読み取り専用とする。直交回転ロック中の角度はPropertiesの`0°`、`90°`、`180°`、`270°`選択で変更でき、全固定中は無効にする。ユーザー向け表記は「ブロック」／`Block`とし、「ブロックインスタンス」／`Block Instance`を使用しない。選択済みBlockと新規配置中の回転モード、直交角度、表示SketchはPropertiesで編集する。
- Constraint Dimension: 型、寸法を定義するPoint／Line／Circle／Arc等のGeometry ID、Parameter名、拘束寸法では式、評価値、Appearance。Appearanceはvisible、color、lineWidth、precision、prefix、suffix、寸法補助線の突出量・起点すき間、端末記号の種類・サイズ・開き角、寸法文字の高さ・寸法線との間隔を持ち、未設定fieldは所属SketchのDefault Dimension Appearanceを継承する。UIは`寸法補助線`／`Extension lines`、`端末記号`／`Terminators`、`寸法文字`／`Dimension text`の3groupに分け、枠で囲わずフラットな小見出しと水平区切り線で表現する。端末種類は標準矢印、塗りつぶし矢印、点から選択し、点では開き角rowを表示しない。左右端は同じ設定を使い、寸法補助線と端末記号の表示切替は設けない。参照寸法の式と評価値は読み取り専用とする。
- Hatch: 種類、ID、所属Sketch、境界状態、編集可能なpattern種類（平行線／クロス／塗りつぶし）、色、表示。平行線とクロスでは角度、画面上のmm間隔、線幅も表示し、塗りつぶしでは0～100%の不透明度を表示して使用しない3項目を非表示にする。境界が無効な場合は理由と「境界を再指定」を表示する。
- Image: 種類、ID、名前、読み取り専用の所属Sketch、中心X／Y、編集可能な幅、読み取り専用の高さ、回転、不透明度、表示、位置ロック、2点から縮尺を設定。幅は縦横共通scaleを変更してpixel縦横比を維持し、位置ロック中は変換項目と縮尺設定を無効にする。
- Annotation: 「基本情報」「内容」「外観」の3区分。種類、ID、読み取り専用の所属Sketch、本文、表示、共通Color Palette、概算mmの文字高さ、フォント、太字、斜体、横位置、回転。Leaderでは線幅、線種、端末記号の種類と概算mmサイズも表示する

複数選択時は選択数と共通Propertiesを表示する。同種Objectではその種類で共通する編集可能なAppearance／状態項目を、異種Objectでは全対象が対応するAppearance項目だけを表示する。

値が一致しない項目は`混在`／`Mixed`と表示し、ユーザーが変更した項目だけを全対象へ明示値として一括適用する。ID、座標、端点などObject固有の定義情報は一括変更しない。

Geometryのconstructionは同種の非Point Geometry、補助Lineの端部設定は同種の補助Line、Hatch固有項目はHatch同士、Annotation固有項目は同じAnnotation種類を選択した場合だけ表示する。1項目の一括変更を1回のUndo単位とする。

## 6. Status Bar

Status Barは現在のコマンド、操作Hintまたはerror、Constraint集計、pointer座標を表示する。矛盾件数は通常表示でも確認できる。
