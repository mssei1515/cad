# ブロック仕様

## 1. 目的

ブロックは、独立したローカル座標系と内部スケッチを持つ再利用可能な形状定義である。

通常スケッチは引き続きグローバル座標系上の作図・拘束・配置単位とし、ブロックは通常スケッチの代替にはしない。

```text
通常スケッチ
  グローバル座標系上で形状を作る

ブロック定義
  独立したローカル座標系と内部スケッチツリーを持つ

ブロックインスタンス
  ブロック定義の一部または全部の内部スケッチを通常スケッチへ配置する
```

## 2. データ構造

CADデータは、ブロック定義とブロックインスタンスを分けて保持する。

```text
blockDefinitions[]
  id
  name
  origin { x, y }
  sketches[]
  activeSketchId
  points
  lines
  circles
  arcs
  constraints

blockInstances[]
  id
  definitionId
  sketchId
  enabledSketchIds[]
  x
  y
  rotation
  fixed
```

ブロック定義内の各図形と拘束は、必ず内部スケッチの `sketchId` を持つ。内部スケッチは定義専用の `Root Sketch -> Sketch-1` から始まり、通常スケッチと同じ親子構造、参照範囲、循環禁止、solve規則を使う。

ブロック原点は定義作成時に自動決定して固定する。ユーザーへ原点指定を要求せず、原点マーカーも表示しない。

インスタンスは移動X、移動Y、回転角だけを持ち、倍率や鏡像は持たない。ワールド座標は次式で得る。

```text
world = rotate(local, rotation) + (x, y)
```

## 3. 投影形状

インスタンスでは、`enabledSketchIds` に含まれる内部スケッチの点、線、円、円弧だけをワールド座標へ投影する。

投影形状は座標を重複保持せず、定義、インスタンス変換、有効スケッチ集合から常に導出する。安定参照IDは次の複合IDとする。

```text
instanceId@definitionElementId
```

投影形状は、表示、スナップ、拘束対象、Presentation参照の対象になる。無効な内部スケッチは投影しないが、ブロック定義内部の拘束計算からは除外しない。

## 4. 新規作成

ブロック新規作成ボタンは、原点指定を挟まず専用ブロックエディタを開く。

### 4.1 選択なしで作成

- 空のブロックエディタを開く。
- 初期名は `Block-N` とする。
- 完了時に図形外接範囲の中心を非表示原点として固定する。
- 定義だけを作成し、インスタンスは自動配置しない。

### 4.2 選択図形から作成

- アクティブスケッチ内の選択図形と、選択範囲内で完結する拘束を内部 `Sketch-1` へ取り込む。
- 原点は選択図形の外接範囲中心から自動決定する。
- 編集中は元図形を変更しない。
- 完了時だけ元図形を同位置のインスタンスへ置換する。
- キャンセル時はドラフト定義を破棄し、元図形を完全に維持する。

次の場合は、元データを変更せず作成を拒否する。

- 非選択図形と点を共有している。
- 選択範囲をまたぐ拘束がある。
- 別スケッチ参照拘束がある。
- Presentation注記から参照されている。
- 既存ブロックインスタンスを含む。

作成と元図形の置換は1回のUndo/Redo単位とする。

## 5. ブロックエディタ

ブロックエディタは、通常CADと区別できる淡い青灰色の背景を使用し、ブロック名と `ブロックエディタ` を明示する。

- 編集は元定義から分離したドラフト上で行う。
- 通常のスケッチツリー、作図、拘束、寸法、補助線、スケッチ追加・削除を再利用する。
- 内部スケッチは通常CADのスケッチから独立する。
- `完了` で全内部スケッチを検証して確定する。
- `キャンセル` でドラフトを破棄する。
- Escはエディタを終了せず、現在の作図・拘束操作だけを解除する。
- ブロック内ブロックとPresentation Modeへの切替は禁止する。

新規定義では、完了時に外接範囲中心がローカル原点になるよう定義全体を平行移動する。既存定義編集では原点を再計算しない。

## 6. 配置

配置開始時に、内部スケッチのチェック可能なツリーを表示する。

- Root Sketchは選択対象外とする。
- 全作図可能スケッチを初期ONにする。
- 親子スケッチは独立して選択できる。
- 少なくとも図形を持つ1スケッチを有効にする。

配置プレビューは有効スケッチの図形だけを表示し、その外接範囲中心をカーソルへ合わせる。

1. 1クリック目で表示中心を指定する。
2. 2クリック目で回転方向を指定する。

表示中心指定前のEscはキャンセルする。表示中心指定後のEscは角度0度で配置を確定する。回転中は表示中心が移動しないよう、インスタンスのX/Yを補正する。

## 7. 有効スケッチ構成

配置後も、選択したインスタンスの `enabledSketchIds` を変更できる。

- 構成変更ではインスタンスのX/Y/rotationを変更しない。
- 定義編集で追加された内部スケッチは、既存インスタンスでは自動有効化しない。
- 無効化対象の投影要素が外部拘束、寸法、Presentation注記から参照されている場合は変更を拒否する。
- Presentation要素スタイルは削除せず、再有効化したときに復元する。
- 有効な図形スケッチが0件になる変更は拒否する。

## 8. 通常編集

通常選択ではインスタンス全体を選択する。

- ドラッグはX/Yを変更する。
- 外部拘束で他インスタンスと連結している場合も、ドラッグ対象をカーソルへ追従させ、拘束を保つために連結インスタンスを連動させる。
- 回転ハンドルはrotationを変更する。
- 固定はX/Y/rotationの3自由度を固定する。
- 定義形状そのものは通常編集で変形しない。

回転ハンドルの中心は、操作開始時点の有効図形外接範囲中心とする。内部原点は変更せず、回転中にX/Yを補正して表示中心を固定する。

## 9. 拘束とsolve

拘束コマンド中は、インスタンス全体ではなく有効な投影形状を選択する。

外部拘束のsolve変数はインスタンスのX/Y/rotationだけとする。拘束によって定義内の点座標、半径、角度を変更しない。

単一インスタンス内だけで完結する線長、点間距離、半径、直径、角度寸法は、括弧付きの読み取り専用寸法として追加する。サイズ変更は定義編集で行う。

定義内部の拘束は、内部スケッチごとの独立した拘束系としてsolveする。定義変更が成功したら全インスタンスの投影形状を更新する。定義変更で配置先スケッチが成立しなくなっても定義変更は戻さず、該当インスタンスとスケッチをエラー状態にする。

## 10. 定義変更の整合性

既存定義の編集完了時は、次を検証する。

- 全内部スケッチの拘束が成立する。
- 参照関係が循環していない。
- 使用中インスタンスで有効図形集合が空にならない。
- 削除された投影要素への外部参照を整理できる。

既存要素のIDを維持し、外部拘束やPresentation参照の安定IDを保つ。

## 11. ライフサイクル

インスタンスを削除した場合、その投影形状を参照する拘束、寸法、Presentation要素を既存の図形削除規則で整理する。

使用中の定義は削除できない。使用スケッチとインスタンス数をユーザーへ示す。

旧形式のブロック定義は、全要素を内部 `Sketch-1` へ所属させ、原点を `(0,0)`、全内部スケッチを有効として移行する。既存の投影IDは維持する。

## 12. Presentation

Presentation Modeでは、有効な投影形状を通常Geometryと同じように扱う。

- 要素単位スタイル
- 表示・非表示
- 注記寸法
- 引出線

Presentationのスタイルキーと参照IDには、インスタンスIDと定義要素IDを含める。無効スケッチの要素スタイルは削除せず、再有効化時に復元する。

## 13. 範囲外

今回の実装では、次を含めない。

- ブロック内ブロック
- 外部ブロックライブラリ
- インスタンス倍率
- 鏡像変換
- 通常Geometryへの分解

これらを追加する場合も、定義とインスタンスの分離、内部スケッチの独立性、通常スケッチのグローバル座標系は維持する。
