# ブロック仕様

## 1. 目的

ブロックは、独立したローカル座標系で定義された形状を、複数のスケッチへ再利用するための機能である。

スケッチは引き続きグローバル座標系上の作図・拘束・配置単位とし、ブロックはスケッチの代替にはしない。

```text
スケッチ
  グローバル座標系上で形状を作る

ブロック定義
  ローカル座標系上で再利用形状を定義する

ブロックインスタンス
  ブロック定義をスケッチ上へ配置する
```

## 2. データ構造

CADデータは、ブロック定義とブロックインスタンスを分けて保持する。

```text
blockDefinitions[]
  id
  name
  points
  lines
  circles
  arcs
  constraints

blockInstances[]
  id
  definitionId
  sketchId
  x
  y
  rotation
  fixed
```

定義内の座標はすべてブロック原点を基準とする。インスタンスは移動X、移動Y、回転角だけを持ち、倍率や鏡像は持たない。

ワールド座標は次式で得る。

```text
world = rotate(local, rotation) + (x, y)
```

## 3. 投影形状

インスタンス内の点、線、円、円弧は、ワールド座標へ投影された読み取り専用プロキシとして扱う。

投影形状は座標を重複保持せず、定義とインスタンス変換から常に導出する。安定参照IDは次の複合IDとする。

```text
instanceId@definitionElementId
```

投影形状は、表示、スナップ、拘束対象、Presentation参照の対象になる。

## 4. 作成

アクティブスケッチ内の選択図形からブロックを作成できる。

1. 図形を選択する。
2. ブロック原点を指定する。
3. 名前を入力する。
4. 選択形状と内部で完結する拘束をローカル座標へ変換する。
5. 元形状を同じ位置のインスタンスへ置換する。

次の場合は、元データを変更せず作成を拒否する。

- 非選択図形と点を共有している。
- 選択範囲をまたぐ拘束がある。
- 別スケッチ参照拘束がある。
- Presentation注記から参照されている。
- 既存ブロックインスタンスを含む。

作成全体は1回のUndo/Redo単位とする。

## 5. 配置

ブロック一覧から定義を選び、次の2クリックで配置する。

1. 配置原点を指定する。
2. 回転方向を指定する。

原点指定前のEscはキャンセルする。原点指定後のEscは角度0度で配置を確定する。

同じ定義を、複数のスケッチへ異なる位置と角度で配置できる。

## 6. 通常編集

通常選択ではインスタンス全体を選択する。

- ドラッグはX/Yを変更する。
- 回転ハンドルはrotationを変更する。
- 固定はX/Y/rotationの3自由度を固定する。
- 定義形状そのものは通常編集で変形しない。

## 7. 拘束

拘束コマンド中は、インスタンス全体ではなく投影形状を選択する。

外部拘束のsolve変数はインスタンスのX/Y/rotationだけとする。拘束によって定義内の点座標、半径、角度を変更しない。

同一スケッチ内の通常形状、別インスタンス、許可されたスケッチ参照元との拘束を追加できる。移動と回転だけで成立しない拘束は矛盾として拒否する。

単一インスタンス内だけで完結する線長、点間距離、半径、直径、角度寸法は、括弧付きの読み取り専用寸法として追加する。サイズ変更は定義編集で行う。

## 8. 定義編集

ブロック定義は、他スケッチ形状を表示しない独立したローカル座標編集画面で編集する。

原点マーカーを表示し、既存の作図、拘束、寸法、補助線コマンドを再利用する。定義編集中はPresentation Modeへ切り替えない。

内部拘束が成立しない変更は確定せず、編集を継続する。定義変更が成立した場合は全インスタンスへ反映する。

定義変更によって配置先スケッチが成立しなくなった場合、定義変更は戻さない。該当スケッチをエラー状態にし、定義から依存先へ順に再solveする。

## 9. ライフサイクル

インスタンスを削除した場合、その投影形状を参照する拘束、寸法、Presentation要素、要素スタイルを整理する。

使用中の定義は削除できない。使用スケッチとインスタンス数をユーザーへ示す。

定義編集で投影要素が削除された場合、その投影要素を参照していた外部拘束とPresentation要素を整理する。

## 10. Presentation

Presentation Modeでは、投影形状を通常Geometryと同じように扱う。

- 要素単位スタイル
- 表示・非表示
- 注記寸法
- 引出線

Presentationのスタイルキーと参照IDには、インスタンスIDと定義要素IDを含める。

## 11. 初期実装の範囲外

初期実装では、次を含めない。

- ブロック内ブロック
- 外部ブロックライブラリ
- インスタンス倍率
- 鏡像変換
- 通常Geometryへの分解

これらを追加する場合も、定義とインスタンスの分離、およびスケッチのグローバル座標系は維持する。
