## 3. 検証コマンド

```text
npm run check
npm run test:unit
npm run test:e2e
```

`npm run test:all`は上記を順に実行する。

## 4. Visual baseline

`phase0-characterization.spec.js`は現在の単一Canvas layoutで、Geometry／Constraint、入れ子Block、Sketch所属Annotation、Block EditorのCanvas baselineを保持する。UI構造変更時は意図を確認してbaselineを更新する。

## 5. 完了判定

仕様変更では実装、関連spec、unit／E2E、visual baselineを同一変更で更新する。旧モードやSheetを前提とするUI selectorおよび保存fieldを現行テストへ持ち込まない。ただし旧JSON破棄を確認するfixtureに限り旧fieldを入力データとして保持できる。
