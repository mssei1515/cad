## 2. 現行仕様のE2E保証

- JSON version 9のround-tripと旧表示専用データの破棄
- Geometry、Constraint、Sketch階層、参照拘束、Block、入れ子Block
- AppearanceのDocument→Sketch→Geometry継承
- Block Instance全体のAppearance Override
- visible=falseのGeometry／寸法とToolbar固定切替／Space押下中のConstraint Status View、および状態表示中のLine endpoint marker抑止
- Constraint Dimensionの表示属性、Prefix／Suffix入力中の即時Canvas反映とdrag後の属性保持、PropertiesでのUpper／Lower tolerance非表示
- Document Leader／Free Textの描画、選択、drag、保存、Undo/Redo
- Menu Bar、Toolbar、最小化可能なExplorer／Properties、Canvas、Status Barの構成
- 背景透過Cad2 SVGロゴ、青系Menu Bar、画面上のファイル名非表示、Sketch treeの枝線とcompactな常時展開row
- Toolbarの保存／開くを含むicon-only表示、狭幅時のlabel非表示、通常時・drag中のdefault cursor
- 背景Gridの非表示
- Menuの排他open、Geometry commandの1列表示、open中の16ms hover切替、外側click／Esc／command実行によるclose
- P1固定の起動sampleでL2／L3がP3 point dragと同じsolve経路に追従
- Canvas左上の独立Sketch tree、Geometry／Block／Constraint順の3tab Explorer、Block InstanceのBlock配置、compactなtab形状とConstraint集計のpanel背景
- Toolbar／Block menu共通の単一Block作成command、およびBlock tab／Block menuから開くBlock Definitions modal
- ExplorerとCanvas／Propertiesのselection・hover同期、Canvas／Sketch tree／Geometry／Constraint間のhover強調統一、Sketch tree hover時のGeometry ID・Line endpoint marker・Block Projection Point marker抑止、および未設定Appearanceの日本語`既定`／英語`Default`表示
- 固定explicit Pointの通常色表示と、Point hover／選択中だけの赤色および`固定`／`Fixed` label表示
- 非アクティブSketchのGeometry／Block Instance／Constraint Dimensionに対する通常hover強調・selection抑止、強調を伴わない所属／参照可否表示、および拘束・寸法command中だけの先祖参照操作
- Selection後もapplication言語を維持するProperties再描画、およびAppearance ColorのCad2 Palette modal、無彩色と複数色相・明暗を含む標準色／Document内で明示使用済みの色swatch／任意色picker、hover時のswatch実色維持、HEX入力、Color reset button非表示、空入力による継承
- Geometry初回表示の全section折り畳みとtab再表示時の開閉状態維持、各分類の件数、Point sectionのLine端点表示、およびBlock／Constraint一覧の折り畳みなし直接表示
- 目と4状態色を用いたConstraint Status View button icon
- 非アクティブを含む表示中SketchのConstraint Dimension描画
- Block Editorの淡色Canvas背景、Block選択時のProjection ID抑止、補助Line／Block hover時の端点はみ出し維持
- Application SettingsとDocument Settingsの分離、既定日本語の日本語／English UI切替、application-localな選択保持
- 作図、拘束、選択、dragの性能characterization

## 3. 検証コマンド

```text
npm run check
npm run test:unit
npm run test:e2e
```

`npm run test:all`は上記を順に実行する。

## 4. Visual baseline

`phase0-characterization.spec.js`は現在の単一Canvas layoutで、Geometry／Constraint、入れ子Block、Document Annotation、Block EditorのCanvas baselineを保持する。UI構造変更時は意図を確認してbaselineを更新する。

## 5. 完了判定

仕様変更では実装、関連spec、unit／E2E、visual baselineを同一変更で更新する。旧モードやSheetを前提とするUI selectorおよび保存fieldを現行テストへ持ち込まない。ただし旧JSON破棄を確認するfixtureに限り旧fieldを入力データとして保持できる。
