## 2. 現行仕様のE2E保証

- JSON version 9のround-tripと旧表示専用データの破棄
- Geometry、Constraint、Sketch階層、参照拘束、Block、入れ子Block
- AppearanceのDocument→Sketch→Geometry継承
- Block Instance全体のAppearance Override
- visible=falseとToolbar固定切替／Space押下中のConstraint Status View、および状態表示中のLine endpoint marker抑止
- Constraint Dimensionの表示属性、Prefix／Suffix入力中の即時Canvas反映とdrag後の属性保持、PropertiesでのUpper／Lower tolerance非表示
- Document Leader／Free Textの描画、選択、drag、保存、Undo/Redo
- Menu Bar、Toolbar、最小化可能なExplorer／Properties、Canvas、Status Barの構成
- Cad2 SVGロゴ、青系Menu Bar、画面上のファイル名非表示、Sketch treeの枝線とcompactな常時展開row
- Toolbarの保存／開くを含むicon-only表示、狭幅時のlabel非表示、通常時・drag中のdefault cursor
- 背景Gridの非表示
- Menuの排他open、Geometry commandの1列表示、open中の16ms hover切替、外側click／Esc／command実行によるclose
- P1固定の起動sampleでL2／L3がP3 point dragと同じsolve経路に追従
- Sketches／Blocks／Objectsの3tab Explorer構成、Block InstanceのObjects配置
- ExplorerとCanvas／Propertiesのselection・hover同期、Canvas／Sketch tree／Objects間のhover強調統一、Sketch tree hover時のGeometry ID抑止、および未設定Appearanceの日本語`既定`／英語`Default`表示
- 非アクティブSketchのGeometry／Constraint Dimension／Block hoverにおける所属Sketchと参照可否表示
- Appearance Colorのpicker、HEX入力、継承へ戻すbutton
- Objects初回表示の全section折り畳み、tab再表示時の開閉状態維持、Point sectionのLine端点表示
- 非アクティブを含む表示中SketchのConstraint Dimension描画
- Block Editorの淡色Canvas背景、Block選択時のProjection ID抑止、補助Line／Block hover時の端点はみ出し維持
- Application SettingsとDocument Settingsの分離
- 作図、拘束、選択、dragの性能characterization

## 3. 検証コマンド

```text
npm run check
npm run test:unit
npm run test:e2e
```

`npm run test:all`は上記を順に実行する。

## 4. Visual baseline

`phase0-characterization.spec.js`は現在の単一Canvas layoutで、Geometry／Constraint、入れ子Block、Document Annotation、Block EditorのCanvas baselineを保持する。UI構造変更時は意図を確認してbaselineを更新する。

## 5. 完了判定

仕様変更では実装、関連spec、unit／E2E、visual baselineを同一変更で更新する。旧モードやSheetを前提とするUI selectorおよび保存fieldを現行テストへ持ち込まない。ただし旧JSON破棄を確認するfixtureに限り旧fieldを入力データとして保持できる。
