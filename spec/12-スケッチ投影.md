# スケッチ投影

## 1. 目的

スケッチ投影は、表示中の先祖SketchにあるGeometryを通常GeometryとしてアクティブSketchへ複製し、`SketchProjectionConstraint`で元Geometryへ関連付けるコマンドである。投影先は通常のPoint、Line、Circle、Arc、Splineであり、投影リンクを解除した後も最後の形状を維持して残る。

Annotation、Hatch、Reference Image、Constraint Dimension、Block Instance本体は投影対象外とする。先祖Sketchに配置されたBlock Instanceから生成されるBlock ProjectionのPoint、Line、Circle、Arc、Splineは投影対象に含む。すべてのSketchは共通world XY座標を使用し、投影時に座標変換は行わない。

## 2. コマンド操作

GeometryメニューまたはToolbarの「スケッチ投影」から開始する。Toolbar iconは、上側の破線形状を投影元、下側の実線形状を投影先として、両者の間に下向きの投影線を3本配置した製図投影表現とする。表示中の作図可能な先祖SketchのGeometryをclickすると投影候補へ追加し、再clickで候補から解除する。空白位置からのドラッグ範囲選択でも複数候補を追加でき、右方向のドラッグは範囲内に完全に含まれるGeometry、左方向のドラッグは範囲と交差するGeometryを対象とする。暗黙のLine端点は範囲選択で独立Point候補にせず、Line自体を候補にする。EnterまたはCanvasの右clickメニューの「実行」で候補を一括作成して選択モードへ戻り、Escでは候補をすべて破棄してGeometryを作成しない。

自己、子孫、兄弟、別階層、Root、非表示Sketchまたは非表示Geometryは選択できない。作成後に元Sketchを非表示にしてもリンクは有効であり、元Geometryの変更へ追従する。同じ元Geometryが同じ投影先Sketchへ既に投影されている場合は重複作成しない。

## 3. 形状とPoint

投影は次を同期する。

- Point: X、Y
- Line: 両端Pointと通常／補助作図属性
- Circle: 中心Point、半径、通常／補助作図属性
- Arc: 中心Point、半径、始点角度、終点角度、通常／補助作図属性
- Spline: 通過Pointの順序・座標・個数、開閉状態、通常／補助作図属性

投影されたGeometryは種類を問わず、それぞれが完全に独立した投影先Pointを所有する。同じ元Pointを参照するPoint、Line端点、Circle／Arc中心、Spline通過Pointであっても、Geometry間で同じPoint objectを共有しない。同じ位置へ投影されるPointは座標だけが一致する。このため、投影先の閉じた矩形は接続済み輪郭として扱わず、投影解除後の端点編集、Offset chain、Copy／Paste、Block化、選択、snapでも共有Pointによる接続関係を持たない。

元Splineの通過Point追加・削除・並び変更では、そのSpline自身がすでに所有する対応Pointを元Point IDと出現順で維持し、新しく必要になった通過Pointだけを独立して追加する。他の投影Geometryが所有するPointは再利用しない。

投影の連鎖を許可する。先祖Sketch上の投影結果をさらに子Sketchへ投影した場合、上流の変更を依存順にsolveして末端まで反映する。

## 4. Constraintと保存

Document直下またはBlock Definitionの`constraints[]`へ次の形式で保存する。

```js
{
  type: "sketchProjection",
  kind: "point" | "line" | "circle" | "arc" | "spline",
  source: "元Geometry参照",
  target: "投影先Geometry ID",
  enabled: true,
  sketchId: "投影先Sketch ID",
  reference: true,
  referenceSketchId: "元Sketch ID"
}
```

`source`は通常Geometry IDまたはBlock Projectionの正規GeometryRef文字列、`target`は通常Geometry IDである。JSON version 19で導入し、version 18以前の読込では`sketchProjection`を持たないものとして扱う。投影先Geometry自体は通常Geometry配列へ保存するため、投影拘束がない旧version扱いでも最後の形状を復元できる。旧実装で作成されたversion 19データに複数の投影Geometryが共有するLine端点、Circle／Arc中心、Spline通過Pointなどがある場合は、読込時に2個目以降を複製し、各投影Geometryが独立したPointを持つ形へ正規化する。

Undo／Redo snapshotとBlock Editor local履歴には投影先Geometryと投影拘束を含める。Block Editor完了後はBlock Definitionの内部Constraintとして保存する。Block Instanceは投影結果Geometryだけを通常どおり公開し、投影拘束そのものをInstance外へ公開しない。

## 5. 表示と情報

通常表示では、リンク中の投影先Geometryにも通常Geometryと同じAppearance解決結果を使用し、投影専用色で上書きしない。Constraint Status Viewでは、有効な投影拘束の投影先Geometryとその所有Pointを投影専用の紫`#7C3AED`で表示する。選択、hover、solve errorの強調色は投影専用色より優先する。

Sketch Treeでは投影先Geometryへ「投影」badgeを付け、Constraint分類へ削除可能な「スケッチ投影」rowを表示する。Geometry Propertiesには参照元Sketchと参照元Geometry ID、Constraint Propertiesには参照元Sketch、元Geometry ID、投影先Geometry IDを表示する。

## 6. 編集と解除

投影先Geometryはsnap、通常拘束、寸法、Hatch境界、Leader、Offsetの参照対象として使用できる。投影拘束を手動削除しても投影先Geometryは削除しない。

投影拘束は、投影先の形状を元Geometryへ固定する参照拘束であり、操作上は固定拘束に近いものとして扱う。有効な投影拘束がある間、投影先の形状と通常／補助作図属性は元Geometryから同期する完全拘束相当の読み取り専用状態とする。投影先本体または所属するLine端点、共有する中心・Spline通過Pointに対するdrag、trim、fillet、Spline通過Point追加・削除、Spline開閉変更、固定、通常／補助作図切替は拒否し、投影拘束を自動解除しない。click選択は許可する。形状または通常／補助作図属性を編集する場合は、Sketch Treeなどから投影拘束を明示的に削除してから操作し、削除後は最後の形状を維持した自由な通常Geometryとなる。

Geometry固有のAppearance（表示、色、線種、線幅、端部表現）は投影の参照対象に含めない。リンク中も個別または複数Propertiesから編集でき、Appearance変更後も投影拘束と元形状への追従を維持する。

Copy／Pasteと選択GeometryのBlock化では投影拘束を含めず、結果を独立Geometryとして扱う。

## 7. 削除

元Geometryまたは元Block Instanceを削除した場合は対応する投影拘束だけを削除し、投影先を最後の形状で残す。投影元Sketch自身を削除する場合は、そのSketchを直接参照する投影先の子Sketchを削除元Sketchの親へ繰り上げ、投影拘束を解除して投影先を残す。投影元になっていないSketchの削除は従来どおり配下Sketchを含めて削除する。投影先Geometryを削除した場合は、対応する投影拘束も削除する。
