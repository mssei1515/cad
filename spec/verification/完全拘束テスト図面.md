# 完全拘束テスト図面

`tools/generate-adversarial-drag-fixture.js` は、固定点を原点の1個だけに限定した完全拘束の混合図形を生成する。生成先はGit管理外の `test-data/意地悪ドラッグ完全拘束.json` とする。

線分のOffset寸法は支持直線の距離と平行関係を拘束し、端点の接線方向の位置と線分長を拘束しない。そのため生成図面の `L_OFFSET_COPY` には、始点のX座標寸法と線分長寸法を別途付ける。Offset自体に旧来の端点固定を要求せず、図面全体の自由度0という検証条件を満たす。

生成後は `tests/e2e/adversarial-drag-fixture.spec.js` と `tests/e2e/adversarial-authoring-performance.spec.js` で、完全拘束状態・拘束削除後の操作・UIからの拘束復元と性能を検証する。
