# スケッチ

## 1. 目的と基本構造

Sketch は Geometry と拘束をまとめる作図・編集・solve 単位である。Document 全体を単一の巨大な拘束系にせず、意味のある階層へ分割する。

新規 Document は次の構造を持つ。

```text
Root Sketch (ROOT)
└─ Sketch-1 (S1)
```

Root Sketch はツリーの基点であり、Geometry や拘束を所属させない。Root をアクティブにすることはできるが、その状態では作図できない。

## 2. 所属と座標系

- Point、Line、Circle、Arc、Spline は必ず1つの作図可能 Sketch に所属する。
- Constraint も所有側の1つの Sketch に所属する。
- Block Instance は配置先の1つの Sketch に所属し、その Projection も同じ Sketch の要素として扱う。
- LeaderとFree Textは作成時のactive Sketchに所属する。Root選択中はAnnotationを作成できない。
- Hatchは作成時のactive Sketchに所属し、同じSketchの通常Line、Circle、Arc、Splineだけを境界として参照する。Root選択中は作成できない。
- Reference Imageは読み込み時のactive Sketchに所属する。Root選択中は読み込めず、Constraint、solver、snapには参加しない。
- すべての通常 Sketch は共通のワールド XY 座標系を使う。
- 同じ座標にある別 Sketch の Point は別オブジェクトであり、共有 Point ではない。

## 3. アクティブ Sketch

アクティブ Sketch だけが通常の作図・変形・通常拘束の対象になる。Sketch 切替時は、選択、ドラッグ、作図途中、拘束コマンド、寸法入力、スナップを解除する。

非アクティブ Sketch は表示中であれば Canvas に描画するが、通常時はGeometry、Block Instance、Constraint Dimension、Annotation、Reference Imageを青色や太線でhover強調せず、選択、dragもできない。pointerが非アクティブなGeometry、Block Instance、Constraint Dimensionに重なった場合は、図形を強調せずに対象ID、所属Sketch名、active Sketchからの参照可否だけをpointer付近へ表示する。現在の実装では非アクティブ要素の `globalAlpha` は1であり、「薄く表示する」という旧仕様は実装されていない。

拘束・寸法コマンドで先祖Sketchを参照対象として指定している間だけ、参照可能な非アクティブGeometryおよびBlock Projectionをcommand operandとしてhover・選択できる。このcommand限定経路は通常のCanvas Selectionへ追加しない。

## 4. 作成、名前、階層

- 「兄弟+」は現在 Sketch と同じ親の下へ新規 Sketch を作る。
- 「子+」は現在 Sketch の子として作る。
- Root 選択中の兄弟・子作成は実質 Root 直下になる。
- Root 直下は `Sketch-n`、子は `<親名>-n` を既定名にする。
- 作成後は新しい Sketch をアクティブにする。
- Root 以外は名前変更できる。

UI には既存 Sketch の親を変更する操作はない。

Canvas左上へ表示するSketch Treeは、初期約320px幅、最大約70vhとし、surface、border、角丸、shadow、背景blurを持たない完全透過の表示とする。右端のresize handleをmouse dragして220–560pxの範囲で横幅を変更でき、狭いCanvasではCanvas内へ収まる幅を上限とする。変更幅はsession中だけ維持し、Document JSONとUndo/Redoには含めない。header、通常のSketch・分類・Object・拘束状態集計rowも背景を透過し、hover、選択、active、error等の操作・状態を示す一時背景だけを表示する。既存の18px cellを用いた縦線とtee／elbowの枝線をSketch、分類、Object rowまで連続させ、各rowのcontent開始位置も階層ごとの18px indentへ揃える。Sketch rowは約19px、分類rowは約20px、Object rowは約22pxとし、余分な行間を設けない。tree全体のHide／Show buttonは設けない。

Objectを持つactive Sketch rowはchevronまたはrow本体のclickで当該Sketch直下の分類を開閉する。非active Sketchのrow本体をclickした場合は、そのSketchを表示してactive化するだけで開閉状態を維持し、active化後の次のrow clickから開閉する。表示、名前変更、削除の各buttonは固有の操作だけを行い、rowの開閉を発生させない。Objectを持たないSketch rowは開閉せず、row本体のclickによるactive化だけを行う。

Root以外の各Sketch直下には、存在する分類だけを次の順に置き、その後に子Sketchを置く。

1. Point
2. Line
3. Circle
4. Arc
5. Spline
6. Hatch
7. Image
8. Block
9. Constraint
10. Annotation

Pointにはexplicit PointとLine端点を表示する。Circle／Arc中心はexplicit PointまたはLine端点でもある場合だけPointへ重複表示する。Imageには所属Reference Imageを表示し、名前とpixel寸法、非表示・位置ロック状態を示す。Blockは配置先にあるInstanceだけを表示し、投影された内部ObjectはホストSketchで個別表示しない。Constraintには通常拘束、拘束寸法、参照寸法、固定Pointを表示する。展開時の先頭には当該Sketchの拘束状態集計をObject rowと同じ22pxの枝付き補助rowとして置き、完全、支持、未拘束、矛盾を状態色のdotと件数でcompactに表示する。完全な名称と件数はtooltipで表示する。

分類はすべて初期折り畳みで、空分類はDOMにも生成しない。開閉状態はDocumentまたは編集中Block Definition、Sketch ID、分類の組み合わせでsession中だけ記憶し、JSONとUndo/Redoには含めない。ファイル読込では全分類を閉じる。閉じた分類のObject rowは生成せず、選択またはhover対象を含む場合は分類見出しを薄い青と左accentで通知する。Canvas選択による自動展開は行わない。

Object rowはToolbarと同じ14px SVG icon、主表示、補助表示、意味のある状態badge、操作領域を1行に置く。分類名には件数pillを表示する。通常clickは選択を置換し、Ctrl／Shift clickは同じSketch内のGeometry、Block、Annotation、Reference Imageを加算／解除する。Constraintは単一選択とする。非アクティブSketchのObject rowをclickすると、そのSketchを表示してactive化してから対象を選択し、PropertiesとCanvasへ同期する。hoverだけでは非アクティブObjectをCanvas強調しない。Geometry／Constraintの削除と固定解除はrow右端のbuttonを使用し、Block／Annotation／Reference Imageは選択後に共通Deleteを使用する。

Root Sketchのrowをhoverした場合は、Root配下の表示中Sketchに属するGeometryとBlock Projectionをすべて、通常のSketch Tree hoverと同じ規則で強調する。Line endpointおよびBlock ProjectionのPoint markerは追加表示しない。

## 5. Appearanceと表示状態

Root以外のすべてのSketchは、通常Geometry用のAppearance、補助Geometry用のConstruction Appearance、寸法用のDimension Appearanceを持つ。PropertiesのUI見出しはDocument設定と同じ`一般外観`／`General Appearance`、`補助線外観`／`Construction Appearance`、`寸法外観`／`Dimension Appearance`とし、3区分は個別に折り畳めて初期状態ではすべて閉じる。ユーザーが開閉した後はPropertiesの再描画やSketch切替を挟んでもsession中の状態を維持する。各未設定fieldは親Sketchではなく対応するDocument外観を直接継承し、未設定欄は日本語で`既定 (継承値)`、英語で`Default (inherited value)`を表示する。Dimension Appearanceでは表示、色、線幅、精度、接頭辞、接尾辞に加え、寸法補助線の突出量・起点すき間、端末記号の種類・サイズ・矢印系の開き角、寸法文字の高さ・寸法線との間隔を個別上書きできる。Construction Appearanceは同じSketchの通常Appearanceを継承しない。Root Sketchは外観の継承元ではなく、Propertiesにも外観区分を表示しない。Block Definition内のRootも同様に編集不可とし、内部の各SketchはDocument外観を直接継承する。

- 親SketchのAppearanceは、`visible`を含めて子孫へ継承しない。
- 非表示Geometryは通常時の描画、hover、snap、新規参照対象選択から除外する。
- 既存の参照拘束は、参照元Sketchを非表示にしてもsolveを継続する。
- Sketch AppearanceはJSONへ保存する。
- Space押下中はvisibleを無視して拘束状態を表示する。

## 6. スナップ

表示中の別 Sketch Geometry へ作図時スナップできる。スナップは座標を借りるだけであり、別 Sketch 間の要素共有や通常拘束を作らない。Lineの中点はスナップ候補にせず、中点一致拘束も自動作成しない。

スナップ先と作成先が別 Sketch でも、新しい Geometry は必ずアクティブ Sketch に所属する。

## 7. 通常拘束

通常拘束は同一 Sketch 内で閉じる。兄弟、子孫、別ブランチを含む対象を通常拘束として結びつけない。

この制限は、拘束の solve 範囲と所有権を明確にし、別 Sketch の意図しない変形を防ぐためである。

## 8. 参照拘束

参照拘束は、アクティブ Sketch の Geometry を、先祖 Sketch の読み取り専用 Geometry に関係づける。

スケッチ投影も同じ先祖参照範囲を使用するが、先祖Geometryを指す派生Instanceと独立した座標を持たない表示Geometryを作成する。投影Geometryは子Sketch所属の読取専用入力として、同じ子Sketch内の通常Geometryとの通常拘束に使用できる。子Sketchから先祖SketchのGeometryを変更してはならないため、投影Geometryおよび投影を経由する派生Geometryはdragできない。元Sketchを非表示にした後も参照は維持する。詳細は[派生Geometryインスタンス](./12-スケッチ投影.md)を参照する。

```text
先祖 Sketch（固定入力）
        ↓
子孫 Sketch（solve 対象）
```

許可する参照元は `ancestorSketchIds(activeSketchId)` に含まれる作図可能 Sketch だけである。

禁止する参照は次のとおり。

- 自分自身
- 子孫
- 兄弟
- 別ブランチ
- Root Sketch
- 直接・間接の循環を作る関係

対称拘束は3対象を持つため、参照対象がある場合は全参照対象が同じ先祖 Sketch に属する必要がある。それ以外の参照拘束は、原則としてアクティブ側1対象と先祖側1対象の組み合わせである。

## 9. 参照 solve

参照先 Geometry は solve 変数に含めず、固定値として拘束式へ渡す。

参照元が変わった場合は、参照グラフをたどって依存 Sketch をトポロジカル順に solve する。各 Sketch は全参照元が確定した後に solve する。

読込時に復元できる参照拘束の範囲違反・循環は、[データモデルと永続化](./02-データモデルと永続化.md)のLOAD-02に従って無効状態で保持する。参照先Geometry自体を復元できない場合や、Block・派生Instanceの依存関係が不正な場合とは区別する。

## 10. Sketch 削除

Sketch削除は原則としてその子孫を含むサブツリー削除である。削除対象のGeometryを存続する派生Instanceが参照している場合は削除を拒否し、依存Instanceの先行削除を求める。

削除前に次を確認する。

1. 削除範囲外の Sketch が、削除範囲を参照していないこと。外部参照があれば拒否する。
2. 削除される Geometry 件数を示し、ユーザー確認を取る。

削除時は次を一括で除去する。

- サブツリー内の Geometry、Constraint、Block Instance、Annotation、Hatch、Reference Image
- 削除 Projection を参照する外部 Constraint
- 該当Geometryを参照するLeader

アクティブ Sketch が削除範囲に含まれる場合は、削除対象外の親、なければ Root をアクティブにする。

## 11. Block Definition 内部 Sketch

Block Definition は通常 Document とは独立した内部 Sketch Treeと`annotations[]`、`hatches[]`、`referenceImages[]`を持つ。構造、作図、通常拘束、スケッチ投影、Annotation、Hatch、Reference Image、先祖参照、solve、削除規則は通常 Sketch と同じコード経路を再利用する。内部Reference ImageはDefinition編集用だけに保存し、Instanceへ投影しない。

内部 Sketch ID は Definition のスコープ内で解釈し、通常 Document の同名 ID と要素を共有しない。Block Instance の `enabledSketchIds` は、内部 Sketch のうちどれを Projection として公開するかを指定する。
