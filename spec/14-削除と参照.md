# 削除と参照

通常の削除操作では、削除対象そのものの所属と、存続するObjectからの参照を区別する。この文書は参照先を削除できる条件と削除後の扱いを定義する。読込時の欠落参照は[データモデルと永続化](./02-データモデルと永続化.md)、編集確定時の失敗は[編集の確定と失敗](./13-編集の確定と失敗.md)に従う。

## 1. 削除を拒否する参照

| ID | 削除対象・操作 | 存続する依存先 | 結果 |
| --- | --- | --- | --- |
| DEL-01 | Parameter、寸法、寸法を含むGeometry・Sketch・Block Instance | 削除対象symbolを参照する式 | 依存元名を表示して拒否する。依存元も同時に消える操作と、名前空間全体の削除は許可する |
| DEL-02 | 元Geometry、元Block Instance、ミラー軸、パターン方向、上流の派生Instance | それを参照する派生Instance | 拒否し、依存Instanceの先行削除を求める |
| DEL-03 | Sketchとその削除範囲 | 範囲外のSketchからの参照拘束、または存続する派生Instance | 拒否する |
| DEL-04 | Block Definition | 使用中のInstance | 拒否する |

DEL-01は、直接選択した寸法だけでなく、Geometry等と一緒に除去する寸法も対象にする。参照元の非表示は参照の消滅を意味しない。派生Geometryを通常Geometryへ変換する独立化操作は設けない。

## 2. 削除が成立した場合の参照整理

| ID | 削除されるもの | 参照・所属するもの | 結果 |
| --- | --- | --- | --- |
| DEL-05 | Geometry、Block InstanceのProjection、派生Instanceの生成Geometry | Constraint・拘束寸法・Leader | 対象を参照するものを除去する。寸法symbolにはDEL-01を適用する |
| DEL-06 | Hatchの境界Geometry | Hatch | Hatchを残し、境界エラーの無効状態にする |
| DEL-07 | Sketchの削除範囲 | 所属するGeometry、Constraint、Block Instance、派生Instance、Annotation、Hatch、Reference Image | 所属Objectを除去する。範囲外への影響はDEL-01～03を先に判定する |
| DEL-08 | Geometry | その定義に使われるPoint | 共有状況を確認して不要なPointを整理する。他のGeometryに使われる共有Pointを不要Pointとして除去しない |

Splineの削除でも、Splineのためだけに存在する不要なfit pointを整理する。Hatchについては「境界を失う」場合と「所属Sketchごと削除する」場合で結果が異なる。

1回のGeometry削除は1つの履歴単位にする。履歴対象は[UI・操作・履歴](./07-UI・操作・履歴.md)に従う。Trim、Fillet、Splineの通過点編集などによる参照の移送・再構成は各機能の操作仕様に従う。

## 3. Sketchの削除範囲

Sketch削除は原則として子孫を含むサブツリー削除とする。

1. 削除範囲外の参照を確認する。
2. 削除されるGeometry件数を示してユーザー確認を取る。
3. 削除される寸法symbolへの依存を確認し、成立する場合に所属Objectと、削除Projection等を参照するConstraint・Leaderを整理する。
4. active Sketchが削除範囲に含まれる場合は、削除対象外の親、なければRootをactiveにする。

Block Definition内部のSketchにも同じ削除規則を適用する。

## 4. Blockの構成変更

| 操作 | 参照が失われる対象 | 結果 |
| --- | --- | --- |
| 有効内部Sketchの切替 | 無効化されるProjectionを参照するLeader | 変更を拒否する |
| 有効内部Sketchの切替 | 無効化されるProjectionを参照する外部Constraint・寸法 | 関連拘束を自動解除し通知する。寸法symbolの依存が残る場合はDEL-01に従い拒否する |
| 子Definition編集でProjectionを削除 | 親Definition内の該当Constraint | 拘束を解除して編集を継続する |
| Definition削除 | 所有下の子孫Definition | 親とともに削除する。使用中DefinitionはDEL-04に従い拒否する |

有効内部Sketchがなくなる変更の拒否、Definition編集完了時の参照整理など、構成変更固有の成立条件は[ブロック](./05-ブロック.md)に従う。内部Sketchの無効化はSketch自体の削除とは区別する。
