# 表示と注記

## 1. 単一Canvas

Geometry、Constraint Dimension、Sketch所属Annotation、Sketch所属Hatchは同じCanvasに描画する。表示専用モードおよびSheetは存在しない。Hatchは境界Geometryより先に描画し、境界strokeを常に手前へ出す。

## 2. Appearanceの継承

通常Geometryと補助Geometry（Splineを含む）のAppearanceは、互いに独立して次の順に解決する。

```text
通常Geometry:
Documentの一般Appearance既定
  → 対象Sketch自身の通常Appearance
    → Geometry
      → Block Instance Appearance Override

補助Geometry:
DocumentのConstruction Appearance既定
  → 対象Sketch自身のConstruction Appearance
    → Geometry
      → Block Instance Appearance Override
```

一般Appearanceは、Document設定でもSketch設定でもConstruction Appearanceへ継承しない。親SketchのAppearanceは子Sketchへ継承しない。Block Definition内部のSketchも対応するDocument既定を基底として自身の明示設定とGeometryを解決した後、外側のInstance Overrideを適用する。入れ子Blockでは最外側の配置Instance Overrideを最後に適用する。

補助GeometryはDocumentのConstruction Appearanceを直接継承し、所属Sketch自身のConstruction AppearanceまたはGeometryで明示したAppearanceがそのプロパティを上書きする。初期基底は一点鎖線、細線、低い不透明度であり、補助Lineでは端部のはみ出しと端部の点を有効にする。端部のはみ出しを無効にした補助Lineは元の端点間だけを描画し、寸法補助線のclearanceにも固定12pxのはみ出しを加算しない。

選択・hoverは一時的な強調表示であり、Appearanceデータを変更しない。アクティブSketchについては、CanvasとSketch TreeのObject rowのどちらを起点にしても、対象GeometryまたはBlockにCanvas hoverと同じ青色と線幅の強調を使用する。Sketch TreeでLineを直接参照する拘束をhoverまたは選択した場合はLine本体を強調し、そのLineの形状を定義するendpointは強調対象へ含めない。点‐線拘束のPointなど、拘束が直接参照するPointは強調する。Sketch TreeのSketch hoverでは通常GeometryとBlock ProjectionのどちらにもLine endpoint markerを表示しない。Block ProjectionはLine・Circle・Arc・Splineのstrokeだけを強調し、explicit Pointや中心Pointを含むPoint markerは表示しない。非アクティブSketchのCanvas hoverは図形を強調せず、対象の所属と参照可否だけを表示する。

固定されたexplicit Pointは、通常時は非固定Pointと同じ通常表示とする。Point自身をhoverまたは選択した間だけ赤色で強調し、日本語で`固定`、英語で`Fixed`のlabelをPointのそばに表示する。

## 3. visible

`visible=false`のGeometryは通常表示とhit testから除外する。Sketchの非表示設定はそのSketch自身のGeometryへだけ適用し、子Sketchへは波及しない。Constraint Status Viewではvisibleに関係なく表示する。

## 4. Constraint Status View

ToolbarのView buttonを有効にしている間、またはSpaceを押している間は次を行う。

- Geometryを完全拘束、支持位置拘束、未拘束、矛盾の状態色で描く。
- 非表示Geometryを含めて表示する。
- Dimension AppearanceのVisibleがfalseの寸法も含め、表示中Sketchに属するすべての寸法を表示する。
- 非アクティブSketchの寸法は、非アクティブGeometryと同じ灰色`#cbd5e1`で描く。アクティブSketchの寸法は設定済みのDimension Appearance色を維持する。
- explicit Pointや中心Pointなど、状態確認に必要なPointを表示する。
- Line endpointの丸markerは通常は表示せず、アクティブSketchの端点をCanvas上で直接hoverしている間だけ通常表示と同じhover markerを表示する。補助LineのAppearanceによるendpoint markerは表示しない。

Toolbar buttonまたはView menuのcheckboxは、clickごとに固定表示を切り替え、両者のON/OFF表示を同期する。Spaceは押下中だけの一時表示であり、固定状態とは独立する。Space押下中もToolbar buttonとView menu checkboxは実際の表示状態をONとして示す。固定表示中にSpaceを押して離しても表示を維持する。windowがfocusを失った場合はSpace由来の一時表示だけを解除する。View Stateだけを変更し、Document、履歴、Selectionは変更しない。

## 5. Constraint Dimension

すべての寸法はConstraintに属する。寸法のAppearanceはDocumentのDimension Appearance、所属Sketch自身のDimension Appearance、各寸法で明示したfieldの順に解決する。親SketchのDimension Appearanceは継承しない。Block Definition内の寸法も同じDocument既定を使用する。Propertiesから値と次のAppearance属性を編集できる。

- Visible
- Color
- Line width
- Precision
- Prefix / Suffix
- Terminator type / size
- Extension line overshoot / origin gap
- Arrow opening angle
- Dimension text height / gap from dimension line

Colorは寸法線、端末記号、補助線、ラベルへ適用し、線幅は寸法線、端末記号および補助線へ画面px単位で適用する。寸法補助線の突出量は寸法線を越える長さ、起点すき間は対象Geometryの数学的な起点から補助線開始位置までの間隔とする。Point marker半径や補助線Geometryの端部はみ出し量を自動加算せず、起点すき間が`0mm`なら補助線も対象起点から描画する。端末記号は標準矢印、塗りつぶし矢印、点から選択し、両端に端末を持つ寸法では左右で同じ種類とサイズを使用する。標準矢印は線幅と開き角によるstroke結合の突出を描画位置で補正し、選択強調時や表示倍率の変更後も、視覚上の先端を寸法補助線と寸法線の交点へ一致させる。円弧の半径寸法は中心側の端末記号を描画せず、円弧側だけに選択中の端末記号を描画する。この半径寸法線は中心点から円弧上までで止め、ラベル配置のために円弧の外側へ延長せず、円弧上から外側へ突出する寸法補助線も描画しない。サイズは矢印では長さ、点では直径とし、開き角は矢印系だけへ適用する。線形寸法では寸法補助線間の距離、角度寸法では同距離に相当する寸法円弧長を、画面上の寸法文字幅へ端末記号1個分の長さを加えた必要幅と比較する。必要幅を下回った時点で矢印系端末を補助線の外側へ反転して内向きに描き、反転した各端末には矢印長さの1.5倍の軸線を外向きに描く。角度寸法ではこの軸線を載せる分だけ寸法円弧も延長する。方向を持たない点端末は反転しない。円弧の半径寸法は前述の円弧外側へ延長しない規則を優先し、外側軸線を追加しない。寸法補助線と端末記号は常時表示する。寸法文字の高さと寸法線との間隔は、線形寸法、角度寸法など共通表示へ適用する。長さ系の設定値はmmで保持し、`mm × 96 / 25.4`で画面pxへ換算してzoomを相殺するため、どの表示倍率でもおおよそ同じ画面上サイズを維持する。開き角は度で保持する。個別Colorまたは線幅を空にすると所属Sketchから継承した設定へ戻る。PrefixとSuffixはPropertiesへの文字入力中にCanvasへ即時反映する。Canvas上の寸法ラベルはParameter名や入力式を表示せず、常にprefix、評価後の数値、suffixを表示する。Upper／Lower toleranceは現在のPropertiesには表示しない。読み取り専用寸法は実測値を括弧付きで表示し、値は編集できない。寸法の配置はCanvas上でdragでき、dragでは配置だけを変更してColor、Prefix、Suffix、Precisionおよび各寸法Appearance属性を保持する。表示中のSketchに属する寸法は、Sketchがアクティブかどうかにかかわらず描画する。非アクティブSketchの寸法は通常時にも所属Sketch名および参照可否をpointer付近へ表示できるが、寸法自体はhover強調しない。非アクティブSketchのGeometryおよびBlock Instanceも同じ所属・参照可否表示を行うが、図形のhover強調およびselection対象にはしない。

標準矢印の先端補正は矢羽まで外側へ平行移動させず、視覚上の先端から矢羽までの寸法線方向距離を設定した端末サイズに保つ。したがって外側へ反転した場合も、矢羽より後方には端末サイズの0.5倍に相当する軸線が見え、先端補正によって軸線が短く見える状態にはしない。

## 6. Annotation

AnnotationはDocument直下またはBlock Definition直下の`annotations[]`に保存されるが、各要素は必ずRoot以外の1つのSketchへ`sketchId`で所属する。新規Leader／Free Textは作成時のactive Sketchへ所属し、Root選択中は作成できない。Sketchを非表示にすると所属Annotationも非表示になる。Annotationは固有のAppearanceを維持し、Sketch一般Appearanceは継承しない。

Propertiesは「基本情報」「内容」「外観」の3区分とする。基本情報には種類、ID、読み取り専用の所属Sketch、内容には本文を表示する。外観ではLeaderとFree Textのどちらも表示、共通カラーパレットによる色、文字高さ、フォント（ゴシック体／明朝体／等幅）、太字、斜体、横位置（左／中央／右）、文字回転を編集できる。文字高さはmmで保持し、`textHeight × 96 / 25.4 / viewport.scale`を描画高さとするため、zoomに依存せず画面上で概算mmの大きさを維持する。色は文字へ適用し、Leaderでは線と端末記号にも同じ色を適用する。

### Leader

Geometryを1つ選択してLeaderを開始するか、Leaderコマンド後に対象Geometryを選択する。参照先は所属Sketchと同じSketchのGeometryに限り、Block Projectionの場合は最上位Instanceの配置Sketchを所属先とする。GeometryRefでアンカーを保持し、終点とelbowをCanvas上に配置する。選択後は移動、Properties編集、Delete、Undo/Redoができる。Leader固有の外観として線幅、実線／破線／一点鎖線／点線、標準矢印／塗りつぶし矢印／点／なしの端末記号、概算mmの端末サイズを編集できる。

### Free Text

TextコマンドでCanvas位置を指定し、文字列を入力する。Toolbar buttonは単独の`T`ではなく、枠内の`A`と文字列を表すテキストボックス型SVGを使用し、Sketch TreeのFree Text rowにも同じSVGを使用する。位置、表示、本文と共通文字外観を編集できる。

Annotationはsolver変数やConstraintを変更しない。通常時の非アクティブSketch所属AnnotationはCanvasからhover、選択、dragできない。Sketch Treeのrow clickでは所属Sketchを表示してactive化した後に選択できる。Propertiesには読み取り専用の所属Sketchを表示する。

Geometry、Block、Annotationは同じSketch内で混在複数選択できる。Copy／Cut／Pasteでは選択Annotationもpayloadへ含め、貼り付け先Sketchへ新しい`ANn`で所属させる。Free Textはpaste offset分移動する。Leaderは参照GeometryまたはBlock Instanceも同時選択されている場合だけコピーでき、貼り付け時に参照を新IDへ書き換える。

Block化では明示選択したAnnotationだけを取り込む。選択Leaderの参照先が未選択、または非選択Leaderが選択Geometryを参照している場合は対象名を示して中止する。Annotationはorigin分をローカル座標へ変換し、新しい内部Sketchへ所属させる。Free TextだけのAnnotation-only Blockを許可する。

Block Definition内部AnnotationはBlock Editorで通常Annotationとして編集する。ProjectionではIDを`BI1/AN1`、入れ子を`BI1/BI2/AN1`として、座標、Leader形状、文字位置、GeometryRef、文字回転へ変換を合成する。有効内部SketchとInstance Appearance Overrideのvisible、color、lineWidthを適用する。配置先Canvasでのclickは投影Annotation単体でなくBlock Instance全体を選択する。

## 7. Hatch表示

Hatchのspacingは画面上の概算mmで保持し、`spacing × 96 / 25.4 / viewport.scale`をモデル間隔として描画する。pattern位相はDocumentのワールド原点またはBlockローカル原点を基準にする。`parallel`は指定角度の1方向、`cross`は指定角度とその90°方向の2組を同じspacingで描画する。`solid`はcolorで外周内を塗り、穴はeven-odd規則で除外する。hover／選択では線色または塗り色を一時強調する。HatchはGeometryより先に描画するため、塗りつぶし時も境界Geometryが手前に残る。非アクティブSketchでは表示だけを行い、Canvas hover・selection対象にしない。無効境界ではpatternも塗りも描画しない。

## 8. View State

View StateはDocumentと分離し、少なくとも次を持つ。

- Geometry ID表示
- Constraint Status View

背景Gridは表示しない。Geometry IDはViewメニューで切り替える。Geometryを直接選択・hoverしたときは対象IDを補助表示できるが、Sketch treeのSketch hoverではGeometry IDを表示しない。Block Instance全体の選択・hoverだけでも内部ProjectionのGeometry IDを一括表示しない。Geometry IDとConstraint Status Viewは保存・Undo/Redo対象外である。
