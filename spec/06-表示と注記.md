# 表示と注記

## 1. 単一Canvas

Geometry、Constraint Dimension、Document Annotationは同じCanvasに描画する。表示専用モードおよびSheetは存在しない。

## 2. Appearanceの継承

各プロパティは独立して次の順に解決する。

```text
Document Default
  → 親Sketchから対象Sketch
    → Geometry
      → Block Instance Appearance Override
```

Block Definition内部ではDefinition内のSketchとGeometryを解決した後、外側のInstance Overrideを適用する。入れ子Blockでは最外側の配置Instance Overrideを最後に適用する。

補助Geometryは既定で一点鎖線、細線、低い不透明度を使う。SketchまたはGeometryで明示したAppearanceはそのプロパティを上書きする。

選択・hoverは一時的な強調表示であり、Appearanceデータを変更しない。

## 3. visible

`visible=false`のGeometryは通常表示とhit testから除外する。親Sketchが非表示なら子Geometryも通常表示しない。SpaceによるConstraint Status Viewではvisibleに関係なく表示する。

## 4. Constraint Status View

Spaceを押している間だけ次を行う。

- Geometryを完全拘束、支持位置拘束、未拘束、矛盾の状態色で描く。
- 非表示Geometryを含めて表示する。
- endpointや参照点など通常省略される状態確認用Pointを表示する。

Spaceを離すかwindowがfocusを失うと通常表示へ戻る。View Stateだけを変更し、Document、履歴、Selectionは変更しない。

## 5. Constraint Dimension

すべての寸法はConstraintに属する。Propertiesから値と次の表示属性を編集できる。

- Visible
- Precision
- Prefix / Suffix
- Upper / Lower tolerance
- Arrows
- Extension lines

読み取り専用寸法は実測値を括弧付きで表示し、値は編集できない。寸法の配置はCanvas上でdragできる。

## 6. Document Annotation

### Leader

Geometryを1つ選択してLeaderを開始するか、Leaderコマンド後に対象Geometryを選択する。GeometryRefでアンカーを保持し、終点とelbowをCanvas上に配置する。選択後は移動、Properties編集、Delete、Undo/Redoができる。

### Free Text

TextコマンドでCanvas位置を指定し、文字列を入力する。位置、表示、文字列、font size、colorを編集できる。

Document Annotationはsolver変数やConstraintを変更しない。

## 7. View State

View StateはDocumentと分離し、少なくとも次を持つ。

- Geometry ID表示
- Constraint Status View

背景Gridは表示しない。Geometry IDはViewメニューで切り替える。Geometry IDとConstraint Status Viewは保存・Undo/Redo対象外である。
