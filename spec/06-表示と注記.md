# 表示と注記

## 1. 単一Canvas

Geometry、Constraint Dimension、Sketch所属Annotationは同じCanvasに描画する。表示専用モードおよびSheetは存在しない。

## 2. Appearanceの継承

通常Geometryと補助GeometryのAppearanceは、互いに独立して次の順に解決する。

```text
通常Geometry:
Documentの一般Appearance既定
  → 対象Sketch自身の通常Appearance
    → Geometry
      → Block Instance Appearance Override

補助Geometry:
DocumentのConstruction Appearance既定
  → 対象Sketch自身のConstruction Appearance
    → Geometry
      → Block Instance Appearance Override
```

一般Appearanceは、Document設定でもSketch設定でもConstruction Appearanceへ継承しない。親SketchのAppearanceは子Sketchへ継承しない。Block Definition内部のSketchも対応するDocument既定を基底として自身の明示設定とGeometryを解決した後、外側のInstance Overrideを適用する。入れ子Blockでは最外側の配置Instance Overrideを最後に適用する。

補助GeometryはDocumentのConstruction Appearanceを直接継承し、所属Sketch自身のConstruction AppearanceまたはGeometryで明示したAppearanceがそのプロパティを上書きする。初期基底は一点鎖線、細線、低い不透明度であり、補助Lineでは端部のはみ出しと端部の点を有効にする。端部のはみ出しを無効にした補助Lineは元の端点間だけを描画し、寸法補助線のclearanceにも固定12pxのはみ出しを加算しない。

選択・hoverは一時的な強調表示であり、Appearanceデータを変更しない。アクティブSketchについては、CanvasとSketch TreeのObject rowのどちらを起点にしても、対象GeometryまたはBlockにCanvas hoverと同じ青色と線幅の強調を使用する。Sketch TreeでLineを直接参照する拘束をhoverまたは選択した場合はLine本体を強調し、そのLineの形状を定義するendpointは強調対象へ含めない。点‐線拘束のPointなど、拘束が直接参照するPointは強調する。Sketch TreeのSketch hoverでは通常GeometryとBlock ProjectionのどちらにもLine endpoint markerを表示しない。Block ProjectionはLine・Circle・Arcのstrokeだけを強調し、explicit Pointや中心Pointを含むPoint markerは表示しない。非アクティブSketchのCanvas hoverは図形を強調せず、対象の所属と参照可否だけを表示する。

固定されたexplicit Pointは、通常時は非固定Pointと同じ通常表示とする。Point自身をhoverまたは選択した間だけ赤色で強調し、日本語で`固定`、英語で`Fixed`のlabelをPointのそばに表示する。

## 3. visible

`visible=false`のGeometryは通常表示とhit testから除外する。Sketchの非表示設定はそのSketch自身のGeometryへだけ適用し、子Sketchへは波及しない。Constraint Status Viewではvisibleに関係なく表示する。

## 4. Constraint Status View

ToolbarのView buttonを有効にしている間、またはSpaceを押している間は次を行う。

- Geometryを完全拘束、支持位置拘束、未拘束、矛盾の状態色で描く。
- 非表示Geometryを含めて表示する。
- Dimension AppearanceのVisibleがfalseの寸法も含め、表示中Sketchに属するすべての寸法を表示する。
- 非アクティブSketchの寸法は、非アクティブGeometryと同じ灰色`#cbd5e1`で描く。アクティブSketchの寸法は設定済みのDimension Appearance色を維持する。
- explicit Pointや中心Pointなど、状態確認に必要なPointを表示する。
- Line endpointの丸markerは通常は表示せず、アクティブSketchの端点をCanvas上で直接hoverしている間だけ通常表示と同じhover markerを表示する。補助LineのAppearanceによるendpoint markerは表示しない。

Toolbar buttonまたはView menuのcheckboxは、clickごとに固定表示を切り替え、両者のON/OFF表示を同期する。Spaceは押下中だけの一時表示であり、固定状態とは独立する。Space押下中もToolbar buttonとView menu checkboxは実際の表示状態をONとして示す。固定表示中にSpaceを押して離しても表示を維持する。windowがfocusを失った場合はSpace由来の一時表示だけを解除する。View Stateだけを変更し、Document、履歴、Selectionは変更しない。

## 5. Constraint Dimension

すべての寸法はConstraintに属する。寸法のAppearanceはDocumentのDimension Appearance、所属Sketch自身のDimension Appearance、各寸法で明示したfieldの順に解決する。親SketchのDimension Appearanceは継承しない。Block Definition内の寸法も同じDocument既定を使用する。Propertiesから値と次のAppearance属性を編集できる。

- Visible
- Color
- Precision
- Prefix / Suffix
- Arrows
- Extension lines
- Extension line overshoot / origin gap
- Arrowhead length / opening angle
- Dimension text height / gap from dimension line

Colorは寸法線、矢印、補助線、ラベルへ適用する。寸法補助線の突出量は寸法線を越える長さ、起点すき間は対象Geometryから補助線開始位置までの間隔とする。矢印の長さは寸法線方向の長さ、開き角は矢印を構成する2辺のなす角度とする。寸法文字の高さと寸法線との間隔は、線形寸法、角度寸法など共通表示へ適用する。長さと文字の設定値はzoomに依存しない画面px、開き角は度で保持する。個別Colorを空にすると所属Sketchから継承した設定へ戻る。PrefixとSuffixはPropertiesへの文字入力中にCanvasへ即時反映する。Canvas上の寸法ラベルはParameter名や入力式を表示せず、常にprefix、評価後の数値、suffixを表示する。Upper／Lower toleranceは現在のPropertiesには表示しない。読み取り専用寸法は実測値を括弧付きで表示し、値は編集できない。寸法の配置はCanvas上でdragでき、dragでは配置だけを変更してColor、Prefix、Suffix、Precisionおよび各寸法Appearance属性を保持する。表示中のSketchに属する寸法は、Sketchがアクティブかどうかにかかわらず描画する。非アクティブSketchの寸法は通常時にも所属Sketch名および参照可否をpointer付近へ表示できるが、寸法自体はhover強調しない。非アクティブSketchのGeometryおよびBlock Instanceも同じ所属・参照可否表示を行うが、図形のhover強調およびselection対象にはしない。

## 6. Annotation

AnnotationはDocument直下またはBlock Definition直下の`annotations[]`に保存されるが、各要素は必ずRoot以外の1つのSketchへ`sketchId`で所属する。新規Leader／Free Textは作成時のactive Sketchへ所属し、Root選択中は作成できない。Sketchを非表示にすると所属Annotationも非表示になる。Annotationは固有のcolor、font size、line widthを維持し、Sketch一般Appearanceは継承しない。

### Leader

Geometryを1つ選択してLeaderを開始するか、Leaderコマンド後に対象Geometryを選択する。参照先は所属Sketchと同じSketchのGeometryに限り、Block Projectionの場合は最上位Instanceの配置Sketchを所属先とする。GeometryRefでアンカーを保持し、終点とelbowをCanvas上に配置する。選択後は移動、Properties編集、Delete、Undo/Redoができる。

### Free Text

TextコマンドでCanvas位置を指定し、文字列を入力する。位置、表示、文字列、font size、colorを編集できる。

Annotationはsolver変数やConstraintを変更しない。通常時の非アクティブSketch所属AnnotationはCanvasからhover、選択、dragできない。Sketch Treeのrow clickでは所属Sketchを表示してactive化した後に選択できる。Propertiesには読み取り専用の所属Sketchを表示する。

Geometry、Block、Annotationは同じSketch内で混在複数選択できる。Copy／Cut／Pasteでは選択Annotationもpayloadへ含め、貼り付け先Sketchへ新しい`ANn`で所属させる。Free Textはpaste offset分移動する。Leaderは参照GeometryまたはBlock Instanceも同時選択されている場合だけコピーでき、貼り付け時に参照を新IDへ書き換える。

Block化では明示選択したAnnotationだけを取り込む。選択Leaderの参照先が未選択、または非選択Leaderが選択Geometryを参照している場合は対象名を示して中止する。Annotationはorigin分をローカル座標へ変換し、新しい内部Sketchへ所属させる。Free TextだけのAnnotation-only Blockを許可する。

Block Definition内部AnnotationはBlock Editorで通常Annotationとして編集する。ProjectionではIDを`BI1/AN1`、入れ子を`BI1/BI2/AN1`として、座標、Leader形状、文字位置、GeometryRef、文字回転へ変換を合成する。有効内部SketchとInstance Appearance Overrideのvisible、color、lineWidthを適用する。配置先Canvasでのclickは投影Annotation単体でなくBlock Instance全体を選択する。

## 7. View State

View StateはDocumentと分離し、少なくとも次を持つ。

- Geometry ID表示
- Constraint Status View

背景Gridは表示しない。Geometry IDはViewメニューで切り替える。Geometryを直接選択・hoverしたときは対象IDを補助表示できるが、Sketch treeのSketch hoverではGeometry IDを表示しない。Block Instance全体の選択・hoverだけでも内部ProjectionのGeometry IDを一括表示しない。Geometry IDとConstraint Status Viewは保存・Undo/Redo対象外である。
