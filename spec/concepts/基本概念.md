# 基本概念

## 1. 製品モデル

Jot2Dはブラウザ上で動作する2DパラメトリックCADである。Documentを保存の単位とし、Sketchで作図・編集対象をまとめる。作図、拘束、表示属性、注記は同じCanvasで扱い、表示専用の別モードやSheetは持たない。

```text
Document
├─ Units（長さはmm固定）
├─ Document Appearance defaults
├─ Document Parameters
├─ Sketch hierarchy
│  ├─ Root／子Sketch
│  ├─ Geometry
│  ├─ Constraint / Constraint Dimension
│  ├─ Block Instance
│  ├─ Hatch
│  ├─ Reference Image
│  └─ Annotation（Leader／Free Text）
├─ Block Definitions
│  ├─ Definition-local Parameters
│  ├─ internal Sketch / Geometry / Constraint / Block Instance
│  └─ internal Sketch所属Hatch／Annotation／Reference Image
```

これは役割と関係の概略であり、保存fieldの一覧ではない。完全な保存構造は[データモデルと永続化](../data/保存形式.md)、Sketchの所属条件は[スケッチ](../04-スケッチ.md)に定義する。子Sketchの外観継承は[表示と注記](../contracts/外観.md#1-appearanceの継承)を参照する。

## 2. 用語と役割

| 用語 | 役割 | 詳細仕様 |
| --- | --- | --- |
| Document | 1つの保存対象。Geometry、Constraint、Sketch、Block、Parameter、Appearance、Hatch、Annotation、Reference Imageを持つ | [保存構造](../data/保存形式.md) |
| Sketch | Geometryと拘束をまとめる作図・編集・solveの単位。階層を持つ | [Sketch](../04-スケッチ.md) |
| Geometry | Point、Line、Circle、Arc、Spline、およびBlock Projectionとして扱う形状 | [Geometry](../03-Geometryと拘束.md) |
| Constraint | Geometryの成立条件。solverが座標・半径・角度・Block配置を解く | [拘束](../03-Geometryと拘束.md) |
| Constraint Dimension | Constraintの値と表示属性を扱う。寸法はConstraintに属し、注記寸法という別Objectは存在しない | [寸法](../operations/拘束と寸法.md#4-寸法の表示と配置) |
| Parameter | 名前と数式を持つスカラー値。Parameter・拘束寸法・参照寸法はDocumentまたはBlock Definition固有の名前空間で相互参照する | [Parameter](../08-Parameter.md) |
| Block Definition | ローカル座標、内部SketchとGeometry等を持つ再利用可能な定義 | [Block](../operations/Block.md) |
| Block Instance | Definitionの配置・回転・有効内部Sketchを指定する配置単位 | [Block](../operations/Block.md) |
| Block Projection | Instanceからワールド座標へ導出した読み取り専用Geometry | [Projection](../operations/Block.md#3-projection) |
| Appearance | Geometryの通常表示を決める属性。visible、color、lineType、lineWidthと、補助Line用のendpointOverhang／endpointMarkersを持つ | [外観](../contracts/外観.md#1-appearanceの継承) |
| Hatch | 通常Geometryが作る閉領域を参照し、境界変形に追従する平行線・クロス・色塗りつぶし | [Hatch](../09-ハッチング.md) |
| Sketch所属Annotation | 作図可能Sketchに所属するLeader（引出線）またはFree Text（自由テキスト）。Geometryを変形しない | [注記](../operations/注記.md#1-annotation) |
| Reference Image | 作図可能Sketchに所属する埋め込み画像。Geometry背面の手動トレース用下地で、Constraint・solver・snapには参加しない | [参照画像](../operations/参照画像.md) |
| 派生Geometry Instance | 参照元から仮想的なGeometryを動的生成するスケッチ投影・ミラー・直線パターン。派生側に独立した座標を保存しない | [派生Instance](../operations/派生Instance.md) |
| Interaction State | 選択、作図、拘束入力、注記配置など現在の操作状態 | [入力・操作状態](../ui/入力と操作状態.md#1-selectionと操作状態) |
| View State | Geometry IDや拘束状態表示など、一時的な表示状態 | [View State](../ui/表示とビュー操作.md#4-view-state) |

派生Geometryを介した参照元の編集可否は種類と参照経路によって異なる。[派生Instanceの共通モデル](../operations/派生Instance.md#1-共通モデル)を参照する。

## 3. Documentと操作・表示状態

Interaction StateとView StateはDocumentデータから分離する。履歴の対象と操作単位は[編集の確定と失敗](../contracts/編集と履歴.md)、保存するデータは[データモデルと永続化](../data/保存形式.md)に従う。

通常表示・拘束状態表示の切替と優先順位は[表示と注記](../ui/表示とビュー操作.md)、画面構成・操作の入口・エラー通知は[UI・操作・履歴](../ui/画面構成.md)に定義する。
