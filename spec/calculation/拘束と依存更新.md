# 拘束と依存更新

計算対象・受入れ・依存順序を記録する。確定時の復元範囲と履歴は[編集と履歴](../contracts/編集と履歴.md)に従い、操作別の違いを維持する。

## 1. 収束と受入れ

ソルバーは数値ヤコビアンと減衰付き最小二乗法を使う。通常の収束許容誤差は `1e-7`、拘束追加・編集の受入れ判定は概ね `1e-4` である。`lambda上限` や最大反復で停止しても、総残差が有限かつ受入れ許容誤差以下なら、操作は成立として扱う。

通常の反復計算では、位置の更新量上限に加え、Arcの開始角・終了角の1反復あたりの更新量を最大 `π/2` に制限する。いずれかの角度が上限を超える場合は更新ベクトル全体を同じ比率で縮小し、連動する位置・半径の更新方向を維持する。接線拘束付近で角度が複数周飛ぶことを防ぎ、長穴の中心間距離を大きく変更しても円弧端点の一致と有効な円弧形状を維持する。

## 2. ドラッグのpreview計算

ドラッグ中は選択に関係する拘束連結成分だけを優先して local solve し、必要な場合に全 Sketch solve へフォールバックする。

Lineのドラッグは、拘束構成とPointer移動量に応じて次のように扱う。

| 条件 | 処理 |
| --- | --- |
| Line–Circle中心距離寸法だけで拘束された連結成分内のLine本体 | ドラッグ対象Lineの両端をPointer位置へ固定し、残りの変数だけをlocal solveする |
| 上記以外で、フレーム間のPointer移動が大きいLine | 反復上限を拡張した全Sketch solveでPointer位置への一括追従を先に試みる |
| 大移動時の一括追従が収束しない場合 | 1回のpreview内で移動経路を有限個の小区間に分けて順にsolveする |

最初の処理では、Lineの両端は反復計算による追従遅れを生じさせず、Circle中心距離は残りのGeometry移動で維持する。大移動時の経路分割は、非線形拘束があってもPointer位置への追従量を維持するために行う。

## 3. Lineドラッグのtarget選択

Lineのドラッグでは、拘束構成に応じて次のtargetを使用する。

| 条件 | targetの選択 |
| --- | --- |
| 固定点を含み、残り自由度が1つの連結Geometryで、両端が自由なLine | 拘束Jacobian上の可動性が最も高い自由端点を代表targetとする |
| 中心と半径が拘束された同一円を共有する複数の独立した弦で、対象Lineの両端に現れる自由度が1つ | 連結成分全体に別の自由度があっても、同じ代表target処理を使用する |
| 上記以外で連結成分の自由度が複数ある通常のLine移動 | 両端targetを維持する |

代表targetを使う場合は、その端点のPointドラッグと同じ拘束solve経路で応答し、複数端点targetによる移動量の減衰を避ける。

## 4. Sketchの依存更新

参照先 Geometry は solve 変数に含めず、固定値として拘束式へ渡す。

参照元が変わった場合は、参照グラフをたどって依存 Sketch をトポロジカル順に solve する。各 Sketch は全参照元が確定した後に solve する。

読込時に復元できる参照拘束の範囲違反・循環は、[データモデルと永続化](../data/読込と互換性.md)のLOAD-02に従って無効状態で保持する。参照先Geometry自体を復元できない場合や、Block・派生Instanceの依存関係が不正な場合とは区別する。

## 5. Blockの配置とsolve変数

変換は次のとおりで、倍率と鏡像はない。

```text
world = rotate(local, rotation) + (x, y)
```

外部solve変数はInstanceの`x`、`y`と、自由回転時の`rotation`だけである。`fixed`は3自由度を固定し、直交回転ロック中は`rotation`をsolve変数に含めない。

Block内部Geometryの個別固定は配置先Sketchの外部拘束として評価する。`geometryFixed`はPointで位置の2残差、Circleで中心位置と半径の3残差、Arcで中心位置・半径・両端角度の5残差を持つ。角度残差は±πに正規化して固定時半径を乗じる。Lineは`lineFixed`の両端位置4残差、Arc端点は`arcEndpointFixed`の位置2残差を用いる。Projectionの参照から所有Instanceを拘束グラフへ含め、残差数ではなくJacobianのrankで自由度を判定する。BlockのPoint固定や中心固定のCircleには回転自由度が残り得る。

Definition 内部は通常 Sketch と同じく内部 Sketch ごとに solve する。Block Parameterの評価と反映順序は[式評価](./式評価.md#4-評価とsolve)に従う。

### 5.1 自由配置Geometry Instance

自由配置InstanceはBlock Definitionを作らず、同一Sketchの参照元Geometryを共有する。変換は`world = rotate(reflect(source - origin), rotation) + (x, y)`とする。`origin`は作成時に指定した座標、反転は回転前のX／Y符号反転であり、倍率は持たない。

`x`、`y`、`rotation`を同一Sketchのsolve変数へ追加する。派生側の拘束は生成Geometryの動的な座標を評価するため、参照元の形状変数と配置変数の両方に作用する。生成Pointや半径を独立したsolve変数にはしない。

Canvasからの形状ドラッグでは参照chain上の自由配置変換をsolve変数から除き、逆変換した参照元を編集する。Tree選択による全体移動では参照元Geometryと上流Instanceの変換、および移動対象の回転を変数から除く。local preview、全体fallback、mouse-upで同じ制限を使う。配置変数・鏡像設定も失敗時の状態復元とUndo／Redoへ含める。

Block Definition全体の原点移動では、内部の自由配置Instanceの`origin`と配置`x`、`y`を同じ移動量だけ補正する。

## 6. 拘束状態

Geometry は解析結果により次の状態で描き分ける。

| 状態 | 意味 |
| --- | --- |
| 完全拘束 | 対象自由度が拘束されている |
| 支持位置拘束 | 固定 Geometry の影響で位置が拘束されている |
| 未拘束 | 1つ以上の自由度が残る |
| 矛盾 | solve 失敗、非有限値、または不安定な拘束がある |

## 7. 失敗時の扱い

依存Sketchのsolve失敗時の扱いは、[編集の確定と失敗](../contracts/編集と履歴.md)の操作別の復元範囲に従う。一般の参照更新と、ドラッグ・Parameter適用の操作全体の確定を区別する。

## 8. 中心線

平行な2本のLineでは、両Lineを無限に延長した支持直線に平行かつ等距離な支持直線へ中心線を置く。2つのPointでは、2点を結ぶ線分の垂直二等分線を中心線の支持直線とする。

どちらも中心線の支持位置と方向だけを拘束し、中心線の長さと両端点の支持直線方向位置は拘束しない。このため作成後も各端点を支持直線上で独立して移動できる。

## 9. 対称

対称拘束は対象の種類ごとに次の量だけを拘束する。

### Point対称

Point対称は、2 Pointの中点を対称軸上へ置き、2 Pointを結ぶ方向を対称軸へ直交させる。

### Line対称

Line対称は、各Lineを両方向へ無限に延長した支持直線どうしを対称軸に対する鏡像にする。拘束するのは支持直線の方向と位置だけであり、Lineの中点、長さ、始点・終点の対応や各端点の支持直線方向位置は拘束しない。

一方のLineと対称軸を固定した場合も、もう一方の各端点には支持直線方向の独立した自由度が残り、一端だけを伸縮できる。

既存JSONの`lineSymmetry.reversed`は互換的に往復保存するが、端点対応を表す拘束条件としては使用しない。

### Arc対称

Arc対称は、2 Arcの中心位置を対称にし、半径を一致させる。開始角・終了角および端点位置は対称拘束の対象にせず、それぞれ独立して変更できる。

## 10. 距離寸法

### LineとCircleの中心距離

測定対象は有限線分までの最短距離や円周までのすき間ではなく、Lineを両方向へ無限に延長した支持線からCircle中心までの垂直距離である。

### 同心半径差

入力値は2つの半径差の絶対値である。作成時の大小関係を保持したまま半径差を拘束し、同じ拘束の中心X差・中心Y差を0にすることで同心関係も維持する。
