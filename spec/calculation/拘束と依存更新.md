# 拘束と依存更新

計算対象・受入れ・依存順序を記録する。確定時の復元範囲と履歴は[編集と履歴](../contracts/編集と履歴.md)に従い、操作別の違いを維持する。

## 1. 収束と受入れ

ソルバーは数値ヤコビアンと減衰付き最小二乗法を使う。通常の収束許容誤差は `1e-7`、拘束追加・編集の受入れ判定は概ね `1e-4` である。`lambda上限` や最大反復で停止しても、総残差が有限かつ受入れ許容誤差以下なら、操作は成立として扱う。

通常の反復で補正後の総残差が改善しない場合、補正前の座標へ戻し、更新ベクトル全体を半分にして最大8回再試行する。短い接線を含む形状の縮小でも、連動した補正方向を保ちながら収束させる。改善しない場合は座標を復元して減衰を強める。拘束条件や受入れ許容誤差は緩和しない。

位置と角度は、角度変化を半径に応じた移動距離へ換算して、自由度解析と反復補正の両方で尺度をそろえる。数値微分は中央差分と半分の刻みの外挿を使い、角度の刻みは累積周回数に比例させない。上下限で刻みを制限した変数では実際の差分区間を分母に使う。依存する拘束だけを再評価し、動的な参照や独自の拘束では全変数への依存を維持する。

位置・半径の数値微分の刻みは、依存するLineの長さとCircle／Arcの半径の最小値の`1e-3`倍でも上限を設ける。ただし座標値に対する浮動小数点の分解能を下回らない。原点から離れた微小な形状で、差分計算が線の反対側をまたいで方向や微分値を誤ることを防ぐ。

Line角度拘束は、各solve開始時の2 Lineの符号付き角度から回転方向を保持し、その方向の目標角度との差を±πへ正規化して解く。寸法の大きさが同じという理由で、肩部などを反対向きの角度へ反転させない。保存する角度値と`startFlip`／`endFlip`は変更しない。

明示された一致・点上・接線の組合せによって接点が定まる場合、距離の残差が接点で二次的にしか変化しない式を、同値な接点方向の式へ置き換えて解く。接線でつながる元円弧同士、および元LineとArcのオフセットにもこの関係を引き継ぐ。チェーンの向きに合わせて、オフセットArcの接続端角度を元Arcの接点角度に対応させる。近くに見えることだけでは接線や一致を追加しない。保存する拘束、寸法値、無効状態は変更しない。

通常の反復計算では、位置の更新量上限に加え、Arcの開始角・終了角の1反復あたりの更新量を最大 `π/2` に制限する。いずれかの角度が上限を超える場合は更新ベクトル全体を同じ比率で縮小し、連動する位置・半径の更新方向を維持する。接線拘束付近で角度が複数周飛ぶことを防ぎ、長穴の中心間距離を大きく変更しても円弧端点の一致と有効な円弧形状を維持する。

## 2. ドラッグのpreview計算

ドラッグ中は選択に関係する拘束連結成分だけを優先して local solve し、必要な場合に全 Sketch solve へフォールバックする。

Lineのドラッグは、拘束構成とPointer移動量に応じて次のように扱う。

| 条件 | 処理 |
| --- | --- |
| Line–Circle中心距離寸法だけで拘束された連結成分内のLine本体 | ドラッグ対象Lineの両端をPointer位置へ固定し、残りの変数だけをlocal solveする |
| 上記以外で、フレーム間のPointer移動が大きいLine | guided local solveで一括追従を試み、成立しなければ反復上限を拡張した全Sketch solveを試みる |
| 大移動時の一括追従が収束しない場合 | 1回のpreview内で移動経路を有限個の小区間に分けて順にsolveする |

最初の処理では、Lineの両端は反復計算による追従遅れを生じさせず、Circle中心距離は残りのGeometry移動で維持する。大移動時の経路分割は、非線形拘束があってもPointer位置への追従量を維持するために行う。

previewのPointer目標には画面上の許容差を使うが、モデルの拘束残差は `1e-4` 以下でなければ受け入れない。半径が下限に達している場合は、連動する変数を含めて可動方向を再計算する。下限へ近づく補助変数を予め保持する場合は、ドラッグ対象に見える可動方向が失われないことを確認する。予測が下限を越えることだけを理由に、まだ到達できるドラッグ方向を除かない。

1つの可動座標を持つPoint、または複数Pointを直接targetにするguided previewでは、対象点の移動量をPointer要求で制限し、連動する変数の移動量には通常のsolve刻み上限を使う。小さな中心移動に大きな周辺形状の変化が必要な場合も、成分全体の移動量をPointer移動量で一律に縮めて追従を減衰させない。拘束面への補正と、到達不能な目標に対する直前形状からの有限移動は引き続き適用する。

Circle／Arcの円周ドラッグは、中心移動と半径変化の両方を含む円周上の応答を目標とする。端点ドラッグも、角度に連動する中心・半径の移動を考慮する。点や円周の到達範囲をPointerが越えた場合は、拘束を満たしPointerとの距離を改善する小さな移動だけを採用し、改善できなければ直前の形状を保つ。移動範囲の端を越えるために拘束を緩めたり、別の解へ大きく飛んだりしない。

## 3. Lineドラッグのtarget選択

Lineのドラッグでは、拘束構成に応じて次のtargetを使用する。

| 条件 | targetの選択 |
| --- | --- |
| 固定点を含む連結Geometryで、対象Lineの両端に現れる自由度が1つ | 拘束Jacobian上の可動性が最も高い自由端点を代表targetとする。連結成分の別の場所にある自由度はこの判定に含めない |
| 上記以外で連結成分の自由度が複数ある通常のLine移動 | 両端targetを維持する |

代表targetを使う場合は、その端点をPointドラッグと同じ単一targetとして扱い、複数端点targetによる移動量の減衰を避ける。向きが自由で、縦横の平行移動が独立にはできないLineでは、Pointドラッグと同じく直前の形状を線形化の基準にする。向きが拘束されているLine、または縦横の平行移動が独立に可能なLineでは、代表targetであっても以下の開始時基準を維持し、微小な補正で可動方向を失わないようにする。

Lineのguided previewは、ドラッグ開始時の形状を線形化の基準にする。直前の微小な補正を累積させて別の自由度を失うことを防ぎ、同じPointer位置へ戻したときに同じ形状を求める。向きが拘束されているLine、または縦横の平行移動が独立に可能なLineでは、左右だけ・上下だけの移動で、移動しない軸を追加の固定条件にせず、拘束維持に必要な端点の伸縮を許す。移動する軸の独立した座標目標を補正中も保持する。自由な平行移動ができないLineではPointerを可動方向へ投影した座標を使用する。回転によって開始時の線形近似から外れ、端点移動が入力に対して大きくなる場合は、直前の有効な形状から補正を継続する。Pointerの座標をそのまま端点へ強制して回転を増幅させない。

## 4. Sketchの依存更新

参照先 Geometry は solve 変数に含めず、固定値として拘束式へ渡す。

参照元が変わった場合は、参照グラフをたどって依存 Sketch をトポロジカル順に solve する。各 Sketch は全参照元が確定した後に solve する。

読込時に復元できる参照拘束の範囲違反・循環は、[データモデルと永続化](../data/読込と互換性.md)のLOAD-02に従って無効状態で保持する。参照先Geometry自体を復元できない場合や、Block・派生Instanceの依存関係が不正な場合とは区別する。

## 5. Blockの配置とsolve変数

変換は次のとおりで、倍率と鏡像はない。

```text
world = rotate(local, rotation) + (x, y)
```

外部solve変数はInstanceの`x`、`y`と、自由回転時の`rotation`だけである。`fixed`は3自由度を固定し、直交回転ロック中は`rotation`をsolve変数に含めない。

Block内部Geometryの個別固定は配置先Sketchの外部拘束として評価する。`geometryFixed`はPointで位置の2残差、Circleで中心位置と半径の3残差、Arcで中心位置・半径・両端角度の5残差を持つ。角度残差は±πに正規化して固定時半径を乗じる。Lineは`lineFixed`の両端位置4残差、Arc端点は`arcEndpointFixed`の位置2残差を用いる。Projectionの参照から所有Instanceを拘束グラフへ含め、残差数ではなくJacobianのrankで自由度を判定する。BlockのPoint固定や中心固定のCircleには回転自由度が残り得る。

Definition 内部は通常 Sketch と同じく内部 Sketch ごとに solve する。Block Parameterの評価と反映順序は[式評価](./式評価.md#4-評価とsolve)に従う。

### 5.1 同期インスタンス

同期インスタンスはBlock Definitionを作らず、同一Sketchの参照元Geometryを共有する。変換は`world = rotate(reflect(source - origin), rotation) + (x, y)`とする。`origin`は作成時に指定した座標、反転は回転前のX／Y符号反転であり、倍率は持たない。

`x`、`y`、`rotation`を同一Sketchのsolve変数へ追加する。派生側の拘束は生成Geometryの動的な座標を評価するため、参照元の形状変数と配置変数の両方に作用する。生成Pointや半径を独立したsolve変数にはしない。

Canvasからの形状ドラッグでは参照chain上の同期インスタンス変換をsolve変数から除き、逆変換した参照元を編集する。全体選択状態で開始するドラッグでは参照元Geometryと上流Instanceの変換、および移動対象の回転を変数から除く。local preview、全体fallback、mouse-upで同じ制限を使う。配置変数・鏡像設定も失敗時の状態復元とUndo／Redoへ含める。ミラー／直線パターンの全体移動は、生成Geometry上の代表点（Lineは押下位置の線分内比率、Pointは自身、Circle／Arcは中心、Splineは先頭通過点）の目標変位を、拘束Jacobianのnullspace上で実変数の移動目標へ変換する。物理的な変数移動量が小さい解を用い、既存のguided dragで拘束を維持する。参照元と上流変換は変数から除外し、移動対象の軸・方向Lineの自由度を使用する。設定値や参照は変更しない。

Block Definition全体の原点移動では、内部の同期インスタンスの`origin`と配置`x`、`y`を同じ移動量だけ補正する。

## 6. 拘束状態

Geometry は解析結果により次の状態で描き分ける。

| 状態 | 意味 |
| --- | --- |
| 完全拘束 | 対象自由度が拘束されている |
| 支持位置拘束 | 固定 Geometry の影響で位置が拘束されている |
| 未拘束 | 1つ以上の自由度が残る |
| 矛盾 | solve 失敗、非有限値、または不安定な拘束がある |

自由度は行・列のピボットを選択したrank解析で求める。許容範囲内の残差を含む状態では、近傍の拘束面へ一時的に補正して解析し、モデル座標は必ず元へ戻す。Lineの支持位置判定には、同じ線形化位置で求めた法線を使う。解析だけで図形や履歴を変更しない。非有限な残差を完全拘束として扱わない。

自由度は現在の解の近傍で動ける量を表し、拘束条件を満たす形状が全体で一意であることを保証しない。非線形な拘束系には、自由度0でも互いに離れた複数の解が存在し得る。別の解への移動を、未拘束の自由度とはみなさない。新規拘束が既存拘束とともにsolveできても、solve後にrank寄与がなく重複と判定された場合は、通常の重複処理に従って元の形状・履歴を維持する。

寸法の読み取り専用化に使う冗長拘束の判定でも、許容範囲内の残差を近傍の拘束面へ一時的に補正してから各拘束のrank寄与を調べる。接触部分に残る微小な角度誤差を独立した拘束として数え、可動な距離を確定済みと誤判定しない。判定後はモデル座標を必ず復元し、図形・寸法値・履歴を変更しない。

## 7. 失敗時の扱い

依存Sketchのsolve失敗時の扱いは、[編集の確定と失敗](../contracts/編集と履歴.md)の操作別の復元範囲に従う。一般の参照更新と、ドラッグ・Parameter適用の操作全体の確定を区別する。

## 8. 中心線

平行な2本のLineでは、両Lineを無限に延長した支持直線に平行かつ等距離な支持直線へ中心線を置く。2つのPointでは、2点を結ぶ線分の垂直二等分線を中心線の支持直線とする。

どちらも中心線の支持位置と方向だけを拘束し、中心線の長さと両端点の支持直線方向位置は拘束しない。このため作成後も各端点を支持直線上で独立して移動できる。

## 9. 対称

対称拘束は対象の種類ごとに次の量だけを拘束する。

### Point対称

Point対称は、2 Pointの中点を対称軸上へ置き、2 Pointを結ぶ方向を対称軸へ直交させる。

### Line対称

Line対称は、各Lineを両方向へ無限に延長した支持直線どうしを対称軸に対する鏡像にする。拘束するのは支持直線の方向と位置だけであり、Lineの中点、長さ、始点・終点の対応や各端点の支持直線方向位置は拘束しない。

一方のLineと対称軸を固定した場合も、もう一方の各端点には支持直線方向の独立した自由度が残り、一端だけを伸縮できる。

既存JSONの`lineSymmetry.reversed`は互換的に往復保存するが、端点対応を表す拘束条件としては使用しない。

### Arc対称

Arc対称は、2 Arcの中心位置を対称にし、半径を一致させる。開始角・終了角および端点位置は対称拘束の対象にせず、それぞれ独立して変更できる。

## 10. 距離寸法

### LineとCircleの中心距離

測定対象は有限線分までの最短距離や円周までのすき間ではなく、Lineを両方向へ無限に延長した支持線からCircle中心までの垂直距離である。

### 同心半径差

入力値は2つの半径差の絶対値である。作成時の大小関係を保持したまま半径差を拘束し、同じ拘束の中心X差・中心Y差を0にすることで同心関係も維持する。
