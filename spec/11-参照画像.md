# 参照画像

## 1. 目的と範囲

PNG、JPEG、WebPを作図の参照画像として読み込み、同じCanvas上で手動トレースできる。UI上のコマンド名は「画像を読み込み」とする。初期機能には自動トレースを含めない。

参照画像はRoot以外のactive Sketchに所属する。Block EditorでもDefinition内部Sketchごとの編集用参照画像として同じ操作を使用できるが、Block Instanceへは投影しない。

## 2. 読み込み

- 対応形式は`image/png`、`image/jpeg`、`image/webp`とし、file inputは`.png`、`.jpg`、`.jpeg`、`.webp`を受け付ける。
- 読み込み時に縦横比を維持する。長辺が3000pxを超える画像は、長辺3000px以下になるようCanvasで縮小してから保持する。
- 読み込み直後は画像の中心をCanvas表示領域の中心へ合わせ、縦横の約68%以内へ収まる一様scaleにする。小さい画像もトレース可能な表示寸法へ拡大する。
- 初期値は回転0°、不透明度50%、表示、位置ロック解除とする。

## 3. 表示と操作

参照画像はHatchおよび通常Geometryより先に描画し、Geometryを常に手前へ出す。所属Sketchの表示状態に連動し、非アクティブSketchでは表示だけを行う。

Canvas clickまたはSketch Treeの「画像」分類から選択できる。位置ロック解除中はCanvas dragで中心位置を移動できる。Propertiesでは名前、中心X／Y、幅、回転、不透明度、表示、位置ロックを編集する。幅の変更はpixel縦横比から単一scaleを更新し、高さは読み取り専用の派生値とするため、縦横比は常に維持する。位置ロック中は移動、幅、回転、2点縮尺設定を無効にするが、不透明度と表示は変更できる。

「2点から縮尺を設定」は選択画像上の2点を順に取得し、入力した正の実寸mmを2点間へ割り当てる。scaleは`実寸 / 画像pixel座標上の2点間距離`とし、1点目のworld位置を維持して画像中心を補正する。Escまたは実寸入力のcancelで変更せず終了する。

参照画像はGeometryではなく、Constraint、solver、snap、Hatch境界、Block化、Copy／Pasteの対象にしない。

## 4. 永続化

JSON version 18で導入し、現行version 21でもDocument直下と各Block Definitionに`referenceImages[]`を必須配列として保存する。

```text
referenceImages[]
  id                // IMGn
  name
  sketchId
  mimeType          // image/png | image/jpeg | image/webp
  dataUrl           // data:<mimeType>;base64,...
  pixelWidth        // 1..3000
  pixelHeight       // 1..3000
  x / y             // 画像中心のmm座標
  scale             // 正のmm/pixel
  rotation          // radian
  opacity           // 0..1
  visible
  locked
```

画像binaryはBase64 Data URLとして`.jot2d`内へ埋め込み、再読込時に復元する。version 17以前は`referenceImages: []`として移行する。version 18以降で配列、MIME、Data URL、pixel寸法、有限な配置値、正のscale、不透明度、boolean field、所属Sketchが不正な場合はDocument全体の読込を拒否して読込前状態を維持する。

追加、削除、移動、Properties変更、2点縮尺設定をDocumentのUndo／Redo対象にする。Block Editorではdraftとlocal履歴に同じBase64データを含め、完了時にDefinitionへ保存する。

## 5. テスト

`tests/e2e/reference-images.spec.js`でPNG／JPEG／WebP、初期fit、長辺3000px縮小、縦横比維持、Canvas移動、Properties、位置ロック、2点縮尺、表示／不透明度、Undo／Redo、Base64 round-trip、version 17移行、Block Editor保存を検証する。
