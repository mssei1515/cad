# UI・操作・履歴

## 1. 画面構成

画面は次の領域で構成する。

- 上部: Document 名、Geometry Mode / Presentation Mode 切替、Presentation Sheet
- 左レール: Undo/Redo、保存・読込、モード別ツール
- Canvas: Geometry と注記の描画・直接操作
- Canvas 上部: Sketch tree、Block 一覧／Block Editor
- 右サイドバー: Constraint、Line、Point、Circle、Arc の一覧
- 下部: 操作ヒント、エラー、solve 状態

Presentation Mode では Geometry 作図・拘束グループを隠し、Presentation style と注記ツールを表示する。Block Editor 中は Presentation Mode へ切り替えられない。

## 2. Document 名とファイル

- Document 名は上部入力で編集し、ブラウザタイトルへ反映する。
- 空文字は表示上 `無題` とする。
- 保存ファイル名は Document 名を基に `.json` とする。
- 読込時はファイル名の拡張子を除いた名前を Document 名として優先する。
- Document 名変更は Undo/Redo 対象外である。
- 保存と読込は Block Editor 中に実行できない。

## 3. Canvas ナビゲーション

| 操作 | 挙動 |
| --- | --- |
| ホイール | Pointer 位置を中心にズーム |
| 中ボタンドラッグ | パン |
| 中ボタンダブルクリック | 表示中 Geometry へフィット |
| 空白の左ダブルクリック | アクティブ Sketch または全 Geometry へのフィット。状況で切替 |

ズーム倍率は `0.001`〜`10,000,000` に制限する。パン・ズームは保存と Undo/Redo の対象外である。

Geometry Mode ではスクリーン32px間隔の Grid を描く。Presentation Mode では Grid を描かない。Grid はスナップ対象ではなく、視覚補助である。

## 4. 選択

Geometry Mode ではアクティブ Sketch の Geometry を通常選択・ドラッグする。非アクティブ Geometry は表示・参照候補になり得るが、直接編集しない。

- クリック: 単一選択またはドラッグ開始
- Shift/Ctrl + クリック: 選択の追加／解除
- 空白ドラッグ: 矩形選択
- 左から右: 矩形内に完全に含まれる対象
- 右から左: 矩形と交差する対象
- Esc: 実行中操作を優先して解除し、操作がなければ選択解除

Presentation Mode の Geometry 選択は style と Annotation 対象指定のためだけに使う。

## 5. キーボード

| キー | 挙動 |
| --- | --- |
| `Ctrl/Cmd+C` | Geometry 選択をコピー |
| `Ctrl/Cmd+X` | Geometry 選択を切り取り |
| `Ctrl/Cmd+V` | active Sketch へ貼り付け |
| `Ctrl/Cmd+Z` | Undo |
| `Ctrl/Cmd+Y` / `Ctrl/Cmd+Shift+Z` | Redo |
| Delete / Backspace | Geometry Mode の選択を削除 |
| Enter | Line 長など、待機中の寸法対象を確定 |
| Esc | 現在のコマンド、作図途中、選択の順で解除 |
| Shift | Line 作図で水平／垂直補助、クリック選択の加算 |

コピー、切り取り、貼り付け、Delete は Presentation Mode では無効である。入力欄編集中はクリップボードショートカットを Geometry コマンドとして扱わない。

## 6. Undo/Redo

通常履歴は Document の直列化スナップショットを最大80件保持する。

履歴へ含める例:

- Geometry の作成、編集、削除
- Constraint、寸法、Sketch、Block の変更
- Presentation Sheet、style、Annotation の変更
- Sketch・Block の表示／構成変更

履歴へ含めない例:

- 選択、ホバー、実行途中コマンド
- パン、ズーム
- Document 名
- サイドバー開閉、タブ
- Geometry copy buffer

新規編集後は Redo stack を破棄する。同一内容のスナップショットは追加しない。

Block Editor は Definition ドラフトだけの独立履歴を持つ。Editor の Undo/Redo は通常 Document 履歴へ入らず、Editor 完了時に Definition 更新全体を通常履歴の1単位として追加する。

## 7. エラーとトランザクション

拘束追加、Block 作成・編集、回転ロック等は、変更前の状態を保持して検証し、成立しない場合はロールバックする。

一方、既存の参照元 Geometry または Block Definition を正当に変更した結果、依存先 Sketch の solve が失敗する場合は元変更を戻さず、依存先をエラー表示する。

現在のエラーは主に下部 Hint と簡易 Log へ表示する。モーダルな Prompt/Confirm は Sheet 名、Sketch 名、Block 名、Leader テキスト、削除確認に使用する。

## 8. サイドバー

右サイドバーは Constraint、Line、Point、Circle、Arc のタブを持つ。Canvas 選択と関連行を同期してハイライトし、行ホバーで対応 Geometry を Canvas 上で強調する。

Constraint 一覧は直接参照する Geometry だけを関連付け、同じ連結成分全体をハイライトしない。状態サマリには完全拘束、支持位置拘束、未拘束、矛盾、重複、無効参照を表示する。

Presentation 専用の Element 一覧やプロパティサイドバーは未実装である。
