# UI・操作・履歴

## 1. 固定レイアウト

画面は次の領域で構成する。

1. Menu Bar
2. Toolbar
3. 左Explorer
4. 中央Canvas
5. 右Properties
6. 下Status Bar

ExplorerとPropertiesはそれぞれ独立してscrollする。各panelはtitle barの矢印buttonで36pxのrailまで個別に最小化でき、同じbuttonで復元する。Canvasは残り領域を使用し、panel幅が変わっても表示中心を維持する。

## 2. Menu Bar

Menu Bar左端には30pxのCad2 SVGロゴを表示し、ファイル名は画面上へ表示しない。背景色はStatus Barと同じ青系の`#1e3a5f`とする。Menu Barはファイル、編集、表示、Geometry、Constraint、Annotation、ヘルプを持つ。Geometry menuのcommandは1列で表示し、2段組にしない。Document設定とApplication設定は別画面として開く。

menuは同時に1つだけ開く。すべて閉じている状態ではhoverだけで開かず、clickで開く。1つのmenuが開いている間は、別のmenu summaryへのmouse／pen hoverから1 frame相当（16ms）で先のmenuを閉じてhover先へ切り替え、focusもそのsummaryへ移す。touchではhover切替を行わない。別のmenuのclick、Menu Bar外のpointer操作、menu commandの実行、Esc、windowのfocus喪失でも先に開いていたmenuを閉じる。Escでmenuを閉じた場合はそのsummaryへfocusを戻し、同じkey操作でCanvas commandのcancelやSelection解除までは行わない。

- Document設定はDocument Default Appearanceを編集する。
- Application設定はDocument設定から独立したapplication viewである。

## 3. Toolbar

Toolbarは保存／開く、Undo/Redo/Delete、選択、Geometry作図・編集、Constraint、Annotation、Viewの各コマンドを横方向に配置する。ViewにはConstraint Status Viewの固定切替buttonを置く。保存／開くはFile menuからも同じcommandを実行できる。各command buttonは従来のSVG iconを使用するicon-only表示とし、tooltipとaccessible nameで名称を提示する。狭いwindowではgroup labelを非表示にしてbuttonと重ならないようにする。Block Definitionの作成・配置・編集はExplorerのBlock領域から操作する。

## 4. Explorer

ExplorerはSketches、Blocks、Objectsの3tabを持つ。tab分割は表示上の構成であり、Documentのデータモデルは変更しない。

### Sketches

- Sketch階層

Sketchのactive化、表示切替、追加、子追加、名前変更、削除を行う。

### Blocks

- Block Definitions

Block Definitionの作成、配置、編集、名前変更、削除を行う。Block InstanceはBlocksには含めない。

### Objects

- Constraint
- Point
- Line
- Circle
- Arc
- Block Instance
- Annotation

Objectsを初めて開いた時点では、ConstraintからAnnotationまでの全sectionを畳んで表示する。以後のtab切替では各sectionの開閉状態を維持する。Point sectionにはexplicit Pointに加え、アクティブSketchのLine端点を表示する。Circle／Arcの中心Pointは、Line端点またはexplicit Pointでもある場合を除いてPoint sectionへ重複表示しない。

rowの選択はCanvas selectionと同期する。row hoverはCanvas上の対象を強調し、Canvas hover／selectionも該当rowへ反映する。Sketch treeおよびObjectsからのhover強調は、対象ごとにCanvas hoverと同じ色・線幅・center marker規則を使用し、pointerがCanvas外へ出た後にCanvas hoverを残さない。

## 5. Properties

Propertiesは現在のSelectionを表示・編集する。Explorer rowとCanvasのどちらで選択しても直ちに同じ対象へ同期し、未選択時はactive Sketchを表示する。Appearanceの部分プロパティが未設定の場合は、親からの実効値を文字列で併記せず、入力欄または選択肢にdocument言語が日本語なら`既定`、英語なら`Default`を表示する。ColorはHEX文字列入力とOSのcolor pickerの両方から設定でき、picker操作中はCanvasへ即時反映する。継承可能なColorには日本語`既定へ戻す`／英語`Reset to default` buttonを表示し、clickで直接値だけを削除して上位設定へ戻す。空値による継承の仕組みは変更しない。

- Geometry: 測定値、construction、Appearance
- Sketch: ID、active状態、Appearance
- Block Instance: Definition、配置、Appearance Override
- Constraint: 型、値、Dimension Display
- Annotation: visible、text、font size、color

複数選択時の共通プロパティ一括編集は現行対象外であり、選択数のみ表示する。

## 6. Selectionと操作状態

SelectionはInteraction Stateから独立する。選択したままPropertiesを編集でき、作図・拘束・Annotation配置はそれぞれInteraction Stateとして管理する。

Escは進行中コマンドを段階的にcancelし、コマンドがなければSelectionを解除する。Canvas空白clickはSelectionを解除する。

起動時のsample GeometryはP1を固定する。固定点を含み残り自由度が1つの連結Geometryで両端が自由なlineをdragする場合は、拘束Jacobian上の可動性が最も高い自由端点を代表targetとし、複数端点targetによる移動量の減衰を避ける。sampleのL2／L3はP3のpoint dragと同じ拘束solve経路で応答する。自由度が複数ある通常のline移動は両端targetを維持する。

## 7. Status Bar

Status Barは現在のコマンド、操作Hintまたはerror、Constraint集計、pointer座標を表示する。矛盾件数は通常表示でも確認できる。

## 8. Shortcut

| 操作 | shortcut |
| --- | --- |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y または Ctrl+Shift+Z |
| Copy / Cut / Paste | Ctrl+C / Ctrl+X / Ctrl+V |
| Delete | Delete / Backspace |
| Constraint Status View | Spaceを押している間 |
| コマンドcancel／選択解除 | Esc |

入力欄編集中は文字入力をCanvas shortcutとして扱わない。

## 9. View操作

wheelでzoom、middle dragでpan、middle double clickで表示中Geometryへfitする。背景Gridは描画せず、Geometry IDはViewメニューから切り替える。通常時とGeometry／Annotation／寸法のdrag中のCanvas cursorは`8a2892a`と同じbrowser標準のdefault cursorとし、drag開始時に別の白色cursorへ切り替えない。pan中だけgrabbing cursorへ切り替える。

## 10. History

Geometry、Constraint、Sketch、Block、Appearance、Dimension Display、Annotationの変更をUndo/Redo対象にする。Selection、hover、tab切替、viewport、View Stateは履歴対象外とする。Block Editorはroot履歴と分離したlocal履歴を使用し、完了時にrootへ1 transactionとして記録する。
