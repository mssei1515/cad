# UI・操作・履歴

## 1. 固定レイアウト

画面は次の領域で構成する。

1. Menu Bar
2. Toolbar
3. 左Explorer
4. 中央Canvas
5. 右Properties
6. 下Status Bar

ExplorerとPropertiesは固定表示し、それぞれ独立してscrollする。Canvasは残り領域を使用する。

## 2. Menu Bar

Menu Barはファイル、編集、表示、Geometry、Constraint、Annotation、ヘルプを持つ。Document設定とApplication設定は別画面として開く。

- Document設定はDocument Default Appearanceを編集する。
- Application設定はDocument設定から独立したapplication viewである。

## 3. Toolbar

ToolbarはUndo/Redo/Delete、選択、Geometry作図・編集、Constraint、Annotationの各コマンドを横方向に配置する。Block Definitionの作成・配置・編集はExplorerのBlock領域から操作する。

## 4. Explorer

ExplorerはStructureとObjectsの2tabを持つ。

### Structure

- Sketch階層
- Block Definitions

Sketchのactive化、表示切替、追加、子追加、名前変更、削除を行う。Block Definitionの作成、配置、編集、名前変更、削除を行う。

### Objects

- Constraint
- Point
- Line
- Circle
- Arc
- Block Instance
- Annotation

rowの選択はCanvas selectionと同期する。row hoverはCanvas上の対象を強調し、Canvas hover／selectionも該当rowへ反映する。

## 5. Properties

Propertiesは現在のSelectionを表示・編集する。未選択時はactive Sketchを表示する。

- Geometry: 測定値、construction、Appearance
- Sketch: ID、active状態、Appearance
- Block Instance: Definition、配置、Appearance Override
- Constraint: 型、値、Dimension Display
- Annotation: visible、text、font size、color

複数選択時の共通プロパティ一括編集は現行対象外であり、選択数のみ表示する。

## 6. Selectionと操作状態

SelectionはInteraction Stateから独立する。選択したままPropertiesを編集でき、作図・拘束・Annotation配置はそれぞれInteraction Stateとして管理する。

Escは進行中コマンドを段階的にcancelし、コマンドがなければSelectionを解除する。Canvas空白clickはSelectionを解除する。

## 7. Status Bar

Status Barは現在のコマンド、操作Hintまたはerror、Constraint集計、pointer座標を表示する。矛盾件数は通常表示でも確認できる。

## 8. Shortcut

| 操作 | shortcut |
| --- | --- |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y または Ctrl+Shift+Z |
| Copy / Cut / Paste | Ctrl+C / Ctrl+X / Ctrl+V |
| Delete | Delete / Backspace |
| Constraint Status View | Spaceを押している間 |
| コマンドcancel／選択解除 | Esc |

入力欄編集中は文字入力をCanvas shortcutとして扱わない。

## 9. View操作

wheelでzoom、middle dragでpan、middle double clickで表示中Geometryへfitする。GridとGeometry IDはViewメニューから切り替える。

## 10. History

Geometry、Constraint、Sketch、Block、Appearance、Dimension Display、Annotationの変更をUndo/Redo対象にする。Selection、hover、tab切替、viewport、View Stateは履歴対象外とする。Block Editorはroot履歴と分離したlocal履歴を使用し、完了時にrootへ1 transactionとして記録する。
