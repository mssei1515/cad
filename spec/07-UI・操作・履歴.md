# UI・操作・履歴

## 1. 固定レイアウト

画面は次の領域で構成する。

1. Menu Bar
2. Toolbar
3. Canvas
4. 右Properties
5. 下Status Bar

左Explorer、3tab、Explorer最小化buttonは持たず、Canvasをworkspace左端まで拡張する。Propertiesは独立してscrollし、title barの矢印buttonで36pxのrailまで最小化でき、同じbuttonで復元する。Canvasは残り領域を使用し、Properties幅が変わっても表示中心を維持する。通常Canvasの背景は真っ白なUI部品とわずかに区別できる薄い青みの白`#fcfdff`とし、Block Editor中は編集状態を示しながらJot2Dの基調色と調和する淡い青`#f3f7ff`へ切り替える。

Sketch TreeはCanvas左上へ背景透過で常時表示する。Block Editorでも同じ位置と操作を再利用し、編集中Definitionの内部Sketch Treeへ切り替える。

起動時はRoot Sketchと、その直下の作図可能な`Sketch-1`だけを持つ空の新規Documentを開く。`Sketch-1`をactiveにし、Geometry、Constraint、Block、Annotation、Hatch、Reference Image、Parameterは作成しない。起動用のsample Geometryは表示しない。

### 1.1 配色

application UIはlight color schemeを使用し、Jot2Dのbrand colorである濃い青と、青みを持つneutral colorを基調とする。青はbrand、選択、focus、編集対象に使用し、灰色は通常surface、読み取り中心の情報、境界の分離に使用する。errorまたは破壊的操作を除き、役割のない別系統の色相を追加しない。Canvas上のGeometry、Constraint、Annotation等のDocument Appearance colorはこのUI配色とは別に扱い、UI surfaceの都合で変更しない。

主要な共通色と用途は次のとおりとする。

| role | color | 主な用途 |
|---|---|---|
| application外周 | `#e8edf4` | window内でpanelやCanvasの外側となる基底背景 |
| primary surface | `#f8fafc` | Toolbar、Propertiesの基本情報、補助panel surface |
| secondary surface | `#eef2f7` | section header、modal header／footer、補助的な面 |
| Properties背景 | `#f4f7fb` | Properties panel全体 |
| editable surface | `#f2f8ff` | Appearance、内容等の編集区分 |
| Canvas | `#fcfdff` | 通常Canvas。白いUI controlとわずかに区別する |
| Block Editor Canvas | `#f3f7ff` | Block編集中であることを示す淡い青 |
| primary text | `#1f2937` | 通常本文とcontrol文字 |
| muted text | `#5f6f86` | 補助説明、読み取り専用値、単位、group label |
| border | `#d8dee8` | 通常の区切りと弱い境界 |
| strong border | `#c5cedb` | panel境界と入力control境界 |
| accent | `#2563eb` | 選択、active command、主要button |
| soft accent | `#dbeafe` | menu等のaccent系hover、選択row、accentの淡色背景 |
| focus | `#60a5fa` | keyboard focus outlineとresize handle |
| application chrome | `#1e3a5f` | Menu BarとStatus Bar |
| danger | `#dc2626` | error、矛盾、破壊的状態 |

隣り合う通常surfaceは同系統の明度差で分離し、必要な箇所だけ`border`または`strong border`を併用する。Propertiesでは外側`#f4f7fb`、基本情報`#f8fafc`、編集区分`#f2f8ff`の順で役割を区別する。Block Editorは紫系など別色相へ切り替えず、通常Canvasより青みの強い`#f3f7ff`で編集状態を示す。Block Editor overlayには`rgba(239, 246, 255, 0.95)`、境界には`#93c5fd`、影には`rgba(30, 64, 175, 0.14)`を使用する。Menu BarとStatus Barは同じ`#1e3a5f`を使い、画面の上下でbrand colorを揃える。

通常サイズの文字は背景に対して原則4.5:1以上のcontrastを確保する。muted文字`#5f6f86`は最も近いeditable surface`#f2f8ff`上でもこの基準を満たす。hover、選択、focus、error等の状態は色だけに依存せず、背景、境界、outline、accent、iconまたはbadgeを組み合わせて識別可能にする。

## 2. Menu Bar

Menu Bar左端には背景を透過したJot2D SVGロゴを108×28pxで表示し、ファイル名は画面上へ表示しない。画像の上下に含まれる透明余白は表示枠で切り取り、38pxのMenu Bar内で上下5pxの余白を確保する。背景色はStatus Barと同じ青系の`#1e3a5f`とする。Menu Barはファイル、編集、表示、Geometry、Block、Constraint、Annotation、ヘルプを持つ。View menuにはGeometry IDとConstraint Status Viewのcheckboxを表示し、Constraint Status ViewはToolbar buttonおよびSpaceによる実際の表示状態と同期する。Geometry menuのcommandは1列で表示し、2段組にしない。File menuは`.jot2d`の開く、上書き保存、名前を付けて保存、およびParameter画面を開くcommandを持つ。Block menuはToolbarと共通のBlock作成command、およびBlock Definitions管理画面を開くcommandを持つ。Help menuは、実行中branch名と12桁の短縮commit IDを`branch@commit`形式で表示し、working treeに未commit変更がある場合は「変更あり」／`dirty`を付記する。commit ID全体はtooltipで確認できる。`file:` URLではGit状態から生成したGit管理外の`runtime-version.js`を読み込み、HTTP配信ではserverが同じ形式のscriptを動的に返す。`file:` URLを含む各起動では、読み込むJavaScriptへ起動ごとに異なるqueryを付け、ブラウザに残った旧scriptや旧commit情報を再利用しない。commit情報を取得できない場合は取得不能であることを表示する。Document設定、Application設定、Parameterは別画面として開く。

開くと名前を付けて保存ではFile System Access APIのpickerを表示し、`.jot2d`だけを対象とする。ブラウザ自動検証用URL parameterとして`filePicker=input`を指定した場合に限り、「開く」はHTML file inputを使用する。この互換経路で開いたDocumentには書込み可能なファイルハンドルがないため、現在の保存先を未設定にする。開いたファイルまたは名前を付けて保存したファイルのハンドルは、次回の保存先としてsession中だけ保持する。保存先をまだ持たないDocumentで「上書き保存」を実行した場合は名前を付けて保存と同じpickerを表示し、保存先を持つ場合はpickerを出さずに同じファイルへ上書きする。pickerをキャンセルした場合は通常の操作中止として扱い、error表示、Document変更、現在の保存先変更を行わない。ファイル内容は現行のDocument JSONをそのまま使用する。

menuは同時に1つだけ開く。すべて閉じている状態ではhoverだけで開かず、clickで開く。1つのmenuが開いている間は、別のmenu summaryへのmouse／pen hoverから1 frame相当（16ms）で先のmenuを閉じてhover先へ切り替え、focusもそのsummaryへ移す。touchではhover切替を行わない。別のmenuのclick、Menu Bar外のpointer操作、menu commandの実行、Esc、windowのfocus喪失でも先に開いていたmenuを閉じる。Escでmenuを閉じた場合はそのsummaryへfocusを戻し、同じkey操作でCanvas commandのcancelやSelection解除までは行わない。

- Root以外のSketch Propertiesは、Document設定と同じ3つの外観区分を`一般外観`／`General Appearance`、`補助線外観`／`Construction Appearance`、`寸法外観`／`Dimension Appearance`と表示する。各区分は個別に折り畳み可能で、初期状態ではすべて閉じる。ユーザーが開閉した後はPropertiesの再描画やSketch切替後もsession中の状態を維持する。各区分の未設定fieldは対応するDocument設定を直接継承し、補助線外観は一般外観を経由しない。補助線外観ではvisible、color、lineType、lineWidth、端部のはみ出し、端部の点を設定できる。寸法外観ではvisible、color、lineWidth、precision、prefix、suffixに加え、寸法補助線の突出量・起点すき間、端末記号の種類・サイズ・矢印系の開き角、寸法文字の高さ・寸法線との間隔を設定でき、そのSketch自身の個別上書きのない対象へ即時反映する。長さ系入力には`mm`、開き角には`°`を表示し、線幅は画面px単位とする。Root SketchおよびBlock Definition内のRoot Sketchには外観区分を表示しない。
- Document設定は一般外観、補助線外観、寸法外観を編集するmodal画面とし、すべての通常SketchおよびBlock Definition内Sketchに対する既定値を設定する。Document設定の変更は即時反映し、Undo/Redo対象とする。寸法外観内の3groupはPropertiesと共通のフラットな小見出しと水平区切り線で階層を示し、groupごとの枠、角丸、背景塗りは使用しない。
- Application設定はDocument設定から独立したapplication viewであり、言語を日本語／Englishから選択する。初回既定値は日本語とし、選択値はbrowserのapplication-local storageへ保存して次回起動時にも適用する。言語設定はDocument JSON、Undo/Redo履歴へ含めない。
- 言語切替はMenu、Toolbar、Sketch Tree、Properties、Settings、Status Bar、標準操作Hintを含むapplication UI全体へ即時反映する。Sketch PropertiesおよびDocument設定に動的生成する3区分のAppearance項目名と選択肢にも、現在のapplication言語を適用する。Document名、Sketch名、Block名、Annotation本文などのユーザーデータは翻訳しない。

## 3. Toolbar

ミラーと直線パターンはGeometry menuとToolbarの同じcommandとして配置し、対称形状および等間隔コピーを表す専用iconを使用する。

Toolbarは上書き保存／開く、Undo/Redo/Delete、選択、Geometry作図・編集（円弧とは別の3点円弧、長穴、スケッチ投影、中心線、ハッチングを含む）、Block作成、Constraint、Annotation、画像を読み込み、Viewの各コマンドを横方向に配置する。「3点円弧」は円弧上の3点を示す専用iconを使用し、Geometry menuとGeometry groupの同じcommandを使用する。「長穴」はGeometry menuとGeometry groupに独立commandとして置き、丸端の外形と2つの半円中心を示すiconを使用する。「画像を読み込み」はAnnotation menuとAnnotation groupの同じcommandを使用する。「スケッチ投影」はGeometry menuとGeometry groupの同じcommandを使用し、上側の破線形状、3本の下向き投影線、下側の実線形状からなる製図投影iconを使用する。中心線buttonは、短い2本の縦実線の間を縦の一点鎖線が上下へ越えるiconとし、Sketch Treeの中心線行とcommand cursorでも同じSVGを使用する。ViewにはConstraint Status Viewの固定切替buttonを置き、目の輪郭と完全拘束／支持位置拘束／未拘束／矛盾の4状態色を並べたiconで表示する。上書き保存／開くはFile menuからも同じcommandを実行できる。各command buttonは従来のSVG iconを使用するicon-only表示とし、tooltipとaccessible nameで名称を提示する。Toolbarの全groupがlabel付きで収まる境界に近い1260px以下ではgroup labelを非表示にし、buttonおよびMenu Barの文字と重ならないようにする。

Block作成buttonは1つだけ配置する。アクティブSketch内のGeometryまたはBlock Instanceが選択されていれば選択内容からDefinitionを作成し、選択がなければ空Definitionを作成する。どちらも同じBlock Editorを開く。

## 4. Sketch Tree

派生Geometryは個別Geometry分類へ表示せず、BlockとConstraintの間に「派生インスタンス」分類を設けて1 Instanceを1 rowで表示する。

Canvas左上のSketch TreeへSketch階層とObject一覧を統合する。表示領域は初期約320px幅、最大約70vhとし、右端をmouse dragして220–560pxの範囲で横幅を変更できる。狭いCanvasではCanvas内に収まる上限へclampし、幅はsession内だけ保持してJSONとUndo/Redoへ含めない。handleは左右矢印keyでも16px単位で変更でき、Home／Endで最小／最大幅へ移動する。surface、border、角丸、shadow、背景blurを持たない完全透過表示とする。header、通常のSketch・分類・Object・拘束状態集計rowも背景を透過し、hover、選択、active、error等の操作・状態を示す一時背景だけを表示する。Block Editorでは同じ位置と操作を再利用し、編集中Definitionの内部Sketch Treeへ切り替える。

Objectを持つactive Sketch rowはchevronまたはrow本体のclickで開閉でき、閉じた場合はそのSketch直下の図形・拘束等の分類とObject rowだけを隠す。非active Sketchのrow本体をclickした場合は、そのSketchを表示してactive化するだけで開閉状態を維持し、active化後の次のrow clickから開閉する。表示、名前変更、削除buttonは固有の操作だけを行い、rowの開閉を発生させない。子Sketchおよびその子孫のSketch rowは親Sketchの開閉状態にかかわらず常に表示し、Sketch階層全体を確認できる状態を保つ。Root SketchなどObject分類を持たないSketchは開閉buttonを表示しないが、行頭が空白に見えないように同じ位置へ薄い無効状態の`▼`を表示する。Objectを持たないrow本体のclickはactive化だけを行う。Root以外のSketchは分類を初期折り畳みとし、起動直後は全階層のSketch名を確認できる一方で図形や拘束の分類を表示しない。入れ子Sketchの作成、Object rowやCanvas操作によるactive化では、各Sketchの開閉状態を変更しない。

各Root以外のSketch直下へ、存在する分類だけをPoint、Line、Circle、Arc、Spline、Hatch、Image、Block、派生インスタンス、Constraint、Annotationの順に置き、その後に子Sketchを置く。空分類はDOMにも生成しない。Pointにはexplicit PointとLine端点を含めるが、Circle／Arc中心はexplicit PointまたはLine端点でもある場合だけ重複表示する。SplineにはそのSketchに所属するSplineを表示する。HatchにはそのSketchに所属するハッチだけを表示する。ImageにはそのSketchに所属するReference Imageを表示する。Blockには配置先のInstanceだけを表示し、Projection内部Objectはホスト側で個別表示しない。派生インスタンスには投影、ミラー、直線パターンの派生Instanceを表示し、仮想出力は個別表示しない。Block EditorではDefinition内部Objectを表示する。Constraintには通常拘束、拘束寸法、参照寸法、固定Pointを含める。展開時の先頭にはSketch別の拘束状態集計をObject rowと同じ22pxの枝付き補助rowとして置き、完全、支持、未拘束、矛盾を状態色のdotと件数でcompactに表示する。完全な名称と件数はtooltipで表示する。

分類もすべて初期折り畳みとする。Sketch rowの開閉状態はDocumentまたはBlock DefinitionとSketch ID、分類の開閉状態はそれらに分類を加えた組み合わせでsession中だけ記憶し、JSONとUndo/Redoへ含めない。Sketch rowを閉じて再び開いた場合は、配下の分類ごとの開閉状態を維持する。ファイル読込時は全Sketch rowを表示し、Root以外のSketch rowと全分類を閉じる。閉じたSketchではそのSketch自身の分類とObject rowを生成しないが、子Sketch rowの生成は継続する。閉じた分類ではObject rowを生成しない。閉じた分類が選択またはhover対象を含む場合は分類見出しを薄い青と左accentで通知する。Canvas選択によるSketchまたは分類の自動展開は行わない。

既存の18px tree cell、縦線、tee／elbow枝線を分類・Object rowまで連続させ、枝線領域の実幅とcontent開始位置を階層ごとの18px indentへ揃える。末端elbowの縦線は横線との交点で終端し、下方向へはみ出させない。Sketch rowは約19px、分類rowは約20px、Object rowは約22pxとする。Rootを含むすべてのSketch rowは、枝線領域の直後かつSketch名の直前に、重なった作図面を表す13pxの線画iconを表示してObject rowと明確に区別する。Sketchの開閉表示には10px幅、分類の開閉表示には12px幅の専用列を設け、muted色・7pxの小さい塗りつぶし`▶`／`▼`を配置する。Sketch行のchevronは専用列の中央へ配置して左右の余白をほぼ均等にし、Sketch名buttonには追加の左余白を設けない。分類rowはchevron、分類名、件数pillを持つ。Object rowはToolbar buttonからcloneした14px SVG、主表示、補助表示、意味のある状態badge、操作領域の1行構成とし、長い文字列は省略してtooltipへ全文を表示する。

- Line: ID、始点–終点ID、リンク中の投影badge
- Circle／Arc: ID、中心ID、半径、リンク中の投影badge
- Spline: ID、fit point数、開／閉、リンク中の投影badge
- Hatch: ID、pattern種類（平行線／クロス／塗りつぶし）、無効時の境界error badge
- Image: ID、名前、pixel寸法、非表示・位置ロックbadge
- Block: Instance ID、Definition名
- Constraint: Parameter名、localize済み拘束名
- Instance: 投影／ミラー／直線パターンの種類、ID、参照状態。生成Geometryは個別行にしない
- Annotation: ID、種類、本文冒頭

Point、Line、Circle、Arc、Spline、Hatch、Image、Block、Leader、Textは対応するToolbar作成buttonと同じSVGを使う。Free Textは枠内の`A`と文字列を表すテキストボックス型SVGとし、単独の`T`は使用しない。Constraintは寸法、一致、水平、垂直、平行、直角、対称、同心、等寸、接線、固定を種類別のToolbar SVGへ対応させ、派生拘束は同じ操作系iconを使う。補助、固定、読み取り専用、重複、参照エラーなど意味のある状態だけを小さいbadgeで表示する。Geometry／Constraint rowの削除と固定解除buttonは右端に維持し、Hatch／Image／Block／Annotationは選択後にToolbar Deleteを使う。

通常clickは選択を置換し、Ctrl／Shift clickは同じSketch内のGeometry、Block、Annotation、Reference Imageを加算／解除する。Constraintは単一選択とする。非アクティブSketchのObject rowをclickすると、対象Sketchを表示してactive化してから対象を選択し、PropertiesとCanvasへ同期する。hoverだけでは非アクティブObjectをCanvas強調しない。ObjectはSketch別に1回だけ索引化し、event handlingは`#sketchList`のdelegationで行う。

Block DefinitionsはBlock menuからmodal windowを開き、配置、編集、名前変更、削除を行う。Definition作成はToolbarまたはBlock menuの共通commandから行う。Block配置中の回転モードと表示内部SketchはPropertiesへ表示し、開始時にPropertiesを一時展開し、完了またはキャンセル時に元の開閉状態へ戻す。

## 5. Properties

Propertiesは現在のSelectionを表示・編集する。Sketch TreeのObject rowとCanvasのどちらで選択しても直ちに同じ対象へ同期し、未選択時はactive Sketchを表示する。全体のpanel余白、section間隔、行高、入力欄、選択肢およびColor buttonは、情報量を保ちながら縦方向をcompactに配置する。Properties全体は淡い青みのグレー`#f4f7fb`、`基本情報`は淡い灰色`#f8fafc`、`外観`、`内容`等の編集区分は淡い青色`#f2f8ff`の背景とし、外側、読み取り中心の情報、編集対象を視覚的に区別する。補助説明、読み取り専用値、単位等のmuted文字には`#5f6f86`を使用し、淡い青色の編集区分上でも通常文字として十分なcontrastを確保する。単一ObjectまたはSketchの枠外見出しは種類だけを表示し、IDまたは名前を併記しない。全対象の第一区分見出しは`基本情報`／`Basic Information`に統一する。各行は項目名を必ず持ち、Constraintを除く単一Objectには`種類`と`ID`を表示する。Geometryにはその形状を定義するPoint ID、中心Point ID、半径、角度等を表示する。Constraintには、その拘束が直接参照しているPoint、Line、Circle、Arc等のGeometry IDを役割ごとに表示する。選択によってPropertiesを再描画した場合も、section見出しと項目名には現在のapplication言語を適用し、選択操作によって英語表記へ戻さない。Appearanceの部分プロパティが未設定の場合は、入力欄または選択肢にapplication言語が日本語なら`既定 (継承値)`、英語なら`Default (inherited value)`を表示する。空文字を継承する場合は`既定 (空)`／`Default (Empty)`とする。ColorはHEX文字列入力と、色buttonから開くJot2DのColor Palette modalの両方から設定できる。Propertiesの文字列・数値入力は、入力途中の値が有効になった時点でmodelとCanvasへ即時反映する。空欄によるAppearance継承も即時反映し、無効な数値や未完成のHEX色はCanvasへ適用しない。入力中は履歴を増やさず、change確定時に一連の入力を1回のUndo単位として記録する。Parameter名と`値 / 数式`は検証および拘束再計算を伴うため、従来どおり確定時に反映する。

Appearance区分の見出しは対象を明示し、Pointは`点の外観`／`Point Appearance`、Lineは`線の外観`／`Line Appearance`、Circleは`円の外観`／`Circle Appearance`、Arcは`円弧の外観`／`Arc Appearance`、Splineは`スプラインの外観`／`Spline Appearance`、Constraint Dimensionは`寸法外観`／`Dimension Appearance`、Hatchは`ハッチング外観`／`Hatching Appearance`、Blockは`ブロック外観の上書き`／`Block Appearance Override`、Leaderは`引出線の外観`／`Leader Appearance`、Free Textは`自由テキストの外観`／`Free Text Appearance`、複数選択は`共通外観`／`Common Appearance`と表示する。SketchはDocument設定と同じ`一般外観`、`補助線外観`、`寸法外観`を使用する。

Color Palette modalには、Jot2Dが用意する無彩色と複数色相の明色・標準色・暗色、そのDocumentで明示設定されている有効なHEX色を重複なしで集めた「このファイルで使用中の色」、任意色を選ぶOS color inputを表示する。使用色の収集対象は互換用Document Default、各Sketchの通常／補助Geometry／寸法Appearance、Geometry、Constraint Dimensionの個別Appearance、Block Definition内部の各Sketch・Geometry・Constraint Dimension、通常／入れ子Block InstanceのAppearance Override、Document／Definition Annotationのstyle colorであり、継承による実効色は追加しない。標準色または使用色のswatch clickは対象Colorへ即時設定する。swatchのhover／keyboard focusでは枠とoutlineだけを強調し、swatchの背景色は実際の色から変更しない。任意色は選択後に適用buttonで設定する。Color専用の「既定へ戻す」buttonは表示せず、HEX文字列入力を空にすると従来どおり上位設定を継承する。入力欄でBackspace／Deleteを操作してもCanvas Selectionを削除しない。

- Point: 種類、ID、X／Y座標、固定状態、Appearance
- Line: 種類、ID、始点／終点Point ID、長さ、拘束状態、construction、Appearance。補助LineのAppearanceには端部のはみ出しと端部の点を表示し、各項目を所属Sketchから継承または個別上書きできる。
- Circle: 種類、ID、中心Point ID、半径、construction、Appearance
- Arc: 種類、ID、中心Point ID、半径、始点／終点角度、construction、Appearance
- Spline: 種類、ID、定義方式、次数、fit point ID列、開／閉、construction、Appearance、fit point編集mode開始button。通常modeではfit pointを表示せず、編集modeでだけhandleと補助polygonを表示する。投影中のGeometryでは参照元Sketch ID、参照元Geometry ID、投影先Geometry IDも読み取り専用で表示する。
- Sketch: 種類、ID、名前、親Sketch、active状態、Appearance
- Block: 種類、ID、Block Definition名とID、X／Y、角度、回転モード、表示する内部Sketch、Appearance Override。X／Yおよび自由回転時の角度は読み取り専用とする。直交回転ロック中の角度はPropertiesの`0°`、`90°`、`180°`、`270°`選択で変更でき、全固定中は無効にする。ユーザー向け表記は「ブロック」／`Block`とし、「ブロックインスタンス」／`Block Instance`を使用しない。選択済みBlockと新規配置中の回転モード、直交角度、表示SketchはPropertiesで編集する。
- Constraint Dimension: 型、寸法を定義するPoint／Line／Circle／Arc等のGeometry ID、Parameter名、拘束寸法では式、評価値、Appearance。Appearanceはvisible、color、lineWidth、precision、prefix、suffix、寸法補助線の突出量・起点すき間、端末記号の種類・サイズ・開き角、寸法文字の高さ・寸法線との間隔を持ち、未設定fieldは所属SketchのDefault Dimension Appearanceを継承する。UIは`寸法補助線`／`Extension lines`、`端末記号`／`Terminators`、`寸法文字`／`Dimension text`の3groupに分け、枠で囲わずフラットな小見出しと水平区切り線で表現する。端末種類は標準矢印、塗りつぶし矢印、点から選択し、点では開き角rowを表示しない。左右端は同じ設定を使い、寸法補助線と端末記号の表示切替は設けない。参照寸法の式と評価値は読み取り専用とする。
- Hatch: 種類、ID、所属Sketch、境界状態、編集可能なpattern種類（平行線／クロス／塗りつぶし）、色、表示。平行線とクロスでは角度、画面上のmm間隔、線幅も表示し、塗りつぶしでは0～100%の不透明度を表示して使用しない3項目を非表示にする。境界が無効な場合は理由と「境界を再指定」を表示する。
- Image: 種類、ID、名前、読み取り専用の所属Sketch、中心X／Y、編集可能な幅、読み取り専用の高さ、回転、不透明度、表示、位置ロック、2点から縮尺を設定。幅は縦横共通scaleを変更してpixel縦横比を維持し、位置ロック中は変換項目と縮尺設定を無効にする。
- Annotation: 「基本情報」「内容」「外観」の3区分。種類、ID、読み取り専用の所属Sketch、本文、表示、共通Color Palette、概算mmの文字高さ、フォント、太字、斜体、横位置、回転。Leaderでは線幅、線種、端末記号の種類と概算mmサイズも表示する

複数選択時は選択数と共通Propertiesを表示する。同種Objectではその種類で共通する編集可能なAppearance／状態項目を、異種Objectでは全対象が対応するAppearance項目だけを表示する。値が一致しない項目は`混在`／`Mixed`と表示し、ユーザーが変更した項目だけを全対象へ明示値として一括適用する。ID、座標、端点などObject固有の定義情報は一括変更しない。Geometryのconstructionは同種の非Point Geometry、補助Lineの端部設定は同種の補助Line、Hatch固有項目はHatch同士、Annotation固有項目は同じAnnotation種類を選択した場合だけ表示する。1項目の一括変更を1回のUndo単位とする。

## 6. Parameter画面

File menuの「Parameter…」からmodal windowを開く。Documentまたは各Block Definitionの名前空間を選択できる。Block Editor中は編集中Definitionだけを対象とし、他scopeは編集できない。

画面は次の2区分を持つ。

- Parameter: 名前、`値 / 数式`（英語`Value / Expression`）、評価値、追加、削除
- 寸法: 名前、種類、所属、`値 / 数式`（英語`Value / Expression`）、評価値。参照寸法は読み取り専用表示

編集内容はwindow内へstageし、「適用」で選択中の名前空間全体を検証して1回のUndo単位として反映する。未適用の変更がある状態で名前空間を切り替える、またはwindowを閉じる場合は適用／破棄／キャンセルを確認する。式またはsolveのエラー時はwindowを閉じず理由を表示する。

Parameter名、拘束寸法名、参照寸法名は有効かつ名前空間内で一意でなければならない。名称変更は同じ名前空間内の全数式へ反映する。依存中のParameterを削除する場合は依存元の名前を表示して拒否する。

## 7. Selectionと操作状態

SelectionはInteraction Stateから独立する。選択したままPropertiesを編集でき、作図・拘束・Annotation配置はそれぞれInteraction Stateとして管理する。

Escは進行中コマンドを段階的にcancelし、コマンドがなければSelectionを解除する。Canvas空白clickはSelectionを解除する。

スケッチ投影コマンドでは、表示中かつアクティブSketchの先祖に属するPoint、Line、Circle、Arc、Spline、Block Projectionをclickして追加／解除する。自己、子孫、兄弟、別branch、Root、非表示Geometryは選択できない。Enterで選択中の元Geometryから1個の投影Instanceを作って選択modeへ戻り、Escでは作成せず全候補を破棄する。同じ元Geometryの重複投影は行わない。ミラーと直線パターンは同じSketchで複写元を先に選択し、ToolbarまたはGeometry menuから開始して軸／方向Lineをclickする。パターンは間隔と元を除くコピー数を入力し、Propertiesで間隔、コピー数、方向反転を編集できる。通常選択で生成Geometryをclickすると派生Instance全体を選択し、ドラッグすると派生変換を逆変換して参照元Geometryを通常Geometryと同じ規則で移動・形状変更する。拘束・寸法コマンド中は生成Geometryを個別対象とする。Constraint Status Viewでは派生専用色を使わず、生成Geometryごとに最終的な参照元Geometryの完全・支持・未拘束・矛盾状態を継承して通常Geometryと同じ色へ対応させる。

起動時のsample GeometryはP1を固定する。固定点を含み残り自由度が1つの連結Geometryで両端が自由なlineをdragする場合は、拘束Jacobian上の可動性が最も高い自由端点を代表targetとし、複数端点targetによる移動量の減衰を避ける。中心と半径が拘束された同一円を共有する複数の独立した弦では、連結成分全体に別の自由度があっても、対象lineの両端に現れる自由度が1つなら同じ代表target処理を使用する。sampleのL2／L3はP3のpoint dragと同じ拘束solve経路で応答する。これら以外で連結成分の自由度が複数ある通常のline移動は両端targetを維持する。

Canvasの寸法入力は数値に加えてParameter名と数式を受け付ける。入力中の有効な式は評価後の数値をpreviewへ使い、エラー時は入力を閉じず理由を表示する。

寸法コマンド中にLineを最初にclickした場合は仮の線長寸法を表示し、続けてCircle円周をclickするとCircle中心からLine支持線までの距離寸法へ切り替える。Circle円周を最初にclickした場合は仮の直径寸法を表示し、続けてLineをclickしても同じ中心距離寸法へ切り替える。CircleまたはArcを最初にclickした後、同心のCircle／Arc円周をclickした場合は半径差寸法へ切り替える。2つ目を選ばずCanvas空白をclickした場合は、従来どおり最初のLineの線長、Circleの直径、Arcの半径を確定する。

OffsetコマンドではLine／Arcをclickするたび、現在のチェーンの先頭または末尾へ明示的に接続できる対象を追加する。接続していない対象、選択済み対象、閉じたチェーンへの追加は理由をHintへ表示して拒否する。Canvas空白clickはチェーン選択を確定すると同時にそのpointer位置から側と概算距離を決め、距離入力へ進む。Enterはチェーン選択だけを確定し、その後のCanvas clickで側と概算距離を決める。Circleおよび事前選択された単一Line／Arcは従来どおり、次のclickを側と概算距離に使用する。Escは選択中のチェーン全体を破棄する。

Sketch TreeのConstraint分類には拘束寸法と参照寸法を表示し、各rowの先頭へ`d1:`のようにParameter名を表示する。参照寸法には読み取り専用であることを表示する。

### Canvas右クリックメニュー

Canvas上で右clickした場合はbrowser標準menuを抑止し、pointer位置を基準とするJot2Dのcontext menuをCanvas領域内に収めて表示する。右click自体ではdragや作図を開始しない。pointer位置の選択候補が1件の場合はそのObjectを選択してCanvasとPropertiesへ同期するが、現在の複数Selectionに含まれるObjectを右clickした場合は複数Selectionを維持する。非アクティブSketchおよび非表示Objectはcontext menuの選択対象にしない。

pointer位置に2件以上のObjectが重なる場合は、Object固有操作の代わりにcontext menu先頭から「選択候補」を一覧表示し、右clickした時点ではSelectionを変更しない。候補はPoint、Arc endpoint、Line、Circle、Arc、Spline、Constraint Dimension、Annotation（Free Text／Leader）、Block、Hatchを対象とする。Block Definition内から投影されたGeometry、Annotation、Hatchは個別候補にせず、配置先の最上位Blockへ1件に集約する。Spline編集modeのfit point handleは親Splineと別候補にせず、fit point追加・削除のObject固有menuを直接表示する。候補順はpointerからの距離、既存の種類優先順位、同種Objectの描画順の順で決める。

各候補rowはToolbar／Sketch Treeと共通のSVG、種類、IDまたは寸法Parameter名、端点ID・Block Definition名・本文冒頭などの補助情報を表示する。rowのpointer hoverまたはkeyboard focus中はその候補だけをCanvasで一時強調し、rowから離れた場合はmenuを開く前のhover／Selection表示へ戻す。rowをclickすると既存SelectionをそのObjectだけへ置き換え、PropertiesとSketch Treeへ同期してmenuを閉じる。上下矢印、Home、Endで候補間のfocusを移動し、EnterまたはSpaceでも候補を確定できる。

- 進行中コマンドがある場合: コマンドcancel、Undo、Redo
- Canvas空白: Paste、Undo、Redo、表示中Geometryへのfit
- Object共通: Cut、Copy、Delete、Properties表示。対象Selectionで実行できない項目はdisabledにする
- Point: 固定／固定解除、Leader追加
- Line: 固定／固定解除、通常／補助Geometry切替、Offset、2本選択時のFillet、Leader追加、選択からBlock作成
- Circle／Arc: 通常／補助Geometry切替、Offset、Leader追加、選択からBlock作成
- Spline: 通常／補助Geometry切替、Leader追加、選択からBlock作成。専用fit point編集modeではSpline本体から通過点を追加し、fit point handleから通過点を削除する。Trim、Offset、Filletは表示しない
- Arc endpoint: 固定／固定解除
- Block: 固定／固定解除、直交回転lock／自由回転、Block Definition編集、選択からBlock作成
- Constraint Dimension: `値 / 数式`編集。参照寸法はdisabledにする
- `値 / 数式`では数値を直接入力し、数式は先頭`=`を必須とする。数式入力中のCanvas寸法clickは通常selectionの代わりに同一名前空間のParameter名をcaret位置へ挿入する
- Hatch: 境界を再指定、選択からBlock作成。Copy／Cut／Block化は全境界Geometryが同時選択されている場合だけ有効にする
- Annotation: 選択からBlock作成

各項目はToolbar、Properties、shortcutと同じ既存command経路を使用し、model変更は同じ検証、Undo/Redo、rollback規則へ従う。menuは項目実行、外側pointer操作、Esc、wheel、window resize、window focus喪失で閉じる。上下矢印、Home、Endで有効項目間のkeyboard focusを移動できる。表示文言はapplication言語へ即時対応する。

## 10. View操作

wheelでzoom、middle dragでpan、middle double clickで表示中Geometryへfitする。表示倍率100%はDocumentの1mmを`96 / 25.4` CSS pxで描くCSS基準の概算実寸であり、wheel操作後はこの基準に対する百分率をStatus BarのHintへ表示する。wheelではpointer下の位置を動かさない。背景Gridは描画せず、Geometry IDはViewメニューから切り替える。Canvas内では選択、作図、drag、panを含むすべての状態でbrowser native custom cursorを使用し、Canvas再描画と独立したOS cursor経路で高速なpointer移動へ追従させる。pointer矢印は約18px高のcompactな共通形状とし、輪郭線は0.8pxの細線とする。状態遷移時にも矢印のhotspotと大きさを変えない。選択以外の継続中commandでは、この矢印へ対応するToolbar buttonのSVG icon badgeを一体化する。対象はGeometry作図・編集、拘束・寸法入力、Annotation配置、Block配置、Spline fit point編集とし、補助線切替や固定など即時完了するtoggleは対象外とする。iconはToolbarの通常iconと同じ色・線幅による18px表示とし、Toolbar surfaceと同じ明色背景、境界線、角丸を持つ22px badge内へ配置する。影は付けない。custom cursorはCanvas領域だけで使用し、pan中やdrag中も別のcursorへ切り替えない。

Canvasの高頻度なpointer moveは、未処理の最新位置だけを保持し、animation frameごとに最大1回だけhit test、drag用local solve、依存Sketch solve、Canvas再描画および座標表示更新を行う。同一frame内に複数のmoveが到着した場合は途中位置を省略するが、pointer down、pointer up、pointer cancel、double click、wheelの処理前には保留位置を同期的に反映し、選択開始位置、drag終了位置およびzoom基準位置を失わない。1回の入力処理と再描画では、Block Projectionを含む全Geometry一覧と解決済みAppearanceを一時cacheしてhit testと描画の間で再利用する。Canvas bitmap寸法はresize時に更新し、通常の再描画ではlayout測定を繰り返さない。Sketch Tree／PropertiesのSelection class更新はCanvas再描画から分離し、SelectionまたはUI再構築時だけ行う。

## 11. History

Geometry（Splineとfit pointを含む）、Constraint、Sketch、Block、派生Geometry Instance、Parameter、寸法名・式、Appearance、Dimension Appearance、Hatch、Annotation、Reference Imageの変更をUndo/Redo対象にする。Hatch本体、境界参照および採番値、Reference Image本体・Base64データ・変換・表示状態、ならびに投影・ミラー・直線パターンInstanceの参照と設定をDocument履歴とBlock Editor local履歴へ含める。派生Geometryは読取専用であり、直接drag、trim、fillet、Spline編集、固定、補助線切替を行わない。Parameter画面の1回の適用は1つの履歴単位とする。Selection、hover、Sketch TreeのSketch／分類の開閉と横幅、viewport、View Stateは履歴対象外とする。Block Editorはroot履歴と分離したlocal履歴を使用し、完了時にrootへ1 transactionとして記録する。
