# UI・操作・履歴

## 1. 固定レイアウト

画面は次の領域で構成する。

1. Menu Bar
2. Toolbar
3. 左Explorer
4. 中央Canvas
5. 右Properties
6. 下Status Bar

ExplorerとPropertiesはそれぞれ独立してscrollする。各panelはtitle barの矢印buttonで36pxのrailまで個別に最小化でき、同じbuttonで復元する。Canvasは残り領域を使用し、panel幅が変わっても表示中心を維持する。

Sketch treeはExplorer内へ格納せず、Canvas左上の独立overlayとして常時表示する。Block Editorでも同じ位置と操作を再利用し、編集中Definitionの内部Sketch treeへ切り替える。

## 2. Menu Bar

Menu Bar左端には背景を透過した30pxのCad2 SVGロゴを表示し、ファイル名は画面上へ表示しない。背景色はStatus Barと同じ青系の`#1e3a5f`とする。Menu Barはファイル、編集、表示、Geometry、Block、Constraint、Annotation、ヘルプを持つ。View menuにはGeometry IDとConstraint Status Viewのcheckboxを表示し、Constraint Status ViewはToolbar buttonおよびSpaceによる実際の表示状態と同期する。Geometry menuのcommandは1列で表示し、2段組にしない。File menuはParameter画面を開くcommandを持つ。Block menuはToolbarと共通のBlock作成command、およびBlock Definitions管理画面を開くcommandを持つ。Document設定、Application設定、Parameterは別画面として開く。

menuは同時に1つだけ開く。すべて閉じている状態ではhoverだけで開かず、clickで開く。1つのmenuが開いている間は、別のmenu summaryへのmouse／pen hoverから1 frame相当（16ms）で先のmenuを閉じてhover先へ切り替え、focusもそのsummaryへ移す。touchではhover切替を行わない。別のmenuのclick、Menu Bar外のpointer操作、menu commandの実行、Esc、windowのfocus喪失でも先に開いていたmenuを閉じる。Escでmenuを閉じた場合はそのsummaryへfocusを戻し、同じkey操作でCanvas commandのcancelやSelection解除までは行わない。

- Root以外のSketch Propertiesは、3つの外観区分を`一般外観`／`General Appearance`、`補助線外観`／`Construction Appearance`、`寸法外観`／`Dimension Appearance`と表示する。各区分は個別に折り畳み可能で、Propertiesの再描画やSketch切替後も開閉状態を維持する。各区分の未設定fieldは対応するDocument設定を直接継承し、補助線外観は一般外観を経由しない。補助線外観ではvisible、color、lineType、lineWidth、端部のはみ出し、端部の点を設定できる。寸法外観ではvisible、color、precision、prefix、suffix、arrows、extension linesを設定でき、そのSketch自身の個別上書きのない対象へ即時反映する。Root SketchおよびBlock Definition内のRoot Sketchには外観区分を表示しない。
- Document設定は一般外観、補助線外観、寸法外観を編集するmodal画面とし、すべての通常SketchおよびBlock Definition内Sketchに対する既定値を設定する。Document設定の変更は即時反映し、Undo/Redo対象とする。
- Application設定はDocument設定から独立したapplication viewであり、言語を日本語／Englishから選択する。初回既定値は日本語とし、選択値はbrowserのapplication-local storageへ保存して次回起動時にも適用する。言語設定はDocument JSON、Undo/Redo履歴へ含めない。
- 言語切替はMenu、Toolbar、Explorer、Properties、Settings、Status Bar、標準操作Hintを含むapplication UI全体へ即時反映する。Sketch PropertiesおよびDocument設定に動的生成する3区分のAppearance項目名と選択肢にも、現在のapplication言語を適用する。Document名、Sketch名、Block名、Annotation本文などのユーザーデータは翻訳しない。

## 3. Toolbar

Toolbarは保存／開く、Undo/Redo/Delete、選択、Geometry作図・編集、Block作成、Constraint、Annotation、Viewの各コマンドを横方向に配置する。ViewにはConstraint Status Viewの固定切替buttonを置き、目の輪郭と完全拘束／支持位置拘束／未拘束／矛盾の4状態色を並べたiconで表示する。保存／開くはFile menuからも同じcommandを実行できる。各command buttonは従来のSVG iconを使用するicon-only表示とし、tooltipとaccessible nameで名称を提示する。Toolbarの全groupがlabel付きで収まる境界に近い1260px以下ではgroup labelを非表示にし、buttonおよびMenu Barの文字と重ならないようにする。

Block作成buttonは1つだけ配置する。アクティブSketch内のGeometryまたはBlock Instanceが選択されていれば選択内容からDefinitionを作成し、選択がなければ空Definitionを作成する。どちらも同じBlock Editorを開く。

## 4. Explorer

ExplorerはGeometry、Block、Constraintの3tabをこの順序で持ち、初期表示はGeometryとする。tab barは高さ32px、各tabは高さ27pxを基準とするcompactな表示とし、文字サイズはExplorer内のsection見出しと同じ12pxとする。inactive tabは背景へ馴染ませる。active tabは上辺を丸めた輪郭、青い上端accent、content面へ連続する白背景を持つ一般的なtab形状で表示する。tab分割は表示上の構成であり、Documentのデータモデルは変更しない。

Sketchのactive化、表示切替、追加、子追加、名前変更、削除は、Canvas左上のSketch treeで行う。

### Blocks

- Block Instance一覧をsection見出しや折り畳みUIを挟まず直接表示
- Block Definitions管理画面を開くbutton

Block Instanceのrow選択とhoverはCanvas selection／hoverへ同期する。Block Definitions buttonはDocument設定と同じmodal windowを開き、現在のDefinition一覧を表示する。Definitionの配置、編集、名前変更、削除はこのwindowで行う。Definitionの作成はToolbarまたはBlock menuの共通commandから行う。Block Editorへ移行する操作と配置開始時はwindowを閉じる。

### Geometry

- Point
- Line
- Circle
- Arc
- Annotation

Geometryを初めて開いた時点では全sectionを畳んで表示する。以後のtab切替では各sectionの開閉状態を維持する。Point、Line、Circle、Arc、Annotationの各見出し右側には、その一覧へ表示する現在件数を表示する。Point sectionにはexplicit Pointに加え、アクティブSketchのLine端点を表示する。Circle／Arcの中心Pointは、Line端点またはexplicit Pointでもある場合を除いてPoint sectionへ重複表示しない。

### Constraint

Constraint一覧と固定拘束をsection見出しや折り畳みUIを挟まず直接表示する。一覧先頭の拘束状態集計は、Block tabの「ブロック」headerと同じ灰色系のpanel背景で区切る。

Geometry／Constraint rowの選択はCanvas selectionと同期する。row hoverはCanvas上の対象を強調し、Canvas hover／selectionも該当rowへ反映する。Sketch treeおよび両tabからのhover強調は、対象ごとにCanvas hoverと同じ色・線幅・center marker規則を使用し、pointerがCanvas外へ出た後にCanvas hoverを残さない。ただしSketch treeでSketch全体をhoverした場合はLine endpointの丸markerとBlock ProjectionのPoint markerを追加表示しない。

## 5. Properties

Propertiesは現在のSelectionを表示・編集する。Explorer rowとCanvasのどちらで選択しても直ちに同じ対象へ同期し、未選択時はactive Sketchを表示する。全体のpanel余白、section間隔、行高、入力欄、選択肢およびColor buttonは、情報量を保ちながら縦方向をcompactに配置する。各行は項目名を必ず持ち、Constraintを除く単一Objectには`種類`と`ID`を表示する。Geometryにはその形状を定義するPoint ID、中心Point ID、半径、角度等を表示する。Constraintには、その拘束が直接参照しているPoint、Line、Circle、Arc等のGeometry IDを役割ごとに表示する。選択によってPropertiesを再描画した場合も、section見出しと項目名には現在のapplication言語を適用し、選択操作によって英語表記へ戻さない。Appearanceの部分プロパティが未設定の場合は、親からの実効値を文字列で併記せず、入力欄または選択肢にapplication言語が日本語なら`既定`、英語なら`Default`を表示する。ColorはHEX文字列入力と、色buttonから開くCad2のColor Palette modalの両方から設定できる。

Color Palette modalには、Cad2が用意する無彩色と複数色相の明色・標準色・暗色、そのDocumentで明示設定されている有効なHEX色を重複なしで集めた「このファイルで使用中の色」、任意色を選ぶOS color inputを表示する。使用色の収集対象は互換用Document Default、各Sketchの通常／補助Geometry／寸法Appearance、Geometry、Constraint Dimensionの個別Appearance、Block Definition内部の各Sketch・Geometry・Constraint Dimension、通常／入れ子Block InstanceのAppearance Override、Document／Definition Annotationのstyle colorであり、継承による実効色は追加しない。標準色または使用色のswatch clickは対象Colorへ即時設定する。swatchのhover／keyboard focusでは枠とoutlineだけを強調し、swatchの背景色は実際の色から変更しない。任意色は選択後に適用buttonで設定する。Color専用の「既定へ戻す」buttonは表示せず、HEX文字列入力を空にすると従来どおり上位設定を継承する。入力欄でBackspace／Deleteを操作してもCanvas Selectionを削除しない。

- Point: 種類、ID、X／Y座標、固定状態、Appearance
- Line: 種類、ID、始点／終点Point ID、長さ、拘束状態、construction、Appearance。補助LineのAppearanceには端部のはみ出しと端部の点を表示し、各項目を所属Sketchから継承または個別上書きできる。
- Circle: 種類、ID、中心Point ID、半径、construction、Appearance
- Arc: 種類、ID、中心Point ID、半径、始点／終点角度、construction、Appearance
- Sketch: 種類、ID、名前、親Sketch、active状態、Appearance
- Block: 種類、ID、Block Definition名とID、X／Y、角度、回転モード、表示する内部Sketch、Appearance Override。X／Yおよび自由回転時の角度は読み取り専用とする。直交回転ロック中の角度はPropertiesの`0°`、`90°`、`180°`、`270°`選択で変更でき、全固定中は無効にする。ユーザー向け表記は「ブロック」／`Block`とし、「ブロックインスタンス」／`Block Instance`を使用しない。選択済みBlockの回転モード、直交角度、表示SketchはPropertiesで編集し、新規配置中だけExplorer下部で設定する。
- Constraint Dimension: 型、寸法を定義するPoint／Line／Circle／Arc等のGeometry ID、Parameter名、拘束寸法では式、評価値、Appearance。Appearanceはvisible、color、precision、prefix、suffix、arrows、extension linesを持ち、未設定fieldは所属SketchのDefault Dimension Appearanceを継承する。参照寸法の式と評価値は読み取り専用とする。
- Annotation: 種類、ID、visible、text、font size、color

複数選択時の共通プロパティ一括編集は現行対象外であり、選択数のみ表示する。

## 6. Parameter画面

File menuの「Parameter…」からmodal windowを開く。Documentまたは各Block Definitionの名前空間を選択できる。Block Editor中は編集中Definitionだけを対象とし、他scopeは編集できない。

画面は次の2区分を持つ。

- Parameter: 名前、`値 / 数式`（英語`Value / Expression`）、評価値、追加、削除
- 寸法: 名前、種類、所属、`値 / 数式`（英語`Value / Expression`）、評価値。参照寸法は読み取り専用表示

編集内容はwindow内へstageし、「適用」で選択中の名前空間全体を検証して1回のUndo単位として反映する。未適用の変更がある状態で名前空間を切り替える、またはwindowを閉じる場合は適用／破棄／キャンセルを確認する。式またはsolveのエラー時はwindowを閉じず理由を表示する。

Parameter名、拘束寸法名、参照寸法名は有効かつ名前空間内で一意でなければならない。名称変更は同じ名前空間内の全数式へ反映する。依存中のParameterを削除する場合は依存元の名前を表示して拒否する。

## 7. Selectionと操作状態

SelectionはInteraction Stateから独立する。選択したままPropertiesを編集でき、作図・拘束・Annotation配置はそれぞれInteraction Stateとして管理する。

Escは進行中コマンドを段階的にcancelし、コマンドがなければSelectionを解除する。Canvas空白clickはSelectionを解除する。

起動時のsample GeometryはP1を固定する。固定点を含み残り自由度が1つの連結Geometryで両端が自由なlineをdragする場合は、拘束Jacobian上の可動性が最も高い自由端点を代表targetとし、複数端点targetによる移動量の減衰を避ける。sampleのL2／L3はP3のpoint dragと同じ拘束solve経路で応答する。自由度が複数ある通常のline移動は両端targetを維持する。

Canvasの寸法入力は数値に加えてParameter名と数式を受け付ける。入力中の有効な式は評価後の数値をpreviewへ使い、エラー時は入力を閉じず理由を表示する。

Constraint tabには拘束寸法と参照寸法を表示し、各rowの先頭へ`d1:`のようにParameter名を表示する。参照寸法には読み取り専用であることを表示する。

## 8. Status Bar

Status Barは現在のコマンド、操作Hintまたはerror、Constraint集計、pointer座標を表示する。矛盾件数は通常表示でも確認できる。

## 9. Shortcut

| 操作 | shortcut |
| --- | --- |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y または Ctrl+Shift+Z |
| Copy / Cut / Paste | Ctrl+C / Ctrl+X / Ctrl+V |
| Delete | Delete / Backspace |
| Constraint Status View | Spaceを押している間 |
| コマンドcancel／選択解除 | Esc |

入力欄編集中はBackspace／Deleteを含む文字入力をCanvas shortcutとして扱わない。

## 10. View操作

wheelでzoom、middle dragでpan、middle double clickで表示中Geometryへfitする。背景Gridは描画せず、Geometry IDはViewメニューから切り替える。通常時とGeometry／Annotation／寸法のdrag中のCanvas cursorは`8a2892a`と同じbrowser標準のdefault cursorとし、drag開始時に別の白色cursorへ切り替えない。pan中だけgrabbing cursorへ切り替える。

## 11. History

Geometry、Constraint、Sketch、Block、Parameter、寸法名・式、Appearance、Dimension Appearance、Annotationの変更をUndo/Redo対象にする。Parameter画面の1回の適用は1つの履歴単位とする。Selection、hover、tab切替、viewport、View Stateは履歴対象外とする。Block Editorはroot履歴と分離したlocal履歴を使用し、完了時にrootへ1 transactionとして記録する。
