# 外観

共通の外観継承・初期値・強調・可視性を定義する。寸法・注記等の固有表示と拘束状態表示の操作は[表示と注記](../ui/表示とビュー操作.md)を参照する。

## 1. Appearanceの継承

### 解決する順序

| ID | 対象 | 優先順位（左から右へ上書き） |
| --- | --- | --- |
| APP-01 | 通常Geometry | Documentの一般Appearance → 所属Sketch自身の一般Appearance → Geometryの明示Appearance |
| APP-02 | 補助Geometry | DocumentのConstruction Appearance → 所属Sketch自身のConstruction Appearance → Geometryの明示Appearance |
| APP-03 | Block ProjectionのGeometry | 対応するDocument既定 → 最外側の配置先Sketchの対応外観 → 対象GeometryのDefinition内Sketchの対応外観 → 内部Geometryの明示Appearance → Instance Override（内側から外側） |
| APP-04 | 派生Instanceの生成Geometry | 各参照元Geometryの実効Appearance → 派生InstanceのAppearance Override |
| APP-05 | Constraint Dimension | DocumentのDimension Appearance＋共通端末設定 → 所属Sketch自身のDimension Appearance → 寸法の明示field |

| APP-06 | Leader | DocumentのLeader Appearance＋共通端末設定 → 所属Sketch自身のLeader Appearance → 個別style |

各段階では、明示されたfieldだけを上書きする。未設定fieldは左側の値を保持する。

- 一般外観、補助線外観、寸法外観、Leader外観は独立した経路とし、一般外観を補助線外観へ継承しない。
- 親Sketchの外観は子Sketchへ継承しない。Root Sketchは外観の継承元にしない。
- APP-03の「対応外観」は通常Geometryなら一般外観、補助GeometryならConstruction Appearanceを指す。Definition内で未設定のfieldには配置先Sketchの値が残る。Block Editor内で通常Geometryとして編集・表示するときはAPP-01／02に従う。
- 入れ子BlockのInstance Overrideは内側から外側へ適用し、最外側の明示値を優先する。
- APP-04はミラー・スケッチ投影・直線パターン・同期インスタンスに共通で、各参照元Geometryの線種・色・線幅・visible・補助Line端部設定を継承し、元の外観変更にも追従する。参照元がBlock投影や別の派生Geometryの場合も、その実効外観を使う。各Instanceで明示されたOverrideだけを優先し、元Geometryには書き戻さない。生成先Sketchの外観は重ねず、Sketch自体の表示／非表示は生成先で判定する。外観値の複製や保存形式の変更は行わず、既存の派生Instanceにも適用する。
- Block Definition内の寸法もAPP-05と同じDocument既定を使用し、親SketchのDimension Appearanceは継承しない。

Free TextとHatchは固有の外観を持つ。LeaderのBlock投影はDocument→Definition内の所属Sketch→個別styleで解決する。Geometryの上記経路へ一律に統合せず、各表示仕様に従う。Blockから投影されるAnnotationとHatchのvisible、color、lineWidthにはInstance Overrideを適用する。

### 初期値と補助Lineの端部

通常Geometryの初期基底線幅は2.0px。補助Geometryの初期基底は一点鎖線、1px、通常時の不透明度72%とする。外観の明示値で色・線種・線幅・visibleを変更できる。

| field | 補助Lineの表示 |
| --- | --- |
| `endpointOverhang: true` | 元の両端から画面上12pxずつ延長する。Geometry自身や所属Block Instanceのhover／選択中も維持する |
| `endpointOverhang: false` | 元の端点間だけを描画し、寸法補助線のclearanceにも固定12pxのはみ出しを加算しない |
| `endpointMarkers: true` | 元の両端に点を描く。Constraint Status Viewでも表示を維持する |
| `endpointMarkers: false` | 外観設定による端部の点を描かない |

端部のはみ出しと点は初期状態で有効にする。外観設定による点と、直接hover／選択した端点の操作markerは区別する。

実線、破線、一点鎖線、二点鎖線、点線はzoom倍率によらず画面上のdash構成がほぼ一定になるようviewport scaleを相殺して描画する。二点鎖線は長いdashの後に2つのdotを置く周期を繰り返す。ただしLeaderの「サイズロック」がチェックありの場合、dashも[注記の共通表示倍率](../operations/注記.md)に従って拡縮する。

### テーマと一時的な強調

外観の継承とテーマ補正は保存済みの明示値を書き換えない。ダークテーマではCanvas描画時だけ[UI・操作・履歴](../ui/画面構成.md)のcontrast補正をGeometry、Constraint Dimension、Hatch、Annotationへ共通適用する。

選択・hoverは一時的な強調表示であり、Appearanceデータを変更しない。アクティブSketchについては、CanvasとSketch TreeのObject rowのどちらを起点にしても、対象GeometryまたはBlockにCanvas hoverと同じ青色と線幅の強調を使用する。Sketch TreeでLineを直接参照する拘束をhoverまたは選択した場合はLine本体を強調し、そのLineの形状を定義するendpointは強調対象へ含めない。点‐線拘束のPointなど、拘束が直接参照するPointは強調する。Sketch TreeのSketch hoverでは通常GeometryとBlock ProjectionのどちらにもLine endpoint markerを表示しない。Block ProjectionはLine・Circle・Arc・Splineのstrokeだけを強調し、explicit Pointや中心Pointを含むPoint markerは表示しない。作図先以外も選択強調を行う。対象の所属と参照可否を表示し、未ロックの通常GeometryはCanvas hoverで強調する。

固定されたexplicit Pointは、通常時は非固定Pointと同じ通常表示とする。Point自身をhoverまたは選択した間だけ赤色で強調し、日本語で`固定`、英語で`Fixed`のlabelをPointのそばに表示する。

## 2. visible

`visible=false`のGeometryは通常表示とhit testから除外する。Sketchの非表示設定はそのSketch自身のGeometryへだけ適用し、子Sketchへは波及しない。Constraint Status Viewでもvisibleを尊重し、現在表示されているGeometryだけに拘束状態色を適用する。独立したView State「非表示要素を表示」がONの間だけ、visible=falseのSketch／要素を一時表示しhit testの対象とする。この切替は保存されるvisible設定を変更しない。
