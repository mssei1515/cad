# 編集と履歴

この文書は、拘束・ドラッグ・Parameter・Block編集の確定と失敗時の扱いを定義する。数値評価は[式評価](../calculation/式評価.md)、拘束の受入れ条件は[拘束と依存更新](../calculation/拘束と依存更新.md)を参照する。

## 1. 操作と計算結果の区別

拘束の計算結果と、ユーザー操作を確定できるかは区別する。

- 編集対象Sketchのsolveが成立しても、依存Sketchで失敗する場合がある。
- Parameter評価や参照寸法feedbackを伴う確定操作では、それらの成立も確認する。
- 復元する範囲は下表の操作単位で決める。一般の参照更新の規則だけで、ドラッグやParameter適用の確定可否を決めない。

## 2. 操作別の復元範囲

| ID | 操作・状況 | 失敗時の扱い | 履歴 |
| --- | --- | --- | --- |
| TX-01 | Parameterを含む確定操作での式エラー、拘束矛盾、非収束 | 操作全体を開始前へ戻す | 失敗した操作は追加しない |
| TX-02 | Geometryドラッグ確定時の最終solve、形状検証、Parameter再評価または依存Sketchのsolve失敗 | ドラッグ開始前へ戻す | 失敗したドラッグは追加しない |
| TX-03 | 上記の操作全体復元を伴わない一般の参照元Sketch更新で、依存Sketchのsolveが失敗 | 参照元の変更は維持し、依存側をエラー状態にする | 編集元の操作の履歴規則に従う |
| TX-04 | Block Parameter適用での評価または影響先のsolve失敗 | 関係するDefinition、Instance、Documentを適用前へ一括復元する | 失敗した適用は追加しない |
| TX-05 | Parameter以外のBlock Definition編集が、外部配置先の拘束を壊す | Definition更新は維持し、影響を受けるSketchをエラー状態にする | Block Editor完了時の履歴規則に従う |

TX-03は、TX-01／02／04で定義した操作全体復元を上書きしない。TX-05もDefinition内部の不正な編集や、使用中Instanceの有効内部Sketchがなくなる編集の受理を意味しない。[Blockの編集完了条件](../operations/Block.md)を満たす必要がある。

## 3. Geometryドラッグの確定

1. 保留中の最新pointer位置を反映する。
2. 最終精度でsolveし、形状の妥当性を確認する。
3. Parameter再評価と必要な依存先の計算結果を確認する。
4. 成立した結果を確定し、履歴へ記録する。失敗した場合はTX-02に従う。

preview中のlocal solve、fallback、target選択は[拘束と依存更新](../calculation/拘束と依存更新.md)に従う。preview中にはParameterの参照寸法feedbackを反復しない。

## 4. 履歴と操作の範囲

Block EditorはDocumentの履歴と分離したlocal履歴を使い、完了時にDocumentへ1 transactionとして記録する。Parameter画面の1回の適用は1つの履歴単位とする。

この文書の復元規則は、ファイル読込時の不正データ処理、参照先削除時の処理、各コマンドのEsc／取消操作を一律に変更するものではない。それぞれの操作仕様に従う。

## 5. 履歴に保持する状態

以下の変更をUndo/Redoの対象とする。Document履歴のsnapshotはversion 22と同等のDocument状態を保持し、Block Editorのdraftとlocal履歴も対象scopeの同じ情報を保持する。

| 対象 | 保持する内容 |
| --- | --- |
| Geometry・Constraint・Sketch・Block | 形状と拘束、Splineとfit point、中心線拘束、順序付きチェーンオフセット参照、同一Sketch内の共通描画順 |
| Parameter・寸法 | Parameter、寸法名、引用形式の式、評価cache、次の寸法採番値 |
| 外観 | Sketchごとの一般・補助線・寸法Appearance、寸法の個別Appearance、Geometry等のAppearance |
| Annotation | 本体、所属、style |
| Hatch | 本体、境界参照、次のHatch採番値 |
| Reference Image | 本体、Base64埋め込みデータ、変換、表示状態 |
| 派生Geometry Instance | 投影・ミラー・直線パターンInstanceの参照と設定 |

同一Sketch内で完結するミラー／直線パターンのdragは、逆変換した参照元Geometryの変更として履歴へ記録する。派生側の独立座標は保存しない。編集可能な操作の範囲は[所属と編集可否](./所属と編集可否.md#6-blockと派生geometryの編集)に従う。

## 6. 履歴・永続化の対象外

Selection、hover、Interaction State、View State、viewport、Sketch TreeのSketch／分類の開閉状態と横幅は永続Documentの一部ではない。Selection、hover、View State、viewport、Sketch Treeの開閉状態と横幅は履歴対象外とする。

Reference Imageは履歴に含めるが、clipboardへは含めない。
