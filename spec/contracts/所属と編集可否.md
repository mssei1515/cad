# 所属と編集可否

表示、通常選択、拘束の入力、形状編集の適用範囲を区別する。各操作の確定・失敗は[編集と履歴](./編集と履歴.md)、削除は[削除と参照](./削除と参照.md)に従う。

## 1. 所属と座標系

- Point、Line、Circle、Arc、Spline は必ず1つの作図可能 Sketch に所属する。
- Constraint も所有側の1つの Sketch に所属する。
- Block Instance は配置先の1つの Sketch に所属し、その Projection も同じ Sketch の要素として扱う。
- LeaderとFree Textは作成時のactive Sketchに所属する。Root選択中はAnnotationを作成できない。
- Hatchは作成時のactive Sketchに所属し、同じSketchの通常Line、Circle、Arc、Splineだけを境界として参照する。Root選択中は作成できない。
- Reference Imageは読み込み時のactive Sketchに所属する。Root選択中は読み込めず、Constraint、solver、snapには参加しない。
- すべての通常 Sketch は共通のワールド XY 座標系を使う。
- 同じ座標にある別 Sketch の Point は別オブジェクトであり、共有 Point ではない。

## 2. アクティブSketchと編集対象

アクティブ Sketch だけが通常の作図・変形・通常拘束の対象になる。Sketch 切替時は、選択、ドラッグ、作図途中、拘束コマンド、寸法入力、スナップを解除する。

非アクティブ Sketch は表示中であれば Canvas に描画するが、通常時はGeometry、Block Instance、Constraint Dimension、Annotation、Reference Imageを青色や太線でhover強調せず、選択、dragもできない。pointerが非アクティブなGeometry、Block Instance、Constraint Dimensionに重なった場合は、図形を強調せずに対象ID、所属Sketch名、active Sketchからの参照可否だけをpointer付近へ表示する。現在の実装では非アクティブ要素の `globalAlpha` は1であり、「薄く表示する」という旧仕様は実装されていない。

拘束・寸法コマンドで先祖Sketchを参照対象として指定している間だけ、参照可能な非アクティブGeometryおよびBlock Projectionをcommand operandとしてhover・選択できる。このcommand限定経路は通常のCanvas Selectionへ追加しない。

## 3. Sketchをまたぐスナップ

表示中の別 Sketch Geometry へ作図時スナップできる。スナップは座標を借りるだけであり、別 Sketch 間の要素共有や通常拘束を作らない。Lineの中点はスナップ候補にせず、中点一致拘束も自動作成しない。

スナップ先と作成先が別 Sketch でも、新しい Geometry は必ずアクティブ Sketch に所属する。

## 4. 通常拘束の範囲

通常拘束は同一 Sketch 内で閉じる。兄弟、子孫、別ブランチを含む対象を通常拘束として結びつけない。

この制限は、拘束の solve 範囲と所有権を明確にし、別 Sketch の意図しない変形を防ぐためである。

## 5. 先祖参照の範囲

参照拘束は、アクティブ Sketch の Geometry を、先祖 Sketch の読み取り専用 Geometry に関係づける。

スケッチ投影も同じ先祖参照範囲を使用するが、先祖Geometryを指す派生Instanceと独立した座標を持たない表示Geometryを作成する。投影Geometryは子Sketch所属の読取専用入力として、同じ子Sketch内の通常Geometryとの通常拘束に使用できる。子Sketchから先祖SketchのGeometryを変更してはならないため、投影Geometryおよび投影を経由する派生Geometryはdragできない。元Sketchを非表示にした後も参照は維持する。詳細は[派生Geometryインスタンス](../operations/派生Instance.md)を参照する。

```text
先祖 Sketch（固定入力）
        ↓
子孫 Sketch（solve 対象）
```

許可する参照元は `ancestorSketchIds(activeSketchId)` に含まれる作図可能 Sketch だけである。

禁止する参照は次のとおり。

- 自分自身
- 子孫
- 兄弟
- 別ブランチ
- Root Sketch
- 直接・間接の循環を作る関係

対称拘束は3対象を持つため、参照対象がある場合は全参照対象が同じ先祖 Sketch に属する必要がある。それ以外の参照拘束は、原則としてアクティブ側1対象と先祖側1対象の組み合わせである。

## 6. Blockと派生Geometryの編集

Block外部の拘束はInstanceの配置を解き、Definition内部の形状自由度とは区別する。固定・回転の条件は[BlockのConstraintとsolve](../operations/Block.md#12-constraint-と-solve)に従う。

派生Geometryは独立した座標を持たない。同一Sketch内で完結するミラー／直線パターンのドラッグは、逆変換した参照元の編集として扱う。スケッチ投影または投影を経由するchainはドラッグできない。trim、fillet、Spline構造編集、固定、補助線切替は派生側で行わない。具体的な対象・禁止操作は[派生Instanceの共通モデルと編集](../operations/派生Instance.md)に従う。
