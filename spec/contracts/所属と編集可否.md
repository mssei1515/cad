# 所属と編集可否

表示、通常選択、拘束の入力、形状編集の適用範囲を区別する。各操作の確定・失敗は[編集と履歴](./編集と履歴.md)、削除は[削除と参照](./削除と参照.md)に従う。

## 1. 所属と座標系

- Point、Line、Circle、Arc、Spline は必ず1つの作図可能 Sketch に所属する。
- Constraint も所有側の1つの Sketch に所属する。
- Block Instance は配置先の1つの Sketch に所属し、その Projection も同じ Sketch の要素として扱う。
- LeaderとFree Textは作成時のactive Sketchに所属する。Rootがactiveの間はAnnotationを作成できない。
- Hatchは作成時のactive Sketchに所属し、同じSketchの通常Line、Circle、Arc、Splineだけを境界として参照する。Rootがactiveの間は作成できない。
- Reference Imageは読み込み時のactive Sketchに所属する。Rootがactiveの間は読み込めず、Constraint、solver、snapには参加しない。
- すべての通常 Sketch は共通のワールド XY 座標系を使う。
- 同じ座標にある別 Sketch の Point は別オブジェクトであり、共有 Point ではない。

選択した通常Objectの所属変更は[スケッチ間移動](../operations/Sketch.md#6-選択図形のスケッチ間移動)で行う。構成点と内部拘束を一緒に移し、外部参照が成立する移動先だけを許可する。座標系、ID、active・選択・表示の独立性を維持する。

## 2. 作図先、選択、編集対象とロック

内部の activeSketchId は保存互換性を維持し、UIでは「作図先スケッチ」／Drawing sketchと呼ぶ。作図先と選択対象の所属は独立する。新規作図・貼り付けは作図先へ追加し、既存要素の選択・編集・寸法値変更によって作図先や所属を自動変更しない。作図先はツリーの「作図先」、右クリックの「作図先」、ダブルクリックまたはAlt+Enterで明示的に変更する。切替時は選択、ドラッグ、作図途中、拘束コマンド、寸法入力、スナップを解除する。

表示中のGeometry、Block、派生Instance、寸法、Annotation、Hatch、Reference Imageは所属やロックに関係なく選択・情報確認できる。Canvas、Tree、Propertiesは同じ選択を表示する。非表示要素は通常選択の対象外とする。Propertiesには所属スケッチと作図先を別々に表示する。

| 操作 | 未ロックの作図先 | 未ロックのその他のSketch |
|---|---|---|
| 選択・情報確認・作図参照 | 可 | 可 |
| 既存図形の移動・削除・属性変更 | 可 | 可 |
| 既存寸法の値・式変更 | 可 | 可 |
| 寸法・拘束の新規追加、拘束の種類・対象変更 | 可 | 不可 |
| 分割・トリム | 可 | 不可 |
| 新規作図・貼り付け | 追加先 | 不可 |

作図先限定操作を他Sketchへ適用しようとした場合は、所属Sketchを作図先に指定するよう案内し、自動切替しない。投影、参照寸法、固定図形などの既存の直接編集制限は維持する。拘束はSketch内で完結し、別Sketch間の直接拘束や共有Pointを新規作成しない。既存の先祖参照・投影の仕組みは下記の参照規則に従う。

Ctrl／Shift追加選択は同一Sketch内に限定する。異なるSketchへの追加clickは無視し、修飾keyなしのclickは単一選択へ置き換える。矩形選択は従来どおり作図先の表示中Objectを対象とし、他Sketchの選択へ追加しない。拘束単独選択は他の種類と混在させない。

他Sketchの移動・寸法値変更も、対象が所属するSketchをsolveし、その既存拘束と参照依存更新を維持する。寸法やGeometryを作図先へ移し替えない。

Sketch単位の locked は手動編集の禁止を表す。ロック中は移動、削除、属性変更、寸法値変更、寸法・拘束追加／変更、分割・トリム、新規追加を禁止する。選択・情報確認・作図参照は許可する。ロックはsolverの固定自由度には変換せず、参照元変更への追従更新を継続する。親Sketchの削除対象にロック中Sketchが含まれる場合も削除を禁止する。ロック解除は明示的な操作とし、作図先がロック中の場合は解除または作図先変更を案内する。

ツリーの単色錠前buttonで各Sketchのロック状態を表示・切替する。閉じた錠前はロック中、開いた錠前は解除中を示す。状態によるbuttonの背景色変更は行わない。切替はUndo／Redo対象で、DocumentとBlock DefinitionのSketchへ保存する。旧ファイルの未指定値は未ロックとする。ロックは親子へ自動伝播しない。

## 3. Sketchをまたぐスナップ

表示中の別 Sketch Geometry へ作図時スナップできる。スナップは座標を借りるだけであり、別 Sketch 間の要素共有や通常拘束を作らない。Lineの中点はスナップ候補にせず、中点一致拘束も自動作成しない。

スナップ先と作成先が別 Sketch でも、新しい Geometry は必ずアクティブ Sketch に所属する。

## 4. 通常拘束の範囲

通常拘束は同一 Sketch 内で閉じる。兄弟、子孫、別ブランチを含む対象を通常拘束として結びつけない。

この制限は、拘束の solve 範囲と所有権を明確にし、別 Sketch の意図しない変形を防ぐためである。

## 5. 先祖参照の範囲

参照拘束は、アクティブ Sketch の Geometry を、先祖 Sketch の読み取り専用 Geometry に関係づける。寸法コマンドでは、参照可能な先祖SketchのGeometryだけを測る読み取り専用寸法も追加できる。異なる先祖Sketchの図形同士も対象とし、寸法はアクティブSketchに所属する。参照元のGeometryは変更しない。

スケッチ投影も同じ先祖参照範囲を使用するが、先祖Geometryを指す派生Instanceと独立した座標を持たない表示Geometryを作成する。投影Geometryは子Sketch所属の読取専用入力として、同じ子Sketch内の通常Geometryとの通常拘束に使用できる。子Sketchから先祖SketchのGeometryを変更してはならないため、投影Geometryおよび投影を経由する派生Geometryは形状dragできない。同期インスタンスの全体移動は、先祖形状を変更しないため許可する。元Sketchを非表示にした後も参照は維持する。詳細は[派生Geometryインスタンス](../operations/派生Instance.md)を参照する。

```text
先祖 Sketch（固定入力）
        ↓
子孫 Sketch（solve 対象）
```

許可する参照元は `ancestorSketchIds(activeSketchId)` に含まれる作図可能 Sketch だけである。

禁止する参照は次のとおり。

- 自分自身
- 子孫
- 兄弟
- 別ブランチ
- Root Sketch
- 直接・間接の循環を作る関係

対称拘束は3対象を持つため、参照対象がある場合は全参照対象が同じ先祖 Sketch に属する必要がある。それ以外の参照拘束は、原則としてアクティブ側1対象と先祖側1対象の組み合わせである。

## 6. Blockと派生Geometryの編集

Block外部の拘束はInstanceの配置を解き、Definition内部の形状自由度とは区別する。固定・回転の条件は[BlockのConstraintとsolve](../operations/Block.md#12-constraint-と-solve)に従う。

派生Geometryは独立した座標を持たない。同一Sketch内で完結するミラー／直線パターン／同期インスタンスの形状ドラッグは、逆変換した参照元の編集として扱う。スケッチ投影または投影を経由するchainは形状ドラッグできない。同期インスタンス・ミラー・直線パターンの全体移動は共有形状と既存の派生関係を維持し、移動可能な配置・軸・方向Lineの自由度を使う。Canvasの1回目は全体選択、同じInstanceの次のclickをドラッグせず完了すると内部Geometry選択とする。全体選択中に押下からドラッグした場合は全体移動を維持する。trim、fillet、Spline構造編集、固定、補助線切替は派生側で行わない。具体的な対象・禁止操作は[派生Instanceの共通モデルと編集](../operations/派生Instance.md)に従う。

スケッチの表示／非表示はロック中も切り替えられる。表示切替でロックや作図先を変更しない。作図先スケッチを非表示にできない制限は維持する。
