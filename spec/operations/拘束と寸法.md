# 拘束と寸法の操作

対象の所属・編集可否は[共通契約](../contracts/所属と編集可否.md)、確定・失敗・履歴は[編集と履歴](../contracts/編集と履歴.md)に従う。以下に操作固有の条件を示す。

Lineの中点を候補にするスナップと`pointOnLineMidpoint`拘束は使用しない。中心位置が必要な場合は中心線commandで意図を明示する。

Line–Circleの中心距離寸法は、Line本体とCircle円周をどちらの順でclickしても作成できる。測定対象は有限線分までの最短距離や円周までのすき間ではなく、Lineを両方向へ無限に延長した支持線からCircle中心までの垂直距離である。LineとArcの組み合わせには適用しない。

同心半径差寸法は、中心が一致しているCircle／Arcの円周または円弧を2つclickして作成する。Circle–Circle、Circle–Arc、Arc–Arcの全組み合わせを許可し、入力値は2つの半径の差の絶対値とする。作成時の大小関係を保持したまま半径差を拘束し、同じ拘束の中心X差・中心Y差を0にすることで同心関係も維持する。対象が同心と判定できない場合は作成せず、理由をHintへ表示する。

対称拘束は対象の種類ごとに次の量だけを拘束する。

- Point対称は、2 Pointの中点を対称軸上へ置き、2 Pointを結ぶ方向を対称軸へ直交させる。
- Line対称は、各Lineを両方向へ無限に延長した支持直線どうしを対称軸に対する鏡像にする。拘束するのは支持直線の方向と位置だけであり、Lineの中点、長さ、始点・終点の対応や各端点の支持直線方向位置は拘束しない。一方のLineと対称軸を固定した場合も、もう一方の各端点には支持直線方向の独立した自由度が残り、一端だけを伸縮できる。既存JSONの`lineSymmetry.reversed`は互換的に往復保存するが、端点対応を表す拘束条件としては使用しない。
- Arc対称は、2 Arcの中心位置を対称にし、半径を一致させる。開始角・終了角および端点位置は対称拘束の対象にせず、それぞれ独立して変更できる。

## 2. 拘束追加のルール

1. 通常拘束の対象はアクティブ Sketch に属する。
2. 別 Sketch の対象を含む場合は、アクティブ Sketch とその先祖 Sketch の組み合わせだけを参照拘束として許可する。
3. 子孫、兄弟、別ブランチは参照できない。
4. 新しい拘束を一時追加して solve し、総残差が有限かつ受入れ許容誤差以下なら、反復の終了理由にかかわらず成立として扱う。許容誤差を超える、非有限値になる、または不安定になる場合はロールバックする。
5. 既存拘束と重複する寸法は、形状を変えない読み取り専用寸法として追加する。
6. 単一 Block Instance 内の Projection だけを測る寸法も読み取り専用にする。Definition のサイズ変更は Block Editor で行う。
7. 新規拘束によって十分長かった Line が下限近傍へ崩壊する場合は拒否する。
8. Splineの接線拘束は開Splineの始点または終点だけに作成できる。端点接線拘束を持つSplineを閉Splineへ変更する操作は拒否する。

## 3. 拘束寸法と読み取り専用寸法

拘束寸法は数値または数式を入力とし、評価結果をsolveの目標値`target`へ反映する。値変更によってGeometryを変形する。寸法線の位置、ラベル位置、表示方向は`dimension`に保存する。

読み取り専用寸法は`readOnlyDimension = true`、`enabled = false`とし、Geometryから取得した実測値を括弧付きで表示する。式と数値入力は表示せず、読み取り専用symbolとして他のParameterおよび拘束寸法式から参照できる。

すべての寸法は所属Parameter名前空間で一意な`parameterName`を持つ。新規寸法は名前空間固有のcounterから`d1`、`d2`、…を付与し、ユーザーは有効かつ一意な識別子へ変更できる。名称変更では同じ名前空間にある全数式の該当識別子tokenを一括更新する。非表示または無効な寸法もsymbolとして存在する限り参照できる。

単一Canvasでは表示中の全Sketchに所属するConstraint Dimensionを描画する。非アクティブSketchであることだけを理由に寸法を非表示にしない。
## 4. 寸法の表示と配置

すべての寸法はConstraintに属する。外観の継承は[外観](../contracts/外観.md)のAPP-05に従う。Propertiesから値と次のAppearance属性を編集できる。

- Visible
- Color
- Line width
- Precision
- Prefix / Suffix
- Terminator type / size
- Extension line overshoot / origin gap
- Arrow opening angle
- Dimension text height / gap from dimension line

Colorは寸法線、端末記号、補助線、ラベルへ適用し、線幅は寸法線、端末記号および補助線へ画面px単位で適用する。寸法補助線の突出量は寸法線を越える長さ、起点すき間は対象Geometryの数学的な起点から補助線開始位置までの間隔とする。

Point marker半径や補助線Geometryの端部はみ出し量を自動加算せず、起点すき間が`0mm`なら補助線も対象起点から描画する。端末記号は標準矢印、塗りつぶし矢印、点から選択し、両端に端末を持つ寸法では左右で同じ種類とサイズを使用する。

標準矢印は線幅と開き角によるstroke結合の突出を描画位置で補正し、選択強調時や表示倍率の変更後も、視覚上の先端を寸法補助線と寸法線の交点へ一致させる。円弧の半径寸法は中心側の端末記号を描画せず、円弧側だけに選択中の端末記号を描画する。

半径寸法のラベルが中心点から円弧上までの区間内にある場合、寸法線は中心点から円弧上までで止め、円弧上から半径方向外側へ突出する寸法補助線も描画しない。ラベルをこの区間の外へ移動した場合は、長さ寸法と同じくラベル側へ寸法線を延長する。

寸法線を円弧の角度範囲外へ移動した場合は、近い円弧端点から寸法線との交点を越えるまで円弧状の寸法補助線を描き、寸法Appearanceの起点すき間と突出量を円弧長として適用する。サイズは矢印では長さ、点では直径とし、開き角は矢印系だけへ適用する。

線形寸法では寸法補助線間の距離、角度寸法では同距離に相当する寸法円弧長を、画面上の寸法文字幅へ端末記号1個分の長さを加えた必要幅と比較する。必要幅を下回った時点で矢印系端末を補助線の外側へ反転して内向きに描き、反転した各端末には矢印長さの1.5倍の軸線を外向きに描く。

角度寸法ではこの軸線を載せる分だけ寸法円弧も延長する。方向を持たない点端末は反転しない。

円弧の半径寸法でも円弧側の反転矢印に同じ長さの外向き軸線を描く。寸法補助線と端末記号は常時表示する。

寸法文字の高さと寸法線との間隔は、線形寸法、角度寸法など共通表示へ適用する。長さ系の設定値はmmで保持し、`mm × 96 / 25.4`で画面pxへ換算してzoomを相殺するため、どの表示倍率でもおおよそ同じ画面上サイズを維持する。

開き角は度で保持する。個別Colorまたは線幅を空にすると所属Sketchから継承した設定へ戻る。

PrefixとSuffixはPropertiesへの文字入力中にCanvasへ即時反映する。Canvas上の寸法ラベルはParameter名や入力式を表示せず、常にprefix、評価後の数値、suffixを表示する。

Upper／Lower toleranceは現在のPropertiesには表示しない。読み取り専用寸法は実測値を括弧付きで表示し、値は編集できない。

寸法の配置はCanvas上でdragでき、dragでは配置だけを変更してColor、Prefix、Suffix、Precisionおよび各寸法Appearance属性を保持する。表示中のSketchに属する寸法は、Sketchがアクティブかどうかにかかわらず描画する。

非アクティブSketchの寸法は通常時にも所属Sketch名および参照可否をpointer付近へ表示できるが、寸法自体はhover強調しない。非アクティブSketchのGeometryおよびBlock Instanceも同じ所属・参照可否表示を行うが、図形のhover強調およびselection対象にはしない。

単純な数値リテラルではない数式を入力した拘束寸法には、カミナリマークを数値ラベルの前へ付記する。マークは寸法色でCanvas描画し、寸法文字高さに比例してzoomを相殺する。マークの幅も寸法文字の必要幅へ含める。参照寸法および数値リテラルを直接入力した拘束寸法には表示しない。

標準矢印の先端補正は矢羽まで外側へ平行移動させず、視覚上の先端から矢羽までの寸法線方向距離を設定した端末サイズに保つ。したがって外側へ反転した場合も、矢羽より後方には端末サイズの0.5倍に相当する軸線が見え、先端補正によって軸線が短く見える状態にはしない。


## 5. 寸法コマンドの入力

Canvasの寸法入力は数値に加えてParameter名と数式を受け付ける。入力中の有効な式は評価後の数値をpreviewへ使い、エラー時は入力を閉じず理由を表示する。

寸法コマンド中にLineを最初にclickした場合は仮の線長寸法を表示し、続けてCircle円周をclickするとCircle中心からLine支持線までの距離寸法へ切り替える。Circle円周を最初にclickした場合は仮の直径寸法を表示し、続けてLineをclickしても同じ中心距離寸法へ切り替える。

CircleまたはArcを最初にclickした後、同心のCircle／Arc円周をclickした場合は半径差寸法へ切り替える。2つ目を選ばずCanvas空白をclickした場合は、従来どおり最初のLineの線長、Circleの直径、Arcの半径を確定する。
