# 図面のブックマークリンク

## 登録とリンク作成

必要なブラウザAPIに対応した環境では、ファイルの読込・保存が成功した後にファイルを自動登録し、URLバーの`document` queryをそのファイルの登録IDへ更新する。ページの再読込は行わず、`history.replaceState`で履歴を追加せずに更新する。その他のquery・fragmentとhistory stateは保持する。その場でCtrl+Dを押して図面のブックマークに登録できる。別ファイルの読込・名前を付けて保存が成功した場合は、その保存先の登録IDへ更新する。キャンセル・読込や保存の失敗では現在のURLを変更しない。

ファイルへのアクセス情報（FileSystemFileHandle）をIndexedDBの`jot2d.document-bookmarks`、`files` storeに保存する。各登録はランダムなUUIDの`id`と`handle`を持つ。同じファイルは`isSameEntry`で照合し、既存の登録IDを再利用する。図面データ自体は登録情報へ複製しない。遅延した登録結果は、その間に別ファイルへ切り替わっていた場合、現在のURLへ反映しない。

ファイルメニューの「この図面のリンクをコピー / Copy link to this drawing」も利用できる。コピーする専用URLは起動したJot2DのURLに`?document=<登録ID>`を付加し、その他のqueryとfragmentを除いたものとする。絶対ファイルパスをURLには含めない。リンクをクリップボードへコピーし、URL欄を持つダイアログも表示する。コピーできない場合はそのURL欄から手動でコピーできる。ダイアログの「リンクを開く」で新しいタブに専用URLを開き、Ctrl+DでChromeのブックマークに登録できる。

新規未保存の図面や互換ファイル入力で開いた図面など、ファイルハンドルを持たない場合は、先にファイルを開くか名前を付けて保存する案内を表示する。登録・リンク作成は図面の保存、図面データ、Undo／Redoを変更しない。未保存の変更はリンクに含まれない。

互換ファイル入力による読込・ハンドルを伴わないダウンロード保存が成功した場合、または自動登録が失敗した場合は、前の図面の`document` queryを除去する。自動登録やURL更新に失敗しても、通常の読込・保存は成功として扱い、図面・保存先・保存状態・編集操作を維持する。

## 起動時の読込

起動の初期化完了後、`document` queryの登録情報を参照し、元ファイルの保存済み最新版を既存の図面読込経路で開く。読込権限が既にある場合は自動で開く。再許可が必要な場合は「許可して開く / Allow and open」のダイアログを表示し、利用者のクリックで読込権限を要求する。キャンセル・拒否・読込失敗後はファイルメニューの「リンクの図面を開く… / Open linked drawing…」から再試行できる。正常に開いた後は再試行項目を隠す。

開いたハンドルを通常の保存先として引き継ぐ。上書き保存時の書込権限は既存のファイル保存の扱いに従う。読込中の図面編集・Block編集は既存の置換確認と内容一致チェックで保護し、拒否・失敗時は図面と保存先を置換しない。

## 利用範囲

Chromeというブラウザ名ではなく、`showOpenFilePicker`、IndexedDB、`crypto.randomUUID`、FileSystemFileHandleの`isSameEntry`・`queryPermission`・`requestPermission`の有無で対応を判定する。未対応環境ではリンクのコピー・再試行メニューを表示せず、ファイル登録・専用リンク読込は実行しない。専用URLで未対応環境を起動してもエラーや権限ダイアログを出さず、`document` queryを除去して通常の新規図面を表示する。通常の互換ファイル入力・ダウンロード保存は従来どおり利用できる。

登録は同じChromeプロファイル・同じ起動元のブラウザ保存領域で有効。HTTPのhost／port変更、別のChromeプロファイル、ブラウザデータの削除などでは登録を利用できない場合がある。`file:` 起動でもブラウザがIndexedDBとファイルハンドルの保存を許可する環境で利用できる。登録情報が見つからない場合は、元ファイルを開いてリンクを作り直す案内を表示する。ファイルの移動・削除・権限失効や保存領域の利用不可はエラーとして表示し、空の図面を元ファイルへ自動保存しない。
