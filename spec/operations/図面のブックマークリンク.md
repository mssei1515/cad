# 図面のブックマークリンク

## 登録とリンク作成

Chromeでファイルを開くか、名前を付けて保存した後、ファイルメニューの「この図面のリンクをコピー / Copy link to this drawing」で専用URLを作成する。ファイルへのアクセス情報（FileSystemFileHandle）をIndexedDBの`jot2d.document-bookmarks`、`files` storeに保存する。各登録はランダムなUUIDの`id`と`handle`を持つ。同じファイルは`isSameEntry`で照合し、既存の登録IDを再利用する。図面データ自体は登録情報へ複製しない。

専用URLは起動したJot2DのURLに`?document=<登録ID>`を付加し、その他のqueryとfragmentを除いたものとする。絶対ファイルパスをURLには含めない。リンクをクリップボードへコピーし、URL欄を持つダイアログも表示する。コピーできない場合はそのURL欄から手動でコピーできる。ダイアログの「リンクを開く」で新しいタブに専用URLを開き、Ctrl+DでChromeのブックマークに登録できる。

新規未保存の図面や互換ファイル入力で開いた図面など、ファイルハンドルを持たない場合は、先にファイルを開くか名前を付けて保存する案内を表示する。登録・リンク作成は図面の保存、図面データ、Undo／Redoを変更しない。未保存の変更はリンクに含まれない。

## 起動時の読込

起動の初期化完了後、`document` queryの登録情報を参照し、元ファイルの保存済み最新版を既存の図面読込経路で開く。読込権限が既にある場合は自動で開く。再許可が必要な場合は「許可して開く / Allow and open」のダイアログを表示し、利用者のクリックで読込権限を要求する。キャンセル・拒否・読込失敗後はファイルメニューの「リンクの図面を開く… / Open linked drawing…」から再試行できる。正常に開いた後は再試行項目を隠す。

開いたハンドルを通常の保存先として引き継ぐ。上書き保存時の書込権限は既存のファイル保存の扱いに従う。読込中の図面編集・Block編集は既存の置換確認と内容一致チェックで保護し、拒否・失敗時は図面と保存先を置換しない。

## 利用範囲

登録は同じChromeプロファイル・同じ起動元のブラウザ保存領域で有効。HTTPのhost／port変更、別のChromeプロファイル、ブラウザデータの削除などでは登録を利用できない場合がある。`file:` 起動でもブラウザがIndexedDBとファイルハンドルの保存を許可する環境で利用できる。登録情報が見つからない場合は、元ファイルを開いてリンクを作り直す案内を表示する。ファイルの移動・削除・権限失効や保存領域の利用不可はエラーとして表示し、空の図面を元ファイルへ自動保存しない。
